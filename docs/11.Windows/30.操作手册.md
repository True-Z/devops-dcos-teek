## 系统操作

### 日常使用

#### 关闭硬盘自动休眠

```json
{
  "控制面板": {
    "硬件和声音": {
      "编辑计划设置": {
        "更改高级电源设置": {
          "硬盘": {
            "在此时间后关闭硬盘": "从不"
          }
        }
      }
    }
  }
}
```

### 最小操作流程

1. 打开 `控制面板`。
2. 进入 `硬件和声音`。
3. 打开 `电源选项`。
4. 进入 `更改高级电源设置`。
5. 将硬盘休眠时间设置为“从不”。

- 适合机械硬盘频繁休眠、唤醒后卡顿的场景。
