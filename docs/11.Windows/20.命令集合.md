### PowerShell

#### 允许使用脚本

```sh

```

### 关闭自动更新

```sh
# 打开注册表输入路径
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings
# 新建 DWORD(32位)值，输入暂停天数（十进制）
FlightSettingsMaxPauseDays # key
```

## 系统命令

### 基础命令

| 命令                  | 作用                         | 常见参数             | 适用场景         |
| --------------------- | ---------------------------- | -------------------- | ---------------- |
| `del`                 | 删除文件                     | `/f` 强制删除        | 删除单文件       |
| `rd` / `rmdir`        | 删除目录                     | `/s` 递归、`/q` 静默 | 删除整个目录     |
| `set-executionpolicy` | 调整 PowerShell 脚本执行策略 | `RemoteSigned` 常用  | 允许执行本地脚本 |

#### 删除

```sh
# 删除文件
del
-f 强制删除

# 删除目录
rd || rmdir
-s 递归
-q 无须询问
```

### 最小示例

```sh
# 删除单个文件
del /f demo.txt

# 删除整个目录
rmdir /s /q demo-folder
```

- 执行删除命令前，最好先确认路径，避免误删。
