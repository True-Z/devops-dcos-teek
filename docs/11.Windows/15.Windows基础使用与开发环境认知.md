# Windows 基础使用与开发环境认知

## 阅读建议

- 这页不是配置大全，而是帮你建立 Windows 在日常开发中的基础使用认知。

## 核心目标

- 先理解路径、终端、文件、环境变量这些开发高频基础，再和 Linux 学习做衔接。

## 最常见关注点

| 主题     | 为什么重要                 |
| -------- | -------------------------- |
| 路径     | 影响命令、脚本、工具配置   |
| 终端     | 影响开发命令执行体验       |
| 环境变量 | 影响 Node、Git、工具链运行 |
| 文件系统 | 影响权限、换行、路径写法   |

## 最小示例

```text
打开终端 -> 进入目录 -> 执行开发命令 -> 查看环境变量
```

## 常见误区

- 只会点图形界面，不熟悉终端基础操作。
- 路径和分隔符概念不清，导致脚本配置容易出错。
- 完全不看环境变量，出问题时难以排查。
