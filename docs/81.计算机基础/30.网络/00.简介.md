**[计算机网络](https://zh.wikipedia.org/wiki/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C)**是利用通信线路和通信设备，将地理位置不同的、功能独立的多台计算机互连起来，以功能完善的网络软件来实现资源共享和信息传递功能的总称。

## 核心关注点

| 主题     | 作用               | 为什么重要               |
| -------- | ------------------ | ------------------------ |
| 分层模型 | 拆解网络通信职责   | 便于理解“问题出在哪一层” |
| IP/端口  | 标识通信对象与服务 | 便于理解请求如何到达目标 |
| TCP/UDP  | 定义传输方式       | 影响可靠性与实时性       |
| HTTP     | 常见应用层协议     | 前端/后端协作基础        |

## 最小理解示例

```text
浏览器发起请求 -> DNS 解析域名 -> 建立连接 -> 发送 HTTP 请求 -> 服务器返回响应
```

- 你在前端里看到的“请求接口”，底层就是这条链路的简化结果。
