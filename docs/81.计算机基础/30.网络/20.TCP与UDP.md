## 核心目标

- 理解为什么有的通信更可靠，有的通信更追求实时性。

## 对比速查

| 协议 | 主要特点           | 适合场景               |
| ---- | ------------------ | ---------------------- |
| TCP  | 面向连接、可靠传输 | 网页、登录、文件传输   |
| UDP  | 无连接、开销更低   | 音视频、游戏、实时消息 |

## 最小示例

```text
打开网页 -> 更适合 TCP
实时语音通话 -> 更适合 UDP
```

- 选型核心不只是“快不快”，而是“更重可靠性还是更重实时性”。
