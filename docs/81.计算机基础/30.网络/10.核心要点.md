## 核心目标

- 理解请求为什么能到达服务器、为什么会超时、为什么会跨域。

## 核心概念速查

| 概念 | 作用             | 常见问题                     |
| ---- | ---------------- | ---------------------------- |
| DNS  | 域名转 IP        | 域名解析慢、污染             |
| IP   | 标识网络中的主机 | 请求到底发给谁               |
| 端口 | 标识主机上的服务 | 服务如何区分                 |
| TCP  | 可靠传输         | 为什么三次握手、为什么慢启动 |
| HTTP | 常见应用层协议   | 前后端接口通信基础           |

## 最小示例

```text
输入网址 -> DNS 解析 -> 建立 TCP 连接 -> 发送 HTTP 请求 -> 返回响应 -> 页面渲染
```

- 这条链路是网络学习的基础，能帮助你把浏览器里的“一个请求”拆成多个阶段。
