数据结构用于回答“数据应该怎么组织，程序才能更高效地处理”。

## 核心关注点

| 结构  | 适合场景             | 典型特点                     |
| ----- | -------------------- | ---------------------------- |
| 数组  | 顺序存储、按索引访问 | 查询快，插入删除中间项成本高 |
| 链表  | 频繁插入删除         | 查询慢，插入删除灵活         |
| 栈    | 后进先出场景         | 适合函数调用、撤销操作       |
| 队列  | 先进先出场景         | 适合任务调度、消息处理       |
| 树/图 | 层级与关系建模       | 适合目录、路由、依赖关系     |

## 最小理解示例

```text
浏览器历史记录回退 -> 栈
异步任务排队执行 -> 队列
页面菜单层级 -> 树
```

- 学数据结构的重点不是记定义，而是能把真实问题映射到合适结构。
