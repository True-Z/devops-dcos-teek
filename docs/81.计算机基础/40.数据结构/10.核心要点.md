## 核心目标

- 理解不同结构在“查、插、删、组织关系”上的取舍。

## 常见结构速查

| 结构 | 适用场景     | 关键特点                 |
| ---- | ------------ | ------------------------ |
| 数组 | 索引访问频繁 | 查询快，插入删除中间项慢 |
| 链表 | 频繁插入删除 | 结构灵活，但查询慢       |
| 栈   | 后进先出     | 适合撤销、调用栈         |
| 队列 | 先进先出     | 适合任务排队             |
| 树   | 层级关系     | 适合菜单、目录、DOM      |
| 图   | 复杂关系网络 | 适合依赖、路线、社交关系 |

## 最小示例

```text
浏览器历史回退 -> 栈
排队执行异步任务 -> 队列
页面菜单层级 -> 树
```

- 数据结构不是抽象名词，而是现实问题的组织方式。
