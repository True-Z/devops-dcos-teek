## 核心目标

- 理解为什么“查得快”和“改得快”通常不能同时兼得。

## 对比速查

| 结构 | 优点         | 缺点               | 适合场景             |
| ---- | ------------ | ------------------ | -------------------- |
| 数组 | 按索引访问快 | 中间插入删除成本高 | 列表、表格、顺序数据 |
| 链表 | 插入删除灵活 | 随机访问慢         | 队列、频繁改动结构   |

## 最小示例

```text
需要按下标快速访问第 10 项 -> 数组
需要频繁在中间插入节点 -> 链表
```

- 数据结构选择的关键，不是“哪个高级”，而是“当前操作模式是什么”。
