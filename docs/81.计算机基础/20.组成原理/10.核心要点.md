## 核心目标

- 理解程序、CPU、内存和 IO 之间是如何协作的。

## 核心概念速查

| 概念   | 作用               | 为什么重要             |
| ------ | ------------------ | ---------------------- |
| 指令   | 告诉 CPU 做什么    | 程序执行的最小单位     |
| CPU    | 执行指令           | 决定计算能力           |
| 内存   | 暂存数据与指令     | 决定程序运行速度       |
| 寄存器 | CPU 内部高速存储   | 决定关键数据访问效率   |
| IO     | 与外部设备交换数据 | 解释为什么读写通常更慢 |

## 最小示例

```text
点击运行程序 -> 程序装入内存 -> CPU 取指令 -> 执行 -> 输出结果
```

- 理解这条链路后，很多“为什么程序能跑”“为什么 IO 慢”会更容易想明白。
