计算机组成原理用于解释“程序为什么能被执行”，重点理解 CPU、内存、总线、指令与输入输出设备之间的协作关系。

## 核心关注点

| 主题    | 作用               | 为什么重要                 |
| ------- | ------------------ | -------------------------- |
| CPU     | 执行指令与控制流程 | 理解程序为何逐条运行       |
| 内存    | 存储数据与指令     | 理解数据读写成本           |
| 总线    | 传输数据与控制信号 | 理解部件如何通信           |
| IO 设备 | 与外界交互         | 理解输入输出为什么慢于计算 |

## 最小理解示例

```text
程序装入内存 -> CPU 取指令 -> 执行运算/读写数据 -> 输出结果
```

- 这条“取指 -> 执行”链路，是组成原理最核心的理解入口。
