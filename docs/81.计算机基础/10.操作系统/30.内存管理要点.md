## 核心目标

- 理解程序为什么会占内存、为什么会内存不足、为什么会出现虚拟内存。

## 核心概念速查

| 概念     | 作用                 | 常见问题       |
| -------- | -------------------- | -------------- |
| 物理内存 | 真正的硬件内存       | 容量有限       |
| 虚拟内存 | 给程序更大的地址空间 | 频繁换页会变慢 |
| 页/分页  | 内存管理基本粒度     | 影响换页与映射 |

## 最小示例

```text
程序申请内存 -> 操作系统分配虚拟地址 -> 再映射到物理内存
```

- 大多数“程序内存很大”问题，看到的并不是程序直接控制物理内存，而是通过操作系统映射后的结果。
