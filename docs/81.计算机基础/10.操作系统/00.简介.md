操作系统负责管理硬件资源，并为应用程序提供统一的运行环境。

## 核心关注点

| 主题       | 作用              | 为什么重要                 |
| ---------- | ----------------- | -------------------------- |
| 进程与线程 | 管理程序执行单元  | 影响并发与调度理解         |
| 内存管理   | 管理程序运行空间  | 影响性能、稳定性、泄漏定位 |
| 文件系统   | 管理数据存储方式  | 影响持久化与权限理解       |
| 调度与中断 | 协调 CPU 执行顺序 | 影响系统响应与吞吐         |

## 最小理解示例

```text
双击应用 -> 操作系统创建进程 -> 分配内存 -> 调度 CPU 执行 -> 应用开始运行
```

- 这是理解操作系统最小的一条链路：应用不是“直接运行”，而是由操作系统负责拉起和管理。
