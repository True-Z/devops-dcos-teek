## 学习路径

1. 先看操作系统，理解进程、内存、文件系统等运行环境。
2. 再看计算机网络，理解请求是如何传输的。
3. 再补组成原理，理解 CPU、内存、指令执行的底层机制。
4. 最后结合数据结构，理解程序为何需要特定组织方式。
