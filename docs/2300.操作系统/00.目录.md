操作系统用于承接运维场景里最常接触的平台环境，当前以 Windows 和 Linux 两个方向作为主要入口。

## 主模型

- 当前主模型：对象层
- 这一组内容主要围绕实际会接触的平台环境来组织。

## 三级分类导航

| 三级分类                      | 说明                               |
| ----------------------------- | ---------------------------------- |
| [Windows](/ops/windows-intro) | 面向图形环境、配置、命令与常用操作 |
| [Linux](/ops/linux-intro)     | 面向命令行、文件权限、服务与日志   |

## 学习建议

1. 先明确自己当前主要使用的系统环境。
2. 再分别补齐对应系统下的基础使用、命令、配置与常见操作。
3. WSL 先作为 Windows 或 Linux 学习中的补充环境认知，不单独成主线。
