工程协作模块用于承接 IDE、版本控制系统、包管理器等项目协作工具知识，帮助把“写代码”与“工程运行、依赖管理、提交流程”连起来理解。

## 推荐阅读

- [IDE 简介](/ide-intro)
- [版本控制系统简介](/vcs-intro)
- [包管理器简介](/pm-intro)

## 学习路径

1. 先熟悉 IDE 和基础开发环境。
2. 再掌握 Git 等版本控制工具。
3. 最后理解 npm / pnpm 等包管理与依赖协作。

## 最小理解示例

```text
打开 IDE -> 拉取代码 -> 安装依赖 -> 运行项目 -> 提交代码
```
