# 川菜风味调料认知

## 快速看懂

- 川菜风味先抓豆瓣、干辣椒、花椒三样。
- 它们决定了红亮、辣香、麻香这条主线。

## 最小对应关系

| 调料     | 主要任务     |
| -------- | ------------ |
| 郫县豆瓣 | 出红油和底味 |
| 干辣椒   | 提辣香       |
| 花椒     | 提麻香       |
