# 基础调味与川菜风味速记

## 快速看懂

- 家常调味先分基础味，再分川菜底味。
- 真正容易翻车的不是调料少，而是不知道哪个负责什么。

## 最小分类

| 类别     | 代表调料           | 主要作用         |
| -------- | ------------------ | ---------------- |
| 基础味   | 盐、生抽、老抽     | 定味、提鲜、上色 |
| 去腥味   | 料酒               | 压腥、下锅前铺底 |
| 收口味   | 醋、少量糖         | 提酸、平衡味道   |
| 川菜底味 | 豆瓣、干辣椒、花椒 | 红亮、辣香、麻香 |

## 先建立的顺序感

- 爆香类多在前段。
- 提鲜和基础盐味多在中后段。
- 醋这类收口味很多时候偏后段更稳。

## 最小示例

```text
不会调味时先记：
盐定底，生抽提鲜，老抽上色，豆瓣出川味，醋收口
```
