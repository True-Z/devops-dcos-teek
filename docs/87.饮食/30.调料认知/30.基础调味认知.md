# 基础调味认知

## 快速看懂

- 家常做饭最先掌握的是盐、生抽、老抽、料酒、醋。
- 这几样就能覆盖多数基础家常菜。

## 最小对应关系

| 调料 | 主要任务   |
| ---- | ---------- |
| 盐   | 定底味     |
| 生抽 | 提鲜增咸   |
| 老抽 | 上色       |
| 料酒 | 去腥       |
| 醋   | 提酸和收口 |
