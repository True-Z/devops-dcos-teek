# 锅具与加热工具认知

## 快速看懂

- 锅具先看用途，不先看材质名词。
- 家常做饭最常用的就是炒锅、汤锅和电饭煲这三类。

## 常见分类

| 工具   | 主要用途           | 最常见场景       |
| ------ | ------------------ | ---------------- |
| 炒锅   | 快炒、煎炒、爆香   | 青椒肉丝、回锅肉 |
| 汤锅   | 煮汤、煮面、焯水   | 面条、焯菜、煮汤 |
| 电饭煲 | 米饭、粥、简单炖煮 | 米饭、白粥       |

## 先建立的判断

- 要翻炒就优先炒锅。
- 要大量水或焯水就优先汤锅。
- 主食稳定最省心的是电饭煲。
