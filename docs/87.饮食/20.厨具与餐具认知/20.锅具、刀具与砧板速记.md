# 锅具、刀具与砧板速记

## 快速看懂

- 锅决定做法，刀决定切配效率，砧板决定卫生边界。
- 入门时先把这三类用稳，比买更多工具重要。

## 三类核心工具

| 工具 | 先记什么                       | 最常见误区               |
| ---- | ------------------------------ | ------------------------ |
| 锅具 | 炒锅做多数热菜，汤锅做汤面焯水 | 锅太小，翻炒和焯水都不顺 |
| 刀具 | 菜刀先满足切丝切片切块         | 追求太多刀型，反而不会用 |
| 砧板 | 至少分出生食板和熟食/水果板    | 一块板长期什么都切       |

## 先建立的使用原则

- 锅大小先匹配家庭分量，不求多。
- 刀先求顺手和基础维护，不求型号齐全。
- 砧板先解决生熟分开，再考虑材质和尺寸。

## 最小示例

```text
一口炒锅 + 一口汤锅 + 一把菜刀 + 两块砧板
= 多数家常做饭场景的核心组合
```
