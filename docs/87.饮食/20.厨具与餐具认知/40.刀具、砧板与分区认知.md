# 刀具、砧板与分区认知

## 快速看懂

- 刀具决定切配效率，砧板决定卫生边界。
- 入门时先解决“能切”和“别混用”，比研究刀法更重要。

## 最小分区

| 对象      | 更稳妥的做法               |
| --------- | -------------------------- |
| 生肉      | 单独砧板或明确分区         |
| 熟食/水果 | 单独砧板或明确分区         |
| 刀具      | 切完生肉及时清洗再处理熟食 |

## 最常见误区

- 一块板长期切所有东西。
- 生肉切完不洗刀就继续切熟食。
- 只记得买刀，不记得安排分区。
