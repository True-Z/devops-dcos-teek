## 学习路径

1. 先搞清楚做饭最常用的厨具和基础调料。
2. 再建立对常见食材和处理方式的最小认识。
3. 最后按川菜常见思路练下锅顺序、火候和成菜节奏。

## 最小理解示例

```text
认厨具 -> 认调料 -> 认食材 -> 学下锅顺序 -> 练几道家常菜
```
