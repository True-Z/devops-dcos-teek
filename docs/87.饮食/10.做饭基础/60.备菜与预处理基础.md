# 备菜与预处理基础

## 阅读建议

- 这页重点不是讲刀工炫技，而是把下厨前最影响成败的备菜和预处理顺一遍。
- 很多菜做得乱，不是不会炒，而是没切好、没分装、没提前把调料准备好。

## 核心目标

- 先建立最小顺序：洗、切、分装、腌、备调料，再开火。

## 备菜最小顺序

| 步骤 | 主要动作         | 关键点                   |
| ---- | ---------------- | ------------------------ |
| 1    | 先想做什么菜     | 决定哪些主料和配料要准备 |
| 2    | 清洗食材         | 肉菜分开处理             |
| 3    | 切配分类         | 主料、配菜、提香料分开   |
| 4    | 提前调好常用小料 | 盐、生抽、料酒可先装小碗 |
| 5    | 需要的话先腌制   | 肉类短时间抓匀更容易入味 |
| 6    | 最后再开火       | 下锅时不容易手忙脚乱     |

## 常见预处理示例

| 食材      | 常见预处理           | 作用                   |
| --------- | -------------------- | ---------------------- |
| 猪肉/鸡肉 | 切好后加少量料酒和盐 | 减腥、提前入底味       |
| 土豆丝    | 切后泡水             | 减少表面淀粉，更不易糊 |
| 豆腐      | 切块后轻放           | 下锅时更不容易碎       |
| 青椒蒜苗  | 提前切好分开放       | 快炒时下锅更顺手       |
| 葱姜蒜    | 单独放一小堆         | 爆香阶段直接就能拿     |

## 最常见的失误

- 一边切菜一边开火，锅热了人还在找调料。
- 葱姜蒜和主料混在一起，爆香时不好分。
- 肉类没简单预处理，直接下锅容易腥、容易柴。
- 不提前想好顺序，导致熟得快的配菜放早了。

## 最小示例

```text
做饭前先把台面分成三堆：
主料 + 配菜 + 调料
```
