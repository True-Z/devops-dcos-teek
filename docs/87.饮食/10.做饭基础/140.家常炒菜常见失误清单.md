# 家常炒菜常见失误清单

## 阅读建议

- 这页重点不是增加新菜，而是把做饭入门时最常见、最容易反复犯的坑集中整理出来。
- 很多问题只要知道原因，下次就能少踩一半。

## 核心目标

- 先建立最小复盘思路：炒出来不好吃时，优先从备菜、火候、下锅顺序、调味量这几件事检查。

## 最常见的失误

| 失误             | 常见结果             | 更稳的改法               |
| ---------------- | -------------------- | ------------------------ |
| 没备菜就开火     | 手忙脚乱，容易糊锅   | 先切好再开火             |
| 锅不够热就下料   | 容易粘锅、出水       | 先热锅再下油             |
| 一次放太多食材   | 锅温掉得快，容易闷熟 | 分量控制好，必要时分两次 |
| 调味一开始就过重 | 后面没法补救         | 先轻后重，边尝边调       |
| 配菜顺序不分先后 | 有的太老，有的还偏生 | 熟得慢的先下，快熟的后下 |
| 起锅太晚         | 青椒蒜苗这类失去脆感 | 断生或合适时就出锅       |

## 遇到问题先怎么排查

| 现象   | 优先怀疑什么             |
| ------ | ------------------------ |
| 太淡   | 调味少或出水过多         |
| 太咸   | 前面下手太重、没留余地   |
| 太柴   | 肉没腌、火候太猛或炒太久 |
| 太湿   | 食材太多或火不够、没收汁 |
| 有苦味 | 豆瓣、蒜、辣椒炒糊了     |

## 最小示例

```text
炒菜翻车先看四件事：
备菜有没有做好、锅够不够热、顺序对不对、调味是不是过重
```
