# 焯水与腌制基础

## 阅读建议

- 这页重点不是讲专业厨房技法，而是先分清哪些食材适合先焯水，哪些更适合先腌一下再下锅。
- 很多菜发腥、发柴、出水多，问题往往出在下锅前没做这一步。

## 核心目标

- 先建立最小判断：去腥去杂味常想到焯水，提前入味和嫩一点常想到腌制。

## 哪些情况常需要焯水

| 食材/场景      | 为什么焯水   | 常见好处           |
| -------------- | ------------ | ------------------ |
| 猪肉块         | 去血沫和杂味 | 后续炖煮味道更干净 |
| 排骨           | 去腥、去浮沫 | 汤和烧菜更清爽     |
| 豆腐           | 轻焯后更定型 | 不容易碎           |
| 叶菜/西兰花    | 先断生       | 颜色更稳，后炒更快 |
| 木耳等泡发食材 | 简单过水     | 口感更稳定         |

## 哪些情况常需要腌制

| 食材     | 常见腌法             | 主要作用             |
| -------- | -------------------- | -------------------- |
| 肉丝肉片 | 少量盐 + 料酒 + 生抽 | 提前入味、减轻腥味   |
| 鸡腿肉   | 盐 + 料酒 + 姜片     | 更嫩，更容易吃进味道 |
| 鱼片     | 少量盐和料酒短时处理 | 去腥、稳住口感       |
| 炸前食材 | 先做基础调味         | 下锅后更容易有底味   |

## 最小顺序

| 场景   | 更稳妥的顺序                     |
| ------ | -------------------------------- |
| 炖肉   | 冷水下锅焯水 -> 捞出冲净 -> 再炖 |
| 炒肉   | 先切好 -> 简单腌几分钟 -> 再下锅 |
| 炒蔬菜 | 需要断生的先焯 -> 再快炒或凉拌   |

## 常见失误

- 焯水时间太久，把食材煮老了。
- 腌制放太多调料，后面正式调味失去空间。
- 所有肉都不处理直接下锅，腥味和出水都重。
- 叶菜类不分情况全焯，反而失去脆感。

## 最小示例

```text
焯水偏向处理杂味和口感，
腌制偏向提前入味和改善下锅状态。
```
