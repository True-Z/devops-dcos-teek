# 常用厨具一览

## 快速看懂

- 入门先认 5 样：炒锅、菜刀、砧板、锅铲、汤锅。
- 原则只有两个：工具够用即可，生熟分开优先。

## 最小配置

| 厨具 | 作用       | 优先级 |
| ---- | ---------- | ------ |
| 炒锅 | 做多数热菜 | 高     |
| 菜刀 | 基础切配   | 高     |
| 砧板 | 放食材切配 | 高     |
| 锅铲 | 翻炒出锅   | 高     |
| 汤锅 | 汤面焯水   | 中     |

## 先记住什么

- 锅看大小是否适合家庭分量。
- 刀和板先解决“能切”和“别混用”。
- 复杂型号先不管，先会认、会选、会分用途。
