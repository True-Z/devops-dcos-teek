# 一周家常做饭模板

## 阅读建议

- 这页不是固定食谱，而是给入门做饭的人一个能直接套用的一周安排思路。
- 目标不是每天做很复杂，而是让买菜、备菜、下厨和剩余食材利用更顺。

## 核心目标

- 先建立最小框架：一周里轮换猪肉、鸡蛋、豆腐、蔬菜和汤面，减少重复想吃什么的成本。

## 一周最小模板

| 天数 | 主体思路           | 示例搭配               |
| ---- | ------------------ | ---------------------- |
| 周一 | 快手开周           | 青椒肉丝 + 米饭        |
| 周二 | 鸡蛋搭蔬菜         | 番茄炒蛋 + 清炒青菜    |
| 周三 | 豆腐类下饭菜       | 麻婆豆腐 + 凉拌黄瓜    |
| 周四 | 用掉前几天剩余配菜 | 蒜苗炒肉片或家常小炒   |
| 周五 | 稍微重口一点       | 回锅肉 + 素菜          |
| 周六 | 面/粉/汤类换口味   | 鸡蛋青菜面             |
| 周日 | 简单收尾和补货准备 | 土豆烧鸡块或清冰箱小炒 |

## 买菜怎么配更省事

| 类别   | 一周可优先准备         |
| ------ | ---------------------- |
| 肉类   | 猪肉、鸡腿或鸡胸       |
| 蛋白类 | 鸡蛋、豆腐             |
| 蔬菜   | 青椒、番茄、土豆、叶菜 |
| 提香类 | 葱姜蒜、蒜苗           |
| 主食   | 米、面条               |

## 使用模板时的思路

- 前半周先吃更容易坏的叶菜、豆腐、切开的配菜。
- 中后段多安排能消耗库存的小炒、面、汤。
- 不追求每天全新菜，只要主料和做法有变化就够了。
- 如果工作日太忙，可以把切配工作集中到周末或前一晚。

## 最小示例

```text
一周家常思路：
2天肉菜 + 2天蛋/豆腐 + 1天重口小炒 + 1天面汤 + 1天清库存
```
