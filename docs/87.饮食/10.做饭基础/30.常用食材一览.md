# 常用食材一览

## 快速看懂

- 入门先记 6 样：猪肉、鸡蛋、豆腐、青椒、番茄、土豆。
- 原则只有两个：先分清主料和配菜，再分清适合炒、煮还是炖。

## 最小分类

| 类别 | 食材             | 常见用途     |
| ---- | ---------------- | ------------ |
| 主料 | 猪肉、鸡蛋、豆腐 | 决定主体口感 |
| 配菜 | 青椒、番茄、土豆 | 增加搭配变化 |

## 先记住什么

- 猪肉、鸡蛋、豆腐是最稳的三类入门主料。
- 青椒、番茄、土豆是最常见的高频配菜。
- 食材先认外观和典型搭配，再记细分做法。

## 最小示例

```text
先认主料和配菜 -> 再记典型搭配 -> 最后回到单菜实操
```
