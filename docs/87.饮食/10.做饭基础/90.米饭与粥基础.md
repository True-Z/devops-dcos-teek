# 米饭与粥基础

## 阅读建议

- 这页不讲复杂米种知识，重点是先把最常见的家常米饭和粥做稳。
- 对做饭入门来说，主食稳定，整顿饭就容易稳很多。

## 核心目标

- 先建立最小判断：平时吃饭先会做正常米饭，肠胃想清淡一点或天气冷时会煮简单粥。

## 米饭最小思路

| 步骤 | 主要动作     | 关键点                         |
| ---- | ------------ | ------------------------------ |
| 1    | 量米         | 先按人数估大概分量             |
| 2    | 淘洗         | 轻洗几遍，别过度搓洗           |
| 3    | 加水         | 想软一点多一点，想硬一点少一点 |
| 4    | 煮熟后焖一会 | 口感更均匀                     |

## 粥最小思路

| 场景   | 常见做法         | 注意点               |
| ------ | ---------------- | -------------------- |
| 白粥   | 米和更多的水同煮 | 比米饭更看时间和水量 |
| 蔬菜粥 | 粥快好时加切碎菜 | 叶菜别太早下         |
| 鸡蛋粥 | 起锅前打蛋花     | 先把粥滚起来再下     |

## 最常见问题

| 问题     | 常见原因             |
| -------- | -------------------- |
| 米饭太硬 | 水偏少，焖得不够     |
| 米饭太黏 | 水偏多，或米本身较软 |
| 粥太稠   | 水不够或煮得太久     |
| 粥太稀   | 米偏少或后期没收一点 |

## 最小示例

```text
家常主食最小组合：
工作日主打米饭，想清淡或不舒服时煮简单粥。
```
