# 炖煮与收汁基础

## 阅读建议

- 这页重点不是教复杂红烧，而是先理解家常炖煮和收汁时最常见的节奏。
- 很多菜不是味道不对，而是火候乱、汤汁多少没控制好，最后不是太淡就是太干。

## 核心目标

- 先建立最小判断：想吃软一点、入味一点时偏炖煮；想让味道集中、挂在食材表面时偏收汁。

## 炖煮最小思路

| 步骤 | 主要动作       | 关键点                   |
| ---- | -------------- | ------------------------ |
| 1    | 先处理主料     | 需要的话先焯水或先煸炒   |
| 2    | 下基础调味     | 盐、生抽、料酒分步放更稳 |
| 3    | 加适量水开始煮 | 别一上来加过多           |
| 4    | 中小火慢煮     | 给食材时间入味           |
| 5    | 看情况收一点汁 | 让味道更集中             |

## 什么时候收汁

| 场景       | 为什么收汁             |
| ---------- | ---------------------- |
| 红烧类     | 汁更浓，颜色和味道更稳 |
| 土豆烧肉   | 味道更挂在主料上       |
| 豆腐类     | 汤别太多，口感更完整   |
| 家常小炖菜 | 不至于变成一锅清汤     |

## 最常见失误

- 火一直太大，外面干了里面还没进味。
- 水放太多，后面收太久，食材口感变差。
- 还没煮透就急着收汁，容易表面重口、里面没味。
- 想收汁却不停翻动，容易把豆腐土豆这类食材翻碎。

## 最小示例

```text
炖煮看“入味”，收汁看“集中味道”。
先煮到位，再决定收多少汁。
```
