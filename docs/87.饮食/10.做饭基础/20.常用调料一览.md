# 常用调料一览

## 快速看懂

- 入门先记 6 样：盐、生抽、老抽、料酒、醋、豆瓣。
- 原则只有两个：先分清“提鲜还是上色”，再分清“前段放还是后段放”。

## 最小配置

| 调料     | 核心作用 | 记忆点 |
| -------- | -------- | ------ |
| 盐       | 定基础味 | 最基础 |
| 生抽     | 提鲜增咸 | 常用   |
| 老抽     | 上色     | 少量   |
| 料酒     | 去腥     | 前段   |
| 醋       | 提酸收口 | 后段   |
| 郫县豆瓣 | 川菜底味 | 爆香   |

## 先记住什么

- 生抽不是老抽，前者提鲜，后者上色。
- 豆瓣、蒜、辣椒都怕炒糊。
- 调味先轻后重，别一开始就放死。

## 最小示例

```text
先认调料长什么样 -> 再记偏什么味 -> 最后记什么时候放
```
