# 工作日省时做饭流程

## 阅读建议

- 这页重点不是做很多菜，而是帮助你在下班后尽量少耗神地做出一顿正常饭。
- 省时做饭的关键不是速度多快，而是减少来回找东西、边做边想的损耗。

## 核心目标

- 先建立最小流程：提前想好菜单，能前置的前置，回家后按固定顺序做。

## 更省时的做饭顺序

| 阶段        | 主要动作                 | 为什么这样做         |
| ----------- | ------------------------ | -------------------- |
| 开始前      | 先决定吃什么             | 避免站在厨房里临时想 |
| 前一晚/周末 | 能切的先切，能分装先分装 | 减少工作日切配时间   |
| 回家后      | 先煮饭/烧水              | 让主食先并行进行     |
| 同步处理    | 再做爆香和主菜           | 利用主食等待时间     |
| 收尾        | 最后快速炒蔬菜或煮汤面   | 保持口感，也减少拖延 |

## 最适合工作日的准备

| 可前置内容   | 例子               |
| ------------ | ------------------ |
| 食材分装     | 肉丝分袋、青椒切好 |
| 调料预估     | 常用小料提前放小盒 |
| 菜单固定模板 | 2-3 套高频晚饭组合 |
| 冰箱顺序     | 常用食材放显眼位置 |

## 工作日晚饭模板

| 时间状态 | 更适合做什么        |
| -------- | ------------------- |
| 很累     | 汤面、粥、番茄炒蛋  |
| 正常状态 | 一个肉菜 + 一个素菜 |
| 稍有余力 | 小炒 + 汤或面       |

## 最小示例

```text
工作日做饭最小顺序：
先决定菜单 -> 回家先煮饭/烧水 -> 再炒主菜 -> 最后补蔬菜
```
