# 凉拌菜基础

## 阅读建议

- 这页重点不是做很多复杂凉菜，而是先掌握最常见的家常凉拌思路。
- 凉拌菜看着简单，但口感和味道很依赖处理顺序、沥水和调味比例。

## 核心目标

- 先建立最小框架：食材处理干净、该焯水的先焯、沥干水分、最后再拌调味。

## 最常见的凉拌食材

| 食材      | 常见处理           | 注意点               |
| --------- | ------------------ | -------------------- |
| 黄瓜      | 拍开或切条         | 出水快，别太早拌盐   |
| 木耳      | 泡发后焯水         | 沥干再拌更稳         |
| 豆腐丝    | 直接拌或轻焯       | 本身有味，调味别太重 |
| 菠菜/生菜 | 视情况焯水或直接拌 | 焯后要挤去多余水分   |
| 土豆丝    | 切丝后焯断生       | 保留一点脆感更好     |

## 最小调味思路

| 味道方向 | 常见组合                |
| -------- | ----------------------- |
| 基础咸鲜 | 盐 + 生抽 + 蒜末        |
| 酸辣开胃 | 醋 + 辣椒 + 盐 + 少量糖 |
| 麻辣一点 | 花椒油/花椒 + 辣椒 + 蒜 |

## 最常见失误

- 食材带太多水直接拌，味道会被冲淡。
- 早早拌好放太久，黄瓜、叶菜容易出水变软。
- 蒜、醋、辣椒一口气放很重，后面没法调整。
- 该焯水的食材直接生拌，口感和安全性都一般。

## 最小示例

```text
凉拌菜最小顺序：
处理食材 -> 沥干 -> 调一个基础汁 -> 拌匀后再试味
```
