# 汤面与快手菜模板

## 阅读建议

- 这页重点是给忙的时候一个可重复的最小做饭模板，不追求复杂，就是要快、稳、能吃。
- 当你没空做正式几道菜时，汤面和快手菜最适合兜底。

## 核心目标

- 先建立最小框架：主食 + 蛋白 + 一点蔬菜 + 基础调味，就能做出一顿简单饭。

## 汤面最小模板

| 组成 | 常见选择             | 作用             |
| ---- | -------------------- | ---------------- |
| 主食 | 面条                 | 顶饱             |
| 蛋白 | 鸡蛋、肉末           | 补充口感和满足感 |
| 蔬菜 | 青菜、番茄、葱花     | 不至于只有碳水   |
| 调味 | 盐、生抽、胡椒、香油 | 味道更完整       |

## 快手菜最小模板

| 类型     | 示例                  | 关键点             |
| -------- | --------------------- | ------------------ |
| 蛋类     | 番茄炒蛋              | 先把蛋炒散再回锅   |
| 肉菜快炒 | 青椒肉丝              | 主料和配菜提前切好 |
| 豆腐类   | 家常豆腐/麻婆豆腐简版 | 豆腐轻推，别猛翻   |
| 清炒蔬菜 | 蒜蓉青菜              | 火快一点，别炒太老 |

## 忙的时候怎么选

- 只有十几分钟：优先汤面或番茄炒蛋这类快手菜。
- 有一点剩肉剩菜：优先做炒面、小炒或清冰箱汤面。
- 很累但想吃热的：优先鸡蛋青菜面或简单粥。

## 最小示例

```text
忙时做饭最小公式：
面条/米饭 + 鸡蛋/肉末 + 一种蔬菜 + 基础调味
```
