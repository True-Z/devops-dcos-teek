# 川菜入门与实际操作

## 快速看懂

- 川菜入门先抓住 4 个动作：备菜、爆香、下主料、调味收汁。
- 真正练手不要只看这页，直接去单菜页做会更快。

## 最小顺序

| 步骤 | 记忆点               |
| ---- | -------------------- |
| 1    | 先备菜               |
| 2    | 热锅下油             |
| 3    | 豆瓣葱姜蒜先爆香     |
| 4    | 下主料再调味         |
| 5    | 看情况收汁或直接出锅 |
