# 冰箱存放与食材保鲜基础

## 阅读建议

- 这页不追求冰箱收纳美学，重点是先把常见食材怎么放、更不容易串味和放坏理顺。
- 很多食材坏得快，不是因为买得多，而是热着就塞进去、熟生混放、忘了先后顺序。

## 核心目标

- 先建立最小判断：生熟分开、密封防串味、先买先吃、冷藏和冷冻别混用。

## 最常见的存放原则

| 原则         | 怎么做                 | 为什么重要           |
| ------------ | ---------------------- | -------------------- |
| 生熟分开     | 生肉和熟食分层或分盒放 | 减少交叉污染         |
| 密封存放     | 盒装或袋装再入冰箱     | 防串味，也更整洁     |
| 先买先吃     | 新买放后面，旧的放前面 | 减少遗忘和浪费       |
| 热食放温再收 | 别刚出锅就直接塞冰箱   | 对食物和冰箱都更稳   |
| 按期限贴标签 | 肉类、剩菜可标日期     | 不靠猜测判断存放时间 |

## 常见食材怎么放

| 食材   | 更合适的方式          | 注意点               |
| ------ | --------------------- | -------------------- |
| 生肉   | 分份装袋冷藏或冷冻    | 一次一份，解冻更方便 |
| 剩菜   | 放凉后密封冷藏        | 尽量别长时间反复加热 |
| 叶菜   | 擦干表面水分再冷藏    | 太湿更容易烂         |
| 葱姜蒜 | 视使用频率分常温/冷藏 | 切开的更要包好       |
| 豆腐   | 短期内尽快吃          | 开封后更别拖太久     |
| 鸡蛋   | 保持稳定放置          | 别频繁拿进拿出       |

## 最小示例

```text
冰箱最小思路：
生熟分开 + 盒袋密封 + 先买先吃 + 放前看日期
```
