# 做饭常识与厨房规则

## 快速看懂

- 规则只先记 4 条：生熟分开、刀板分开、容器分开、做完就洗。

## 最小规则

| 规则             | 为什么                 |
| ---------------- | ---------------------- |
| 生板熟板别混用   | 避免交叉污染           |
| 生肉熟菜别混放   | 避免污染成品           |
| 生料盘熟菜盘别混 | 出锅菜不要回碰生料容器 |
| 试味勺别回锅     | 避免重复污染           |

## 最容易踩坑的地方

- 切完生肉的刀板没洗就切熟食。
- 出锅直接装到之前放生肉的盘里。
- 一双筷子全程做饭、夹生料、入口试味。
- 抹布和海绵用太久，不换不洗。

## 最小示例

```text
先把厨房规则守住，再谈味道和菜谱细节。
```
