# 木耳炒蛋

## 菜品介绍

![木耳炒蛋成菜示意](./木耳炒蛋.assets/cover.svg)

- 鸡蛋香软、木耳脆爽，属于非常稳的家常快炒组合。

## 适合季节

- 春、夏、秋

## 主菜分类

- 豆腐蛋类

## 材料（1人份）

### 主料

- [鸡蛋](/diet-tofu-egg-guide) 3个
- [木耳](/diet-vegetable-ingredient-guide) 25g（干木耳，泡发后约120g）

### 辅料

- [青椒](/diet-vegetable-ingredient-guide) 50g
- [蒜](/diet-seasoning-visual-guide) 6g

### 调料

- [盐](/diet-basic-seasoning-guide) 2g
- [生抽](/diet-basic-seasoning-guide) 5ml

## 做法

![木耳炒蛋流程示意](./木耳炒蛋.assets/steps.svg)

1. 木耳提前泡发后焯水，鸡蛋打散，青椒切片，蒜切末。
2. 先把鸡蛋炒成块，盛出。
3. 锅中炒蒜末和青椒，再下木耳翻炒。
4. 倒回鸡蛋，加盐和 3ml 生抽翻匀后出锅。

## 关键要点

- 木耳先泡发并焯水，口感更稳。
- 鸡蛋先炒出来，避免和木耳一起久炒变老。
