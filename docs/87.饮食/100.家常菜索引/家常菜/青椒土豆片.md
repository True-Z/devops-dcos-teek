# 青椒土豆片

## 菜品介绍

![青椒土豆片成菜示意](./青椒土豆片.assets/cover.svg)

- 食材常见、做法简单，适合练切片和快炒的顺序感。

## 适合季节

- 夏、秋

## 主菜分类

- 素菜

## 材料（1人份）

### 主料

- [土豆](/diet-vegetable-ingredient-guide) 220g
- [青椒](/diet-vegetable-ingredient-guide) 100g

### 辅料

- [蒜](/diet-seasoning-visual-guide) 8g

### 调料

- [盐](/diet-basic-seasoning-guide) 2g
- [生抽](/diet-basic-seasoning-guide) 4ml
- [醋](/diet-basic-seasoning-guide) 4ml

## 做法

![青椒土豆片流程示意](./青椒土豆片.assets/steps.svg)

1. 土豆切薄片后泡水，青椒切片，蒜切片。
2. 热锅下油，先炒蒜片。
3. 下土豆片翻炒，必要时加 20ml 水。
4. 下青椒片，加盐、生抽和 4ml 醋，炒匀出锅。

## 关键要点

- 土豆片别切太厚，不然熟得慢。
- 青椒后下，保持颜色和口感。
