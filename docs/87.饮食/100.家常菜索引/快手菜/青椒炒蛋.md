# 青椒炒蛋

## 菜品介绍

![青椒炒蛋成菜示意](./青椒炒蛋.assets/cover.svg)

- 很适合工作日晚饭的快手菜，食材少、步骤短、容错高。

## 适合季节

- 夏、秋

## 主菜分类

- 豆腐蛋类

## 材料（1人份）

### 主料

- [鸡蛋](/diet-tofu-egg-guide) 3个
- [青椒](/diet-vegetable-ingredient-guide) 2个（约120g）

### 辅料

- [蒜](/diet-seasoning-visual-guide) 6g

### 调料

- [盐](/diet-basic-seasoning-guide) 2g
- [生抽](/diet-basic-seasoning-guide) 5ml

## 做法

![青椒炒蛋流程示意](./青椒炒蛋.assets/steps.svg)

1. 鸡蛋打散，青椒切丝，蒜切末。
2. 先把鸡蛋炒到凝固成块，盛出。
3. 锅中下蒜末和青椒丝快速翻炒。
4. 倒回鸡蛋，加盐和 3ml 生抽翻匀，断生后出锅。

## 关键要点

- 蛋先炒出来，口感更完整。
- 青椒别炒太老，保留一点脆感更好吃。
