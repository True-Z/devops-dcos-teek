# 蒜蓉青菜

## 菜品介绍

![蒜蓉青菜成菜示意](./蒜蓉青菜.assets/cover.svg)

- 这是最典型的补一道素菜思路，适合练“爆香 -> 断生 -> 立刻出锅”。

## 适合季节

- 春、夏

## 主菜分类

- 素菜

## 材料（1人份）

### 主料

- [叶菜](/diet-vegetable-ingredient-guide) 220g

### 辅料

- [蒜](/diet-seasoning-visual-guide) 10g

### 调料

- [盐](/diet-basic-seasoning-guide) 2g
- [生抽](/diet-basic-seasoning-guide) 3ml

## 做法

![蒜蓉青菜流程示意](./蒜蓉青菜.assets/steps.svg)

1. 青菜洗净沥水，蒜切末。
2. 热锅下油，先下蒜末炒香。
3. 下青菜快速翻炒到变软。
4. 用盐和 3ml 生抽调味，断生后马上出锅。

## 关键要点

- 青菜要沥水，不然容易变成焖菜。
- 断生就出锅，颜色和口感更好。
