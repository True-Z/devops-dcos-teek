# 蔬菜认知

## 快速看懂

- 入门先抓高频配菜，不要一开始买太杂。
- 青椒、番茄、土豆、叶菜是最常用的几类。

## 常见分类

| 食材 | 常见做法   | 高频菜             |
| ---- | ---------- | ------------------ |
| 青椒 | 快炒、配菜 | 青椒肉丝、青椒炒蛋 |
| 番茄 | 炒、汤、面 | 番茄炒蛋、汤面     |
| 土豆 | 丝、块、炖 | 土豆丝、土豆烧鸡块 |
| 叶菜 | 清炒、蒜蓉 | 蒜蓉青菜           |
