# 豆制品与蛋类认知

## 快速看懂

- 鸡蛋和豆腐是最稳的入门主料。
- 这两类食材便宜、高频、容易练基础手感。

## 常见分类

| 食材 | 常见做法         | 高频菜             |
| ---- | ---------------- | ------------------ |
| 鸡蛋 | 炒、蒸、煮、汤   | 番茄炒蛋、青椒炒蛋 |
| 豆腐 | 烧、炖、煮、收汁 | 麻婆豆腐、家常豆腐 |
