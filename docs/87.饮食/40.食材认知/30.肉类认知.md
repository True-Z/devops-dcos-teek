# 肉类认知

## 快速看懂

- 入门最常做的是猪肉和鸡肉。
- 肉类先分切丝快炒、切块炖煮两种思路。

## 常见分类

| 食材      | 常见做法           | 高频菜               |
| --------- | ------------------ | -------------------- |
| 猪肉      | 切丝、切片、回锅   | 青椒肉丝、回锅肉     |
| 鸡腿/鸡胸 | 切丁、切块、煎炒炖 | 宫保鸡丁、土豆烧鸡块 |
