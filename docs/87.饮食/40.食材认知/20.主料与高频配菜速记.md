# 主料与高频配菜速记

## 快速看懂

- 学食材时先分主料和配菜，不要一上来记很杂的买菜清单。
- 入门做饭能反复练的组合，其实就集中在几类高频搭配上。

## 最小组合

| 主料 | 高频配菜         | 常见结果           |
| ---- | ---------------- | ------------------ |
| 猪肉 | 青椒、蒜苗、豆瓣 | 青椒肉丝、回锅肉   |
| 鸡蛋 | 番茄、青椒       | 番茄炒蛋、青椒炒蛋 |
| 豆腐 | 肉末、豆瓣、花椒 | 麻婆豆腐、家常豆腐 |
| 土豆 | 青椒、鸡肉       | 土豆丝、土豆烧鸡   |

## 先建立的判断

- 主料决定这道菜主体。
- 配菜负责口感、颜色和变化。
- 不熟的食材不要一次买太多，先从高频组合练。

## 最小示例

```text
主料先抓 猪肉/鸡蛋/豆腐，
配菜先抓 青椒/番茄/土豆。
```
