# 厨房计量估算

## 阅读建议

- 这页按家常做饭的近似值来写，目标是帮你快速下手，不是做精密实验。
- 不同勺子、碗、食材大小会有误差，所以第一次先按这里做，后面按口味微调。

## 常见口语计量

### 一小勺

![teaspoon](./10.厨房计量估算.assets/teaspoon.svg)

- 常见理解：家里小勺一勺，约 `5ml`
- 对粉类：平一小勺盐大约 `4g`，平一小勺糖大约 `4g`

### 一大勺

![tablespoon](./10.厨房计量估算.assets/tablespoon.svg)

- 常见理解：家里吃饭用大勺一勺，约 `15ml`
- 对液体：一大勺生抽、醋、料酒，大多按 `15ml` 记最方便

### 一碗

![bowl](./10.厨房计量估算.assets/bowl.svg)

- 常见理解：普通家用饭碗一碗，约 `250ml` 左右
- 半碗就先按 `120ml` 到 `130ml` 理解

### 一撮

![pinch](./10.厨房计量估算.assets/pinch.svg)

- 常见理解：手指捏起一点点，约 `0.5g` 到 `1g`
- 适合胡椒、盐、花椒粉这类“先少后补”的调味

## 常见调料估算

| 名称      | 家常估算     | 你可以怎么理解           |
| --------- | ------------ | ------------------------ |
| 盐 2g     | 半小勺左右   | 1 人份清淡热菜常见起步量 |
| 糖 3g     | 小半勺到半勺 | 常用于提鲜，不是做甜味   |
| 生抽 5ml  | 1 小勺       | 快炒里很常见             |
| 生抽 10ml | 2 小勺       | 一人份肉菜常见           |
| 料酒 5ml  | 1 小勺       | 腌肉去腥常见             |
| 醋 5ml    | 1 小勺       | 凉拌或收口常见           |
| 醋 8ml    | 1 小勺多一点 | 酸味更明显一点           |
| 油 10ml   | 2 小勺       | 一人份快炒大致起步量     |

## 常见食材估算

| 食材     | 家常估算        | 你可以怎么理解              |
| -------- | --------------- | --------------------------- |
| 1 个鸡蛋 | 约 50g 到 60g   | 3 个鸡蛋就是一盘炒蛋常见量  |
| 1 个青椒 | 约 50g 到 70g   | 2 个青椒大概够一人份配菜    |
| 1 个番茄 | 约 120g 到 180g | 看大小差异会比较明显        |
| 1 瓣蒜   | 约 3g 到 5g     | 6g 蒜大概 1 到 2 瓣偏大的蒜 |
| 1 段葱   | 约 8g 到 10g    | 一段够一人份家常菜提香      |

## 最常用换算口诀

```text
1 小勺约 5ml
1 大勺约 15ml
1 碗约 250ml
盐 2g 先理解成半小勺左右
```

## 使用提醒

- 菜谱里的 `g/ml` 优先级高于口语估算。
- 估算页更适合你在没有电子秤、没有量勺时临时判断。
- 第一次做菜，宁可先轻一点，后面再补，不要一开始就重手。
