## 核心目标

- 区分“用户是谁”和“用户能做什么”。

## 核心概念速查

| 概念                   | 作用           | 常见实现                |
| ---------------------- | -------------- | ----------------------- |
| 认证（Authentication） | 证明用户身份   | 密码登录、验证码、Token |
| 授权（Authorization）  | 控制可访问资源 | 角色、权限、菜单控制    |
| 会话（Session）        | 维持登录状态   | Cookie、Session、JWT    |

## 最小示例

```text
用户登录 -> 服务端校验身份 -> 生成会话/令牌 -> 后续请求携带凭证 -> 服务端校验权限
```

- 认证解决“你是谁”，授权解决“你能做什么”。
