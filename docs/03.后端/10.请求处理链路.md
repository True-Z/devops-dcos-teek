## 核心目标

- 理解一个接口请求进入后端后，通常会经过哪些环节。

## 链路速查

| 阶段     | 作用             | 常见问题               |
| -------- | ---------------- | ---------------------- |
| 路由匹配 | 找到对应处理器   | 路径不匹配、方法不对   |
| 参数校验 | 保证输入可用     | 参数缺失、格式错误     |
| 业务处理 | 执行核心逻辑     | 状态不合法、流程错误   |
| 数据访问 | 读写数据库/缓存  | 查询慢、事务失败       |
| 响应返回 | 输出结果给调用方 | 状态码不合理、结构混乱 |

## 最小示例

```text
请求进来 -> 校验参数 -> 执行业务 -> 读写数据库 -> 返回响应
```

- 这条链路几乎适用于所有后端接口，只是不同框架拆分方式不同。
