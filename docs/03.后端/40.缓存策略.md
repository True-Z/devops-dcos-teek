## 核心目标

- 在保证数据可用的前提下，减少重复计算和重复查询。

## 常见缓存位置

| 位置      | 适合缓存什么           | 注意点                 |
| --------- | ---------------------- | ---------------------- |
| 本地内存  | 热点配置、短时数据     | 多实例间不共享         |
| Redis     | 高频读写、共享缓存     | 需考虑过期与一致性     |
| HTTP 缓存 | 静态资源、接口协商缓存 | 更适合网关或客户端配合 |

## 最小示例

```text
请求进来 -> 先查缓存 -> 命中直接返回 -> 未命中再查数据库并回填缓存
```

- 这是最常见的缓存使用路径，重点是先明确缓存命中策略和失效策略。
