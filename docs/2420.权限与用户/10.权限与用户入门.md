# 权限与用户入门

## 主模型定位

- 主模型：对象层
- 这页主要回答“在处理什么对象，以及这些对象为什么会影响运维操作。”

## 阅读建议

- 这页重点不是背很多命令，而是先理解 Linux 里“谁能看、谁能改、谁能执行”这套规则。

## 核心目标

- 建立最小权限认知：用户、组、文件权限、执行权限这些概念为什么会直接影响开发和运维操作。

## 最小主线

```text
谁在执行 -> 属于哪个用户/组 -> 对文件有没有权限 -> 命令能不能成功
```

## 最常见关注点

| 方向     | 为什么重要               |
| -------- | ------------------------ |
| 用户     | 命令是谁在执行           |
| 用户组   | 同一类权限如何归属       |
| 文件权限 | 能不能读、写、执行       |
| 执行权限 | 脚本为什么存在却跑不起来 |

## 最小示例

```text
脚本存在 -> 没有执行权限 -> 命令失败 -> 补权限后再执行
```

## 学习建议

1. 先理解用户、组、权限三者关系。
2. 先看场景，再记命令。
3. 权限学习最好和文件、服务、部署问题一起练。

## 常见误区

- 看到权限错误只会反复重试，不先看当前用户和权限。
- 不区分读权限、写权限、执行权限。
- 只记 `chmod`，不理解背后权限模型。
