## 核心目标

- 先掌握“看目录、看文件、移动、删除、搜索”这类最高频操作。

## 高频命令速查

| 命令    | 作用         | 常见场景       |
| ------- | ------------ | -------------- |
| `pwd`   | 查看当前目录 | 确认自己在哪   |
| `ls`    | 查看目录内容 | 看文件与子目录 |
| `cd`    | 切换目录     | 进入目标路径   |
| `cp`    | 复制文件     | 备份配置文件   |
| `mv`    | 移动/重命名  | 调整文件位置   |
| `rm`    | 删除文件     | 清理无用文件   |
| `mkdir` | 新建目录     | 搭建目录结构   |

## 最小示例

```sh
pwd
ls
mkdir demo
cd demo
```

- 这 4 条命令已经能覆盖“确认位置 -> 看内容 -> 建目录 -> 进入目录”的基本链路。
