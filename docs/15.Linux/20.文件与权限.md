## 核心目标

- 理解文件为什么“看得见但不能改”、命令为什么“存在但不能执行”。

## 权限速查

| 权限 | 含义 | 常见对象       |
| ---- | ---- | -------------- |
| `r`  | 读   | 查看文件内容   |
| `w`  | 写   | 修改文件       |
| `x`  | 执行 | 执行脚本或程序 |

## 最小示例

```sh
ls -l
chmod +x deploy.sh
./deploy.sh
```

- 这条链路体现了 Linux 文件权限最常见的问题：文件在，但没有执行权限。
