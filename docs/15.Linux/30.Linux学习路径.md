# Linux 学习路径

## 阅读建议

- 这页以开发者入门 Linux 为目标，优先解决“看得懂、会操作、能排查”。

## 核心目标

- 帮你把 Linux 学习拆成可执行的几个阶段，而不是一上来背大量零散命令。

## 推荐顺序

1. 目录与路径认知。
2. 常用命令与文件操作。
3. 权限、用户和组。
4. 进程、服务和日志。
5. 网络与部署基础。

## 最小示例

```text
pwd -> ls -> cat -> grep -> chmod -> ps -> systemctl -> tail
```

## 学习建议

- 每学一个命令，都配一个真实场景。
- 命令学习和日志、服务、权限问题一起练效果最好。
- 先求会用，再慢慢理解底层细节。

## 常见误区

- 只记命令参数，不记使用场景。
- 只看教程，不自己在命令行里执行。
- 一上来就钻高级网络或内核内容。
