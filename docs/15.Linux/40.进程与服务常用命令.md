# Linux 进程与服务常用命令

## 阅读建议

- 这页重点不是把所有命令都背下来，而是先会处理“程序有没有在跑、服务有没有起来”这类高频场景。

## 核心目标

- 先建立进程和服务的基本认知，再掌握查看状态、停止、重启、验证结果这些最常见动作。

## 高频命令速查

| 命令                | 作用             | 常见场景           |
| ------------------- | ---------------- | ------------------ |
| `ps`                | 查看进程         | 判断程序是否在运行 |
| `top`               | 查看实时进程状态 | 看 CPU、内存占用   |
| `kill`              | 结束进程         | 处理异常进程       |
| `systemctl status`  | 查看服务状态     | 判断服务是否正常   |
| `systemctl restart` | 重启服务         | 修改配置后生效     |
| `systemctl stop`    | 停止服务         | 临时停用服务       |
| `systemctl start`   | 启动服务         | 拉起服务           |

## 最小示例

```sh
ps -ef | grep nginx
systemctl status nginx
systemctl restart nginx
```

- 这条链路已经能覆盖“看进程 -> 看服务状态 -> 重启服务”的最小场景。

## 学习建议

1. 先分清“进程”和“服务”不是完全同一个概念。
2. 每执行一次管理命令，都要再做一次状态验证。
3. 命令学习和日志查看一起练，效果最好。

## 常见误区

- 只会 `restart`，不会先看状态。
- 分不清程序进程和 systemd 服务。
- 命令执行完就以为恢复了，不做验证。
