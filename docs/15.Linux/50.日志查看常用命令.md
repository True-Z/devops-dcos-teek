# Linux 日志查看常用命令

## 阅读建议

- 这页先解决“怎么看日志”而不是“怎么看懂所有报错”，重点是先会查、会定位、会抓关键词。

## 核心目标

- 让你在服务异常、启动失败、页面访问报错时，先能用最常见命令定位日志线索。

## 高频命令速查

| 命令         | 作用              | 常见场景             |
| ------------ | ----------------- | -------------------- |
| `cat`        | 直接看文件        | 看小日志文件         |
| `less`       | 分页查看          | 看较长日志           |
| `tail`       | 看文件尾部        | 看最新日志           |
| `tail -f`    | 持续跟踪日志      | 实时看服务输出       |
| `grep`       | 搜索关键词        | 找 `error`、`failed` |
| `journalctl` | 查看 systemd 日志 | 看服务相关系统日志   |

## 最小示例

```sh
tail -f app.log
grep error app.log
journalctl -u nginx
```

- 这组命令已经覆盖“实时看日志、搜关键词、看服务日志”的最小场景。

## 学习建议

1. 先学会看“最新日志”和“错误关键词”。
2. 一看到报错先抓时间、服务名、关键词。
3. 日志命令优先配真实问题场景去练。

## 常见误区

- 一上来就把整份日志全看完，没有先定位时间和关键词。
- 只会 `cat`，不会用 `tail -f` 和 `grep`。
- 看见英文报错就跳过，不抓关键单词。
