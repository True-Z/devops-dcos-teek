# 知识库组织说明

知识库组织说明用于解释这套知识库为什么这样设计、目录如何组织、内容如何判断放置位置。它不是正式知识分类，而是一个讲解型说明组件。进入后建议直接通过左侧栏阅读各页，不需要在当前页反复跳转。

## 这组内容分别解决什么问题

- `整体组织思路`：解释这套知识库为什么这样设计。
- `目录层级设计`：解释一级、二级、三级、四级分别承担什么职责。
- `三层模型与面试视角`：解释认知层、对象层、方法层以及面试视角怎么区分。
- `文件编写方式`：解释目录页、简介页、正文页怎么分工。

## 推荐阅读顺序

1. 先看“整体组织思路”，建立全局认识。
2. 再看“目录层级设计”，理解目录结构如何落地。
3. 再看“三层模型与面试视角”，理解内容组织的基础框架。
4. 最后看“文件编写方式”，理解目录页、简介页、正文页如何分工。
