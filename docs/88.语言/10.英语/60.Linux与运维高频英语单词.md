# Linux 与运维高频英语单词

## 阅读建议

- 这页优先解决你看 Linux 命令说明、日志、部署资料时最常见的词汇障碍。

## 核心目标

- 先掌握系统、文件、权限、服务、日志这些高频词，降低后续 Linux 学习门槛。

## 高频词表

| 单词         | 中文   | 最小示例           |
| ------------ | ------ | ------------------ |
| `file`       | 文件   | `Open the file`    |
| `directory`  | 目录   | `Create directory` |
| `permission` | 权限   | `Check permission` |
| `user`       | 用户   | `Add user`         |
| `group`      | 用户组 | `User group`       |
| `service`    | 服务   | `Restart service`  |
| `process`    | 进程   | `Kill process`     |
| `log`        | 日志   | `View log`         |
| `network`    | 网络   | `Network issue`    |
| `deploy`     | 部署   | `Deploy app`       |

## 最小示例

```text
Check file permission.
Restart the service.
View the log.
```

## 学习建议

- 先学你在 Linux 命令和教程里一定会遇到的词。
- 单词学习和命令学习一起进行，效果最好。
- 看不懂整句时，先抓关键词，不要求第一遍全部翻译准确。

## 常见误区

- 先背太多复杂运维术语，忽略基础词。
- 只背单词，不结合命令和场景。
- 过于追求完整语法，反而拖慢入门速度。
