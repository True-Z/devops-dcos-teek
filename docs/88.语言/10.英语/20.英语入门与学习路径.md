# 英语入门与学习路径

## 阅读建议

- 这页以“能看懂前端文档和后续 Linux 学习资料”为目标，不走传统考试路线。

## 核心目标

- 先补最基础语法和发音，再积累编程与 Linux 高频词，优先解决“能看、能查、能猜”。

## 推荐学习顺序

1. 先看人称代词与 `be` 动词。
2. 再看英式音标，解决基本发音和查词问题。
3. 接着补前端高频词。
4. 最后补 Linux 与运维高频词。

## 最小学习链路

```text
基础代词 -> 基本句型 -> 英式音标 -> 编程词汇 -> Linux 词汇
```

## 为什么这样排

- 代词和 `be` 动词是最基础句型入口。
- 音标能帮助你查词和记词。
- 词汇学习要贴近真实目标，优先学你马上会看到的文档词汇。

## 常见误区

- 一开始就背大量单词，不补基础句型。
- 只看中文意思，不看发音和最小例句。
- 学太宽，和前端/Linux 场景脱节。
