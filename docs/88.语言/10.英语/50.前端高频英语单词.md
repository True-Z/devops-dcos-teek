# 前端高频英语单词

## 阅读建议

- 这页只收前端文档里最常见、最值得优先认识的基础词。

## 核心目标

- 让你在看前端文档、报错信息、接口说明时，先能认出高频词的大致含义。

## 高频词表

| 单词        | 中文     | 最小示例              |
| ----------- | -------- | --------------------- |
| `component` | 组件     | `Base component`      |
| `props`     | 属性参数 | `Pass props to child` |
| `state`     | 状态     | `Update state`        |
| `render`    | 渲染     | `Render the page`     |
| `event`     | 事件     | `Click event`         |
| `router`    | 路由     | `Router config`       |
| `build`     | 构建     | `Build success`       |
| `deploy`    | 部署     | `Deploy to server`    |

## 学习建议

- 每次先记 5 到 10 个高频词。
- 看文档时尽量直接认英文，不先在脑中翻译成长句。
- 配合你的真实前端学习内容反复出现，记得更快。

## 常见误区

- 背很多低频词，忽略最常见高频词。
- 只背中文意思，不看最小使用语境。
- 学单词和真实项目、真实报错脱节。
