# 英式音标速记

## 阅读建议

- 这页目标不是学完整语音学，而是让你查词时能大概读出来、能帮助记单词。

## 核心目标

- 先认识常见英式音标和最小发音示例，服务于前端和 Linux 学习中的查词需求。

## 常见元音速记

| 音标   | 示例词 | 提示         |
| ------ | ------ | ------------ |
| `/i:/` | `she`  | 长音“衣”     |
| `/i/`  | `it`   | 短音         |
| `/e/`  | `bed`  | 类似“诶”     |
| `/ae/` | `cat`  | 张口更大     |
| `/u:/` | `food` | 长音“乌”     |
| `/ʌ/`  | `cut`  | 短促 central |

## 常见辅音速记

| 音标  | 示例词 | 提示       |
| ----- | ------ | ---------- |
| `/p/` | `page` | 清辅音     |
| `/b/` | `book` | 浊辅音     |
| `/t/` | `time` | 常见高频   |
| `/d/` | `day`  | 常见高频   |
| `/k/` | `code` | 编程常见词 |
| `/g/` | `git`  | 开发高频词 |

## 最小示例

```text
file /fail/
code /kəud/
server /ˈsɜːvə/
```

## 学习建议

- 查词时先看音标，再看例句。
- 先掌握高频开发词，不追求一次学全。
- 同一个单词优先做到“看见能大致读出”。

## 常见误区

- 只记中文近似发音，不看音标。
- 一开始就想学全全部音标细节。
- 把音标学习和单词场景割裂开。
