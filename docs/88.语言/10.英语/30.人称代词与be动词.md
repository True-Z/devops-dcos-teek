# 英语人称代词与 be 动词

## 阅读建议

- 这页只解决最基础的入门句型，让你先看懂最简单的英文表达。

## 核心目标

- 理解 `I / you / he / she / it / we / they` 和 `am / is / are` 的最基本搭配。

## 人称代词速查

| 中文 | 主格   |
| ---- | ------ |
| 我   | `I`    |
| 你   | `you`  |
| 他   | `he`   |
| 她   | `she`  |
| 它   | `it`   |
| 我们 | `we`   |
| 他们 | `they` |

## be 动词搭配

| 主语          | 搭配  | 示例                |
| ------------- | ----- | ------------------- |
| `I`           | `am`  | `I am a developer.` |
| `he/she/it`   | `is`  | `It is useful.`     |
| `you/we/they` | `are` | `They are ready.`   |

## 最小示例

```text
I am ready.
It is a file.
They are users.
```

## 学习建议

- 先看中文，立刻说出英文主语。
- 再补上正确的 `be` 动词。
- 最后用最简单的名词和形容词造句。

## 常见误区

- 把 `I is`、`he are` 这种基础搭配写错。
- 只背中文意思，不做最小句练习。
- 还没掌握主格，就急着学太多复杂语法。
