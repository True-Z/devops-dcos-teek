## 核心目标

- 理解“程序运行起来后”为什么会出现进程、线程、并发这些概念。

## 对比速查

| 对象 | 核心含义       | 典型特点                 |
| ---- | -------------- | ------------------------ |
| 进程 | 程序运行实例   | 资源分配基本单位         |
| 线程 | 进程内执行单元 | 调度更轻量，共享进程资源 |

## 最小示例

```text
打开浏览器 -> 启动一个浏览器进程 -> 进程内创建多个线程处理渲染、网络、脚本
```

- 这条链路能帮助理解：一个应用为什么既能并发执行多个任务，又不会完全互相独立。
