## 核心目标

- 理解程序为什么能运行、为什么会卡、为什么会占内存。

## 核心概念速查

| 概念     | 作用           | 常见问题                 |
| -------- | -------------- | ------------------------ |
| 进程     | 程序运行实例   | 一个应用为何能开多个实例 |
| 线程     | 进程内执行单元 | 并发与卡顿问题           |
| 内存     | 程序运行空间   | 内存泄漏、内存不足       |
| 文件系统 | 管理文件与目录 | 读写权限、路径结构       |
| 调度     | 决定谁先执行   | 为什么程序会“抢 CPU”     |

## 最小示例

```text
打开浏览器 -> 创建进程 -> 分配内存 -> 创建线程 -> 开始渲染页面
```

- 这条链路能帮助理解：应用运行不是“凭空开始”，而是操作系统一步步管理出来的。
