## 主模型

- 主模型：认知层
- 这一页主要回答“怎么理解这个主题，以及它在运维知识里的位置。”

## 学习路径

1. 先理解系统为什么能把程序运行起来。
2. 再理解进程、线程和内存这些运行时概念。
3. 最后再看 Windows 与 Linux 的基础差异，避免把系统认知和运维实操混在一起。
