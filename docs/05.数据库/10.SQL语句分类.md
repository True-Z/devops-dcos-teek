## 核心目标

- 先分清 SQL 在“定义结构、操作数据、查询数据、控制权限”上的不同职责。

## 分类速查

| 分类 | 全称                         | 作用           | 常见命令                     |
| ---- | ---------------------------- | -------------- | ---------------------------- |
| DDL  | Data Definition Language     | 定义数据库结构 | `CREATE`、`ALTER`、`DROP`    |
| DML  | Data Manipulation Language   | 修改数据       | `INSERT`、`UPDATE`、`DELETE` |
| DQL  | Data Query Language          | 查询数据       | `SELECT`                     |
| DCL  | Data Control Language        | 控制权限       | `GRANT`、`REVOKE`            |
| TCL  | Transaction Control Language | 控制事务       | `COMMIT`、`ROLLBACK`         |

## 最小示例

```sql
CREATE TABLE user (id INT PRIMARY KEY, name VARCHAR(50));
INSERT INTO user (id, name) VALUES (1, 'Tom');
SELECT * FROM user;
```

- 这个示例依次体现了建表、插入、查询三类最常见操作。
