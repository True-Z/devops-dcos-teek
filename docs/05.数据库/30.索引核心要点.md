## 核心目标

- 理解索引为什么能加快查询，以及为什么索引不是越多越好。

## 索引作用速查

| 作用         | 价值                     | 代价             |
| ------------ | ------------------------ | ---------------- |
| 加快查询     | 提升筛选、排序、连接效率 | 占用额外存储     |
| 保证唯一性   | 约束重复数据             | 写入成本增加     |
| 支持范围查询 | 提升区间检索效率         | 不合理设计会失效 |

## 最小示例

```sql
CREATE INDEX idx_user_name ON user(name);
SELECT * FROM user WHERE name = 'Tom';
```

- 这个例子说明：索引通常围绕高频筛选字段建立。

## 常见误区

- 给低选择性字段盲目建索引。
- 一个表加过多索引，导致写入明显变慢。
- 以为建了索引，所有查询都会自动变快。
