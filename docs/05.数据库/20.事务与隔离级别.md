## 核心目标

- 理解“为什么多条数据库操作要么一起成功，要么一起失败”。

## 隔离级别速查

| 隔离级别 | 能解决什么           | 可能问题                       |
| -------- | -------------------- | ------------------------------ |
| 读未提交 | 性能优先             | 脏读、不可重复读、幻读         |
| 读已提交 | 避免脏读             | 不可重复读、幻读               |
| 可重复读 | 避免脏读和不可重复读 | 可能幻读（不同数据库实现不同） |
| 串行化   | 最强一致性           | 性能开销最大                   |

## 最小示例

```sql
BEGIN;
UPDATE account SET money = money - 100 WHERE id = 1;
UPDATE account SET money = money + 100 WHERE id = 2;
COMMIT;
```

- 这是一笔最典型的转账事务：中间任何一步失败，都应该回滚。
