# 小鹤音形前后鼻音问题

## 阅读建议

- 这页只解决你当前最核心的打字问题：`in/ing` 和 `en/eng`。

## 核心目标

- 把 `in/ing`、`en/eng` 这两组练到更稳定，先解决最影响输入准确率的问题。

## 当前主要问题

| 易混组     | 你当前要先解决什么        |
| ---------- | ------------------------- |
| `in / ing` | 金 / 京、心 / 星、民 / 名 |
| `en / eng` | 很 / 横、真 / 整、文 / 翁 |

## 怎么解决

1. 先只练这两组，不分散到别的前后鼻音。
2. 先以单字为主，确认自己能稳定分清拼音。
3. 把你高频误打词单独记录，反复输入。
4. 练习目标不是记规则，而是形成手感。

## 练习建议

- 每次只练 10 到 15 分钟，但要连续几天。
- 先打单字，再回头看自己最容易错的是哪一组。
- 你练的是输入准确率，不是语文考试。

## 常见误区

- 一上来就把所有前后鼻音都一起练。
- 还没分清单字，就直接上大量词语。
- 错了不记，下一次还是重复错同样的字。
