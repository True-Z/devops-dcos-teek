# 2026年4月份学习规划

## 阅读建议

- 这页用于承接 3 月的输入法起步结果，把 4 月重点放在“输入法持续纠错 + 英语入门 + Linux 起步 + 锻炼开始建立节奏”这四条线上。

## 本月与年度目标的关系

- 本月继续承接 2026 年度目标中的四条主线，并开始把锻炼纳入日常节奏：
  - 双拼易错字持续学习
  - 英语英标与基础词汇入门
  - 运维基础认知起步
  - Python 保持基础认知预热
  - 锻炼身体建立基础节奏

## 本月主目标

| 优先级 | 方向       | 本月目标                                           |
| ------ | ---------- | -------------------------------------------------- |
| 1      | 输入法     | 持续纠正前后鼻音易错字，并开始形成高频错词复盘习惯 |
| 2      | 英语       | 认识基础英标，补人称代词、be 动词和技术高频词      |
| 3      | Linux/运维 | 建立命令、权限、日志、服务最小认知                 |
| 4      | 锻炼       | 开始建立每周锻炼节奏，先做跑步、羽毛球、基础恢复   |
| 5      | Python     | 了解基础语法和最小脚本用途，不作为本月主投入       |

## 本月周目标

| 周次  | 本周重点 | 具体目标                                      | 实际完成情况 | 个人检测/完成情况统计 |
| ----- | -------- | --------------------------------------------- | ------------ | --------------------- |
| 第1周 | 输入法   | 练 3 组前后鼻音易错词，做 10 到 15 句短句输入 | 待填写       | 待填写                |
| 第2周 | 英语     | 认识基础英标，补人称代词与 `be` 动词          | 待填写       | 待填写                |
| 第3周 | Linux    | 练命令基础、文件权限、日志查看最小链路        | 待填写       | 待填写                |
| 第4周 | 锻炼     | 完成 1 次跑步或羽毛球 + 1 次基础恢复训练      | 待填写       | 待填写                |

## 本月执行方式

1. 每周保留 1 个主目标。
2. 输入法作为整月维持主题，不完全中断。
3. 锻炼先从“能坚持”开始，不追求强度。
4. 每次学习保留最小示例或练习结果。
5. 每周末更新一次实际完成情况和个人检测结果。

## 本月最小示例

```text
第4周主目标：锻炼
维持目标：输入法错词 10 分钟、英语单词 5 个

周末检查：
- 本周是否完成 1 次运动
- 运动后身体状态是否正常
- 输入法错词是否减少
```

## 个人检测建议

| 方向   | 检测方式                         |
| ------ | -------------------------------- |
| 输入法 | 重打一轮高频错词和练习句         |
| 英语   | 看词能否认、看句能否读懂         |
| Linux  | 不看文档独立敲 3 到 5 个常用命令 |
| 锻炼   | 是否完成本周计划，并记录身体反馈 |
| Python | 能否说清基础语法和最小脚本用途   |

## 月末统计建议

| 统计项           | 记录方式                     |
| ---------------- | ---------------------------- |
| 本月主目标完成率 | 完成 / 部分完成 / 未完成     |
| 输入法纠错情况   | 错词是否减少、准确率是否提升 |
| 英语积累情况     | 学了多少词、能否认英标       |
| Linux 学习情况   | 会了哪些命令和场景           |
| 锻炼执行情况     | 本月是否建立最小锻炼节奏     |
| Python 学习情况  | 是否形成基础认知             |

## 常见误区

- 4 月把目标铺太开，导致输入法和锻炼都无法坚持。
- 英语只背单词，不补音标和最小句型。
- Linux 只看命令，不做实际场景练习。
- 锻炼一开始就追求强度，不先建立节奏。
