# 周计划模板与执行节奏

## 阅读建议

- 这页重点不是把每一天排满，而是让一周内的学习目标有主线、有复盘、有最小产出。

## 核心目标

- 帮你把学习目标拆成一周内能完成的小任务，避免目标过大后持续拖延。

## 一周最小模板

| 时间段   | 建议做什么                     |
| -------- | ------------------------------ |
| 周一     | 确定本周主目标与 1 到 2 个重点 |
| 周二周三 | 学核心内容，做最小示例         |
| 周四周五 | 练习、查漏、补错题错词         |
| 周末     | 复盘、整理、决定下周衔接点     |

## 适合你的周计划拆法

| 学习方向   | 一周最小任务示例                  |
| ---------- | --------------------------------- |
| 输入法     | 刷 2 组前后鼻音错词 + 10 句练习句 |
| 英语       | 学 10 个前端词 + 5 个 Linux 词    |
| Linux      | 练 5 个命令 + 1 个日志查看场景    |
| 计算机基础 | 看 1 篇简介 + 记 1 张核心表格     |

## 最小示例

```text
本周目标：输入法 + 英语
周二：练前后鼻音
周三：学人称代词
周四：补前端高频词
周末：复盘错词和例句
```

## 执行要点

1. 一周不要同时开太多主题。
2. 每个主题至少保留一个最小示例或练习结果。
3. 周计划重点是“能坚持”，不是“写得很满”。

## 常见误区

- 计划写很多，实际没有一个能完成。
- 只有学习输入，没有输出和复盘。
- 每周都换方向，没有连续性。
