# 月计划模板与阶段推进

## 阅读建议

- 这页重点不是按自然月堆任务，而是用月计划承接“短期到中期”目标，让一段时间内的学习方向稳定下来。

## 核心目标

- 帮你把输入法、英语、计算机基础、Linux/运维这些方向排出阶段主次，避免每周都重新开始。

## 一个月怎么拆

| 阶段         | 重点                           |
| ------------ | ------------------------------ |
| 第 1 周      | 明确本月主方向和验收标准       |
| 第 2 到 3 周 | 连续学习与练习                 |
| 第 4 周      | 复盘结果、补缺口、调整下月目标 |

## 适合你的月计划方向

| 方向       | 月度目标示例                           |
| ---------- | -------------------------------------- |
| 输入法     | 解决最常错的前后鼻音组，减少误打       |
| 英语       | 建立基础代词、音标和高频技术词         |
| Linux/运维 | 会用常见命令并能看懂基础日志和服务词汇 |
| 计算机基础 | 建立操作系统和网络的最小认知框架       |

## 最小示例

```text
本月主目标：Linux 入门
辅助目标：英语高频词 + 双拼纠错
月末验收：能独立看懂基础命令、日志关键词和最小部署路径
```

## 阶段推进建议

1. 每个月只设 1 个主目标。
2. 允许有 1 到 2 个辅助目标，但不能抢主目标时间。
3. 月末要看是否真的形成了能力，而不只是看了多少文档。

## 常见误区

- 月目标过多，最后都只停留在阅读层。
- 只看完成数量，不看是否能实际使用。
- 月末不复盘，下个月继续重复同样问题。
