## 学习路径

1. 先定阶段目标。
2. 再给每个目标挂到具体知识域。
3. 最后按“输入 -> 理解 -> 示例 -> 练习 -> 复盘”执行。

## 最小理解示例

```text
定目标 -> 找知识域 -> 做最小练习 -> 持续复盘
```
