# 2026年度学习规划

## 阅读建议

- 这页用于固定 2026 年的年度主线，重点是确定全年主要投入方向，而不是把每个月都排死。

## 核心目标

- 让 2026 年的学习重点围绕输入法、英语、运维基础和 Python 基础四条主线持续推进。

## 2026 年主要目标

| 优先级 | 方向     | 年度目标                                                   | 对应知识域                               |
| ------ | -------- | ---------------------------------------------------------- | ---------------------------------------- |
| 1      | 双拼输入 | 解决前后鼻音导致的小鹤双拼易错问题，并在日常输入中持续深入 | `85.输入法`                              |
| 2      | 英语     | 对英标形成完整基础认知，单词随学习过程持续积累             | `88.语言/10.英语`                        |
| 3      | 运维基础 | 对计算机基础、Linux、开发运维形成基础认识                  | `2200.运维基础`、`15.Linux`、`2000.运维` |
| 4      | Python   | 对 Python 形成基础认知与最小实现能力                       | 后续可挂到脚本或编程相关知识域           |

## 年度推进原则

1. 输入法、英语、Linux/运维是全年持续主题。
2. Python 不追求一步到位，先完成基础认知和最小示例。
3. 先学当前能直接用上的内容，再逐步扩展体系。
4. 所有学习尽量留下示例、练习和复盘记录。

## 阶段安排建议

| 阶段   | 重点                                |
| ------ | ----------------------------------- |
| 上半年 | 双拼纠错、英语基础、Linux 基础命令  |
| 下半年 | 运维基础补全、Python 基础认知与实践 |

## 年度验收重点

| 方向     | 年底希望达到什么状态                         |
| -------- | -------------------------------------------- |
| 输入法   | 高频前后鼻音错词明显减少，日常输入更稳定     |
| 英语     | 能看懂基础技术词、英标、最小句型             |
| 运维基础 | 能理解 Linux、日志、服务、网络、权限基础概念 |
| Python   | 能读懂基础语法并写出最小脚本示例             |

## 实施要点

1. 每个月只设 1 个主目标。
2. 每周只保留 1 个验收重点。
3. 每月都记录“实际完成情况”和“自检结果”。
4. 年度目标不求面面俱到，先保证持续推进。

## 常见误区

- 年度目标写很多，但没有月计划承接。
- 只统计看了多少文档，不统计实际能否用出来。
- 临时兴趣过多，打断全年主线。
