# 2026年3月份学习规划

## 阅读建议

- 这页用于记录 2026 年 3 月的主目标、每周目标、实际完成情况和个人自检结果，后续月份可继续按同样格式新增。

## 本月与年度目标的关系

- 由于 3 月已经接近月末，本月主要先把年度目标中的“输入法前后鼻音纠错”启动起来。
- 英语、Linux/运维、Python 在 3 月先以认知和规划为主，正式推进放到 4 月继续展开。

## 本月主目标

| 优先级 | 方向       | 本月目标                                   |
| ------ | ---------- | ------------------------------------------ |
| 1      | 输入法     | 先集中规划并开始练前后鼻音易错字与高频错词 |
| 2      | 英语       | 先明确 4 月英语学习入口与高频内容          |
| 3      | Linux/运维 | 先明确后续 Linux 与运维学习路径            |
| 4      | Python     | 先保留年度目标，占位不强推                 |

## 本月周目标

| 周次  | 本周重点 | 具体目标                                        | 实际完成情况 | 个人检测/完成情况统计 |
| ----- | -------- | ----------------------------------------------- | ------------ | --------------------- |
| 第4周 | 输入法   | 整理前后鼻音易错组，练 2 组错词与 10 句短句输入 | 进行中       | 待填写                |

## 本月执行方式

1. 3 月只保留“输入法前后鼻音”这一个真正主目标。
2. 英语、Linux/运维、Python 以规划和入口整理为主。
3. 每次输入法练习尽量保留错词和短句示例。
4. 月末记录一次实际完成情况和个人检测结果。

## 本月最小示例

```text
3月主目标：输入法前后鼻音

本月动作：
- 整理 2 组易错词
- 练 10 句短句
- 记录高频误打点
```

## 个人检测建议

| 方向   | 检测方式                               |
| ------ | -------------------------------------- |
| 输入法 | 回看错词表，重打一轮高频错词与练习短句 |
| 英语   | 记录已规划内容，准备 4 月正式学习      |
| Linux  | 记录已整理入口与学习路径               |
| Python | 确认已纳入年度目标但本月不强推         |

## 月末统计建议

| 统计项           | 记录方式                       |
| ---------------- | ------------------------------ |
| 本月主目标完成率 | 完成 / 部分完成 / 未完成       |
| 输入法纠错情况   | 错词是否减少、易错组是否更清楚 |
| 英语准备情况     | 是否已明确 4 月学习入口        |
| Linux 准备情况   | 是否已明确 4 月学习路径        |
| Python 准备情况  | 是否保留年度目标位置           |

## 常见误区

- 月计划一开始写太满，后面很难坚持。
- 只写计划，不回填实际完成情况。
- 没有个人检测，月底很难知道自己到底学会了什么。
