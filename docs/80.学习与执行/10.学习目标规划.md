# 学习目标规划

## 阅读建议

- 这页重点不是列愿望清单，而是把短期、中期、长期目标和对应实现方式挂到实际知识域。

## 核心目标

- 让学习目标具备阶段性、可执行性和可复盘性，而不是一直停留在“以后再学”。

## 当前第一版个人计划

| 优先级 | 当前方向   | 当前想先解决什么                      | 对应知识域              |
| ------ | ---------- | ------------------------------------- | ----------------------- |
| 1      | 输入法     | 前后鼻音导致的小鹤双拼输入不准        | `85.输入法`             |
| 2      | 英语       | 尽快能看懂前端与 Linux 学习中的基础词 | `88.语言/10.英语`       |
| 3      | Linux      | 建立命令、目录、权限、日志基础认知    | `15.Linux`、`2000.运维` |
| 4      | 计算机基础 | 补操作系统、网络等底层常识            | `2200.运维基础`         |

## 当前执行原则

1. 输入法、英语、Linux 先并行，但每周只保留一个主目标。
2. 所有学习内容都尽量保留最小示例，方便复习。
3. 先学“现在用得上”的，再学更系统的扩展内容。
4. 英语学习优先服务前端和 Linux，而不是泛化背单词。

## 按每周投入时间的建议版本

| 每周可投入时间 | 更推荐怎么学                                  |
| -------------- | --------------------------------------------- |
| 3 小时以内     | 只保留 1 个主目标，输入法或英语二选一         |
| 4 到 6 小时    | 1 个主目标 + 1 个辅助目标，适合“英语 + Linux” |
| 7 到 10 小时   | 输入法、英语、Linux 并行，但仍要分主次        |
| 10 小时以上    | 可加计算机基础，但仍建议每周只设 1 个验收重点 |

## 当前最适合你的每周节奏

| 方向   | 建议周投入  | 学什么                                 |
| ------ | ----------- | -------------------------------------- |
| 输入法 | 1 到 2 小时 | 前后鼻音错词、短句、双拼反复练         |
| 英语   | 2 到 3 小时 | 代词、be 动词、音标、前端/Linux 高频词 |
| Linux  | 2 到 3 小时 | 命令、权限、日志、服务、网络基础       |

## 一周最小执行版

```text
主目标：Linux
辅助目标：英语
维持目标：输入法

Linux：练 5 个命令 + 1 个日志场景
英语：学 10 个高频词 + 3 个最小句
输入法：刷 10 分钟错词
```

## 验收建议

1. 输入法看一周内高频错词有没有减少。
2. 英语看是否能认出本周目标词和最小句。
3. Linux 看是否能独立完成一个最小命令场景。

## 短期目标

| 方向   | 具体目标                           | 如何实现                           |
| ------ | ---------------------------------- | ---------------------------------- |
| 输入法 | 提升小鹤双拼前后鼻音输入准确率     | 刷错词表、练短句、每天短时重复输入 |
| 英语   | 看懂前端文档里的高频词和最基础句型 | 先学代词、be 动词、前端高频词      |
| Linux  | 会用常见命令、看懂基础目录和权限   | 命令练习 + 文件权限场景结合        |

## 中期目标

| 方向       | 具体目标                             | 如何实现                           |
| ---------- | ------------------------------------ | ---------------------------------- |
| 计算机基础 | 建立操作系统、网络、数据结构基础框架 | 按模块学习并用最小示例理解         |
| 英语       | 能看 Linux 与运维资料的基础英文      | 补英式音标、Linux 高频词、常见句子 |
| 运维       | 能完成最小部署、日志查看和简单排障   | Linux 基础 -> 服务 -> 日志 -> 网络 |

## 长期目标

| 方向     | 具体目标                          | 如何实现                             |
| -------- | --------------------------------- | ------------------------------------ |
| 技术学习 | 形成前端、Linux、运维协同学习能力 | 持续把知识沉淀到各自知识域           |
| 英语阅读 | 能快速阅读技术文档并定位关键内容  | 高频词积累 + 按场景持续阅读          |
| 学习方法 | 形成自己的学习与复盘节奏          | 每学完一块就整理示例、记录问题和结论 |

## 实现要点

1. 每个目标都要挂到具体目录，而不是悬空。
2. 每次学习都尽量保留最小示例。
3. 先解决当前最需要的能力，再扩展周边知识。
4. 周期性回看错题、错词和易混点。

## 推荐挂载关系

| 学习目标         | 对应知识域              |
| ---------------- | ----------------------- |
| 双拼输入         | `85.输入法`             |
| 英语入门         | `88.语言/10.英语`       |
| 计算机基础       | `2200.运维基础`         |
| Linux 与运维     | `15.Linux`、`2000.运维` |
| Windows 基础认知 | `11.Windows`            |

## 常见误区

- 目标太大，没有阶段拆分。
- 只看内容，不做示例和练习。
- 不把学习目标映射到具体知识域，后面难以维护。
- 同时开太多学习主线，最后每条都推进很慢。
