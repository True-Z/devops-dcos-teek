IDE 模块主要用于整理编辑器、快捷键、插件和工作流配置，让编码环境更稳定、更高效。

## 推荐阅读

- [JetBrains 简介](/tools/ide-jetBrains)
- [JetBrains 核心要点](/tools/ide-jetBrains-core)

## 学习路径

1. 先理解 IDE 的核心作用：编辑、导航、重构、调试。
2. 再看具体工具（如 JetBrains）的插件和配置。
3. 最后按个人工作流沉淀快捷键与布局习惯。

## 最小理解示例

```text
打开项目 -> 跳转文件/定义 -> 修改代码 -> 重构 -> 运行/调试
```
