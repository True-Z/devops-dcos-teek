# 恋爱计划-实施记录

## 2026-03-26 周末约出来玩计划

- **当前目标**：自然约出来，轻松相处，不给压力。
- **时间建议**：优先周六下午；不方便再看周日下午。
- **时长建议**：2 到 3 小时，宁短勿满。
- **核心原则**：少走路，不赶场，不排满。
- **初步安排**：约一个交通方便、能坐下来聊天的地方；先坐聊，再看状态决定要不要附近走一小段。
- **推荐节奏**：见面落座 -> 轻松聊天 -> 视状态小范围走动 -> 自然结束。
- **为什么这样安排**：周六下午通常更自然；轻安排更放松；少走路更省体力；前期见面更要留余地。
- **地点类型**：优先安静、交通方便、能坐着聊的地方，比如咖啡、甜品、商场里的轻餐位置；不选太吵、太远、要走很多路的地方。
- **预算范围**：先控制在轻松范围，重点是舒服，不靠花费制造氛围；以饮品、甜品、轻食这类可进可退的消费为主。
- **邀约话术**：语气轻一点，不把见面说得太重，比如“周六下午如果你方便的话，可以一起出来坐坐，找个地方聊聊天。”
- **当天流程**：先见面落座，聊当下和轻话题；如果状态自然，再顺带附近走一小段；如果状态一般，就在第一个点自然收住。
- **结束后延续联系**：结束后简单回应当天感受，轻一点延续，不立刻上强度，比如“今天见面挺开心的，路上注意安全。”
- **备选方案**：天气不好就纯室内；时间紧就缩成 1 到 1.5 小时；状态一般就在第一个地点结束。
- **风险点**：地点太远、安排太满、话题太刻意、结束太拖。
- **执行提醒**：约法轻一点；地点让对方也方便；不急着推进；结束时留一点下次空间。
