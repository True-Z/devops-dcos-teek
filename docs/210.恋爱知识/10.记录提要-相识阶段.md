# 记录提要-相识阶段

## 记录视角

- 只提炼相识阶段最该记住的点，不展开长讲。

## 相识阶段提要

| 要点词语 | 要做什么               | 为什么                     |
| -------- | ---------------------- | -------------------------- |
| 轻一点   | 先自然交流，不急着推进 | 一开始太重，关系容易发紧   |
| 先观察   | 看对方节奏和反馈       | 避免只按自己感觉往前冲     |
| 留边界   | 不急着定义关系         | 相识阶段更适合先建立舒服感 |
| 先真实   | 不硬装，不急着证明自己 | 真实比用力表现更自然       |

## 最小提醒

```text
相识先轻一点。
先认识，先观察，先留边界。
```
