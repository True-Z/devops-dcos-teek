# 记录提要-相知阶段

## 记录视角

- 只提炼相知阶段的关键点：做什么，为什么这样更稳。

## 相知阶段提要

| 要点词语 | 要做什么             | 为什么                   |
| -------- | -------------------- | ------------------------ |
| 稳节奏   | 有来有回，不忽冷忽热 | 节奏稳定比推进更重要     |
| 轻关心   | 关心要自然，不过界   | 太满会给人压力           |
| 看反馈   | 看对方是否也在靠近   | 关系是双向，不是单向想象 |
| 先轻后深 | 话题慢慢展开         | 太快聊太深容易让人不舒服 |
| 留空间   | 不要一直追着确认     | 给彼此呼吸感，关系更自然 |

## 最小提醒

```text
相知先稳一点。
先看反馈，再决定下一步。
```
