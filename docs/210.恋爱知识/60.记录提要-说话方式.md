# 记录提要-说话方式

## 记录视角

- 这页只提炼恋爱相处里和说话相关的核心提醒，不展开成长篇聊天理论。

## 说话方式提要

| 要点词语 | 要做什么                 | 为什么                 |
| -------- | ------------------------ | ---------------------- |
| 轻一点   | 开口先轻，不先把气氛压重 | 一开始太重容易让人紧张 |
| 接得住   | 先接住对方当前的话       | 比自顾自输出更自然     |
| 少盘问   | 一次问一两个点就够       | 连续追问容易像盘问     |
| 留余地   | 话不要说得太满           | 给双方都留空间         |
| 看反馈   | 根据对方回应调整节奏     | 不是只按自己想法说     |

## 最小提醒

```text
先轻一点。
先接住。
少盘问。
留余地。
```
