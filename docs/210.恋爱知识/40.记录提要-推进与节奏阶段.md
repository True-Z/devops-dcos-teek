# 记录提要-推进与节奏阶段

## 记录视角

- 只提炼关系推进中的节奏判断，不展开成很多分散页面。

## 推进与节奏提要

| 要点词语   | 要做什么                       | 为什么                       |
| ---------- | ------------------------------ | ---------------------------- |
| 不急推     | 不急着定义关系、不急着把话说满 | 快不等于稳                   |
| 双向感     | 判断聊天是不是双向舒服         | 只有一方在推进，关系容易失衡 |
| 自然靠近   | 看整体趋势，不看单次热络       | 靠近通常是慢慢形成的         |
| 适度主动   | 可以轻一点主动，但不猛推       | 主动不是越多越好             |
| 不制造压力 | 不靠频繁追问、过满关心维持关系 | 压力感会破坏自然感           |

## 最小提醒

```text
不急推。
看双向。
稳节奏。
```
