# 记录提要-聊天与见面阶段

## 记录视角

- 只提炼聊天、冷场、第一次见面、约见面的关键提醒，不展开长讲。

## 聊天与见面提要

| 要点词语 | 要做什么                           | 为什么                             |
| -------- | ---------------------------------- | ---------------------------------- |
| 接得住   | 先接话，再展开                     | 比一味输出更自然                   |
| 不硬撑   | 冷场时轻一点接，不慌着连发         | 冷场本身不可怕，慌乱才会把节奏弄坏 |
| 先轻话题 | 第一次见面从眼前、兴趣、日常聊起   | 太深太快容易让人紧绷               |
| 看状态   | 聊天顺、回应自然时再考虑见面       | 见面更看整体节奏是否自然           |
| 顺延续   | 见面后轻一点回应、顺着当天内容延续 | 不让联系突然变重                   |

## 最小提醒

```text
聊天先接住。
见面先轻松。
联系先自然延续。
```
