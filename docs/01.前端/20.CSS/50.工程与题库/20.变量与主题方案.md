# CSS 变量与主题方案

## 核心目标

- 用统一变量管理颜色、间距、字号等设计 token，降低样式散落与主题切换成本。

## 为什么优先用 CSS 变量

| 方案           | 优点                         | 限制               |
| -------------- | ---------------------------- | ------------------ |
| CSS 变量       | 运行时可变、天然支持主题切换 | 旧浏览器兼容性略差 |
| Sass/Less 变量 | 编译期能力强                 | 编译后不可动态修改 |

## 最小示例

```css
:root {
  --color-primary: #1677ff;
  --bg-page: #ffffff;
  --text-color: #1f2329;
}

.dark {
  --color-primary: #7cc4ff;
  --bg-page: #111111;
  --text-color: #f5f5f5;
}

.button {
  color: var(--text-color);
  background: var(--color-primary);
}
```

- 变量写在 `:root` 适合全局主题，写在组件容器上适合局部覆写。

## 常用变量分组

| 分组      | 常见变量                            | 说明               |
| --------- | ----------------------------------- | ------------------ |
| 颜色      | `--color-primary`、`--color-danger` | 统一品牌色与状态色 |
| 背景      | `--bg-page`、`--bg-card`            | 区分页面与组件层级 |
| 文本      | `--text-color`、`--text-secondary`  | 控制主次文本层级   |
| 间距      | `--space-xs`、`--space-md`          | 统一布局节奏       |
| 圆角/阴影 | `--radius-sm`、`--shadow-card`      | 统一视觉风格       |

## 主题切换方案

### 1. class 切换（最常用）

```js
document.documentElement.classList.toggle('dark')
```

- 适合明暗主题、品牌主题切换。

### 2. data-theme 切换（可读性更强）

```css
:root[data-theme='dark'] {
  --bg-page: #111111;
}
```

```js
document.documentElement.dataset.theme = 'dark'
```

- 适合多主题场景，比单个 class 更直观。

## JavaScript 中如何使用 CSS 变量

```js
document.documentElement.style.setProperty('--color-primary', '#ff4d4f')

const primary = getComputedStyle(document.documentElement).getPropertyValue('--color-primary')
```

- JS 负责“改变量和读取变量”，CSS 负责“真正渲染界面”。

## 常见误区

- 把所有值都抽成变量，导致命名混乱。
- 变量名直接写业务含义，后期难复用。
- 主题切换时只改颜色，不改边框、阴影、文本层级。
