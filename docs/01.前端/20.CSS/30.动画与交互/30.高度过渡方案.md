# CSS 高度过渡方案

## 核心目标

- 解决内容展开/收起时，高度无法直接从 `0` 平滑过渡到 `auto` 的问题。

## 方案速查

| 方案                 | 是否纯 CSS | 适合场景                   | 注意点                   |
| -------------------- | ---------- | -------------------------- | ------------------------ |
| `max-height`         | 是         | 内容高度有上限的折叠面板   | 上限设置过大时节奏不精确 |
| `grid-template-rows` | 是         | 现代浏览器环境下的展开收起 | 兼容性需确认             |
| `transform: scaleY`  | 是         | 视觉展开，不依赖真实高度   | 不会推动文档流           |
| `scrollHeight + JS`  | 否         | 高度不固定、要求最准确     | 需处理测量与回流         |

## 为什么 `height: auto` 不能直接过渡

- 浏览器无法直接把 `auto` 插值成一个确定数值，因此 `height: 0 -> auto` 不会产生正常过渡。

## 最小示例

### `max-height`

```css
.panel {
  max-height: 0;
  overflow: hidden;
  transition: max-height 0.3s ease;
}

.panel.is-open {
  max-height: 300px;
}
```

### `grid-template-rows`

```css
.wrapper {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows 0.3s ease;
}

.wrapper.is-open {
  grid-template-rows: 1fr;
}

.content {
  overflow: hidden;
}
```

### JS + `scrollHeight`

```js
const panel = document.querySelector('.panel')
panel.style.height = `${panel.scrollHeight}px`
```

- 需要最准确的过渡时，JS 测量是最稳的方案。

## 选型建议

- 内容不高且结构简单：优先 `max-height`
- 纯 CSS 且现代项目：可尝试 `grid-template-rows`
- 要推动布局且高度不可预估：优先 `scrollHeight + JS`
