# CSS 选择器一览

## 阅读建议

- 优先按“用途”选选择器，而不是死记所有语法。
- 日常开发最常用的是基础选择器、结构伪类、属性选择器、状态伪类。
- `:is()`、`:where()`、`:has()` 这类新能力要重点理解权重和兼容性。

## 选择器选型速查

| 目标             | 优先选择                                 | 说明               |
| ---------------- | ---------------------------------------- | ------------------ |
| 稳定选中业务节点 | `.class` / `[data-*]`                    | 最适合业务样式     |
| 精准选中唯一节点 | `#id`                                    | 适合锚点或唯一容器 |
| 按结构筛选       | `:nth-child()` / `:first-child`          | 列表、表格最常用   |
| 按状态切换       | `:hover` / `:focus-visible` / `:checked` | 交互场景高频       |
| 降低重复书写     | `:is()` / `:where()`                     | 注意权重不同       |

## 基础选择器

| 选择器    | 作用         | 常见场景               | 权重      |
| --------- | ------------ | ---------------------- | --------- |
| `*`       | 选择所有元素 | reset、全局兜底        | `0,0,0,0` |
| `element` | 按标签选中   | 基础排版、语义标签统一 | `0,0,0,1` |
| `.class`  | 按类名选中   | 最常见业务样式         | `0,0,1,0` |
| `#id`     | 按 id 选中   | 锚点、唯一节点         | `0,1,0,0` |

## 复合选择器

| 选择器  | 作用       | 常见场景               | 权重           |
| ------- | ---------- | ---------------------- | -------------- |
| `A B`   | 后代选择器 | 某容器内部所有目标元素 | 叠加各部分权重 |
| `A > B` | 子代选择器 | 限制直接子元素         | 叠加各部分权重 |
| `A + B` | 相邻兄弟   | 紧邻提示、表单错误提示 | 叠加各部分权重 |
| `A ~ B` | 通用兄弟   | 同级联动               | 叠加各部分权重 |
| `A, B`  | 并集选择器 | 合并多个规则           | 各自独立计算   |

## 伪元素选择器

| 选择器           | 作用         | 常见场景       | 权重      |
| ---------------- | ------------ | -------------- | --------- |
| `::before`       | 内容前插入   | 图标、装饰线   | `0,0,0,1` |
| `::after`        | 内容后插入   | clearfix、角标 | `0,0,0,1` |
| `::first-letter` | 首字母样式   | 特殊排版       | `0,0,0,1` |
| `::first-line`   | 首行样式     | 特殊排版       | `0,0,0,1` |
| `::selection`    | 选中文本样式 | 选中高亮       | `0,0,0,1` |

## 状态伪类选择器

| 选择器           | 作用             | 常见场景       | 权重      |
| ---------------- | ---------------- | -------------- | --------- |
| `:link`          | 未访问链接       | 链接初始态     | `0,0,1,0` |
| `:visited`       | 已访问链接       | 链接状态区分   | `0,0,1,0` |
| `:hover`         | 鼠标悬浮         | Hover 交互     | `0,0,1,0` |
| `:active`        | 激活态           | 点击瞬间态     | `0,0,1,0` |
| `:focus`         | 获得焦点         | 表单交互       | `0,0,1,0` |
| `:focus-visible` | 焦点且应显示轮廓 | 键盘无障碍     | `0,0,1,0` |
| `:focus-within`  | 子元素获得焦点   | 表单组联动高亮 | `0,0,1,0` |

## 结构伪类选择器

| 选择器                   | 作用           | 常见场景         | 权重      |
| ------------------------ | -------------- | ---------------- | --------- |
| `:first-child`           | 第一个子元素   | 列表首项样式     | `0,0,1,0` |
| `:last-child`            | 最后一个子元素 | 列表末项样式     | `0,0,1,0` |
| `:nth-child(n)`          | 第 n 个子元素  | 斑马纹、序号样式 | `0,0,1,0` |
| `:nth-of-type(n)`        | 同类型第 n 个  | 指定标签筛选     | `0,0,1,0` |
| `:only-child`            | 唯一子元素     | 特殊兜底样式     | `0,0,1,0` |
| `:empty`                 | 空元素         | 占位和空态处理   | `0,0,1,0` |
| `:enabled` / `:disabled` | 控件状态       | 表单启用禁用     | `0,0,1,0` |
| `:checked`               | 选中态         | checkbox/radio   | `0,0,1,0` |
| `:target`                | 当前锚点目标   | 锚点高亮         | `0,0,1,0` |
| `:root`                  | 根元素         | 全局变量、主题   | `0,0,1,0` |

## 属性选择器

| 选择器           | 作用           | 常见场景      | 权重      |
| ---------------- | -------------- | ------------- | --------- |
| `[attr]`         | 存在某属性     | 通用属性标记  | `0,0,1,0` |
| `[attr=value]`   | 属性值完全匹配 | 精准筛选      | `0,0,1,0` |
| `[attr^=value]`  | 以某值开头     | URL、前缀命名 | `0,0,1,0` |
| `[attr$=value]`  | 以某值结尾     | 文件后缀      | `0,0,1,0` |
| `[attr*=value]`  | 包含子串       | 模糊匹配      | `0,0,1,0` |
| `[attr~=value]`  | 包含完整单词   | 类名风格匹配  | `0,0,1,0` |
| `[attr\|=value]` | 语言值匹配     | `lang` 相关   | `0,0,1,0` |

## 新能力补充

| 选择器     | 作用                             | 注意点                 |
| ---------- | -------------------------------- | ---------------------- |
| `:is()`    | 合并多个选择器，取参数中最高权重 | 适合减少重复书写       |
| `:where()` | 合并多个选择器，但权重恒为 0     | 适合基础规则兜底       |
| `:has()`   | 条件父级选择                     | 能力强，但要关注兼容性 |
| `:not()`   | 排除不符合条件的元素             | 参数内部权重参与计算   |

## 为什么能减少书写

### `:is()`

- 把多个“相同样式、不同目标”的选择器合并到一条规则里，减少重复声明。
- 它不会像 Sass 那样“编译出新 CSS 规则”，而是浏览器直接把参数列表当作一组可匹配选择器来处理。

```css
:is(h1, h2, h3) {
  margin: 0;
}
```

可以把它理解为语义上接近下面这组写法：

```css
h1,
h2,
h3 {
  margin: 0;
}
```

- 区别在于：`:is()` 更适合嵌入复杂选择器中，减少重复前缀。

```css
.article :is(h1, h2, h3, h4) {
  color: #1f2329;
}
```

等价理解为：

```css
.article h1,
.article h2,
.article h3,
.article h4 {
  color: #1f2329;
}
```

### `:where()`

- 写法类似 `:is()`，但权重恒为 `0`，适合写基础兜底规则。
- 浏览器同样不会额外生成多份 CSS，它只是把参数列表参与匹配，但在优先级计算时把 `:where()` 本身当成 `0` 权重处理。

```css
:where(.article-content) h1 {
  margin-top: 0;
}
```

- 好处是后续业务样式更容易覆盖，不容易产生权重竞争。

可以把它理解为“分组匹配 + 不抬高权重”。

### `:has()`

- 让“父级根据子级状态改变样式”成为可能，减少额外 class 或 JS 中转。
- 浏览器在匹配 `.card:has(.error)` 时，会判断 `.card` 内部是否存在 `.error`，匹配成功后再应用样式。

```css
.card:has(.error) {
  border-color: #ff4d4f;
}
```

- 以前这个场景通常要：
  - JS 手动给父级加类
  - 或模板里提前多写一层状态类
- 所以它减少的是“额外状态同步代码”。

### `:not()`

- 用来排除特例，减少再写一套相反规则。
- 浏览器会先匹配前面的主选择器，再排除满足 `:not()` 参数的元素。

```css
.button:not(.is-disabled) {
  cursor: pointer;
}
```

可以把它理解为：

```css
.button {
  cursor: pointer;
}

.button.is-disabled {
  cursor: not-allowed;
}
```

- 但 `:not()` 的写法更直接，尤其适合“默认规则 + 少量排除项”的场景。

## 如何理解“减少书写”

| 选择器     | 减少的内容                   | 本质                   |
| ---------- | ---------------------------- | ---------------------- |
| `:is()`    | 重复前缀选择器               | 合并多个同类目标       |
| `:where()` | 重复前缀 + 权重控制代码      | 合并目标且不抬高权重   |
| `:has()`   | 额外父级状态类 / JS 同步逻辑 | 让父级可按子级条件选中 |
| `:not()`   | 反向覆盖规则                 | 用排除法表达特例       |

- 这几个选择器减少的不是“最终浏览器一定执行更少代码”，而是“开发时更少重复书写、更少补状态类、更少写覆盖规则”。

## 最小示例

```css
.form-item:focus-within {
  border-color: #1677ff;
}

.list > li:nth-child(odd) {
  background: #f5f5f5;
}

.card:has(.error) {
  border-color: #ff4d4f;
}
```

- 这组示例分别对应：焦点联动、列表奇偶项、父级条件选择。
