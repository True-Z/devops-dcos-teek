# V8 执行优化方案

## 核心目标

- 让热点路径更稳定地被引擎优化，减少反优化带来的性能抖动。

## 模块定位

- 这页更偏“性能优化实践”，适合在你明确遇到执行效率问题时回看。

## 高收益原则

| 原则             | 说明                       | 价值               |
| ---------------- | -------------------------- | ------------------ |
| 对象形状稳定     | 避免频繁增删字段和类型漂移 | 提升隐藏类复用概率 |
| 热点函数稳定输入 | 减少多态/超态调用点        | 降低反优化风险     |
| 控制临时对象数量 | 减轻 GC 压力               | 降低卡顿峰值       |

## 代码层建议

- 数据结构先设计再编码，避免后期频繁改“对象形状”。
- 热点循环内减少隐式类型转换与多分支类型混用。
- 复用可复用对象，降低高频分配；相关背景可继续看 [V8 hidden classes](https://v8.dev/docs/hidden-classes) 和 [V8 隐藏类与对象存储](/fe/v8-hidden-class-storage)。

## 最小示例

### 更稳定的对象形状

```js
function createUser(id, name) {
  return {
    id,
    name,
    status: 'active',
  }
}
```

- 同类对象字段顺序和字段集合保持一致，更利于隐藏类复用。

### 不稳定的对象形状

```js
const user = { id: 1 }

if (needName) {
  user.name = 'tom'
}

if (needScore) {
  user.score = 100
}
```

- 运行时动态增删字段，容易让对象形状漂移，增加优化难度。

## 常见误区

- 为了“灵活”随意给对象动态挂字段。
- 把所有性能问题都归因于框架，忽略运行时特性。
- 未确认瓶颈就做微优化，收益不稳定。
