# 图片优化策略

## 阅读建议

- 这页重点不是只记图片格式，而是从资源体积、设备适配、视觉稳定性和加载时机一起看图片策略。

## 核心目标

- 理解图片优化真正要解决的是“看得清、下得快、占得稳”，而不是单纯把文件压小。

## 图片优化常见方向

| 方向       | 常见做法                         |
| ---------- | -------------------------------- |
| 格式选型   | 照片优先 WebP/AVIF，图标优先 SVG |
| 尺寸控制   | 上传前裁剪，按展示尺寸提供资源   |
| 响应式适配 | `srcset`、`sizes`、多分辨率资源  |
| 加载时机   | 首屏关键图优先，其余图片懒加载   |
| 视觉稳定性 | 预留宽高、占位图、渐进展示       |

## 常见场景策略

| 场景        | 更推荐的做法                   |
| ----------- | ------------------------------ |
| Banner 大图 | 控制尺寸，必要时预加载         |
| 列表缩略图  | 固定比例裁剪，懒加载           |
| 图标        | 优先 SVG 或图标方案            |
| 商品详情图  | 提供多尺寸资源，按需放大       |
| 长图/海报   | 分段加载或控制清晰度与体积平衡 |

## 最小示例

```html
<img src="cover-640.webp" srcset="cover-640.webp 640w, cover-1280.webp 1280w" sizes="(max-width: 768px) 100vw, 50vw" loading="lazy" alt="封面图" />
```

- 响应式资源和懒加载配合使用，通常比只做单张大图压缩更有效。

## 实施重点

- 图片上传链路就要限制尺寸和格式，避免问题拖到前端页面解决。
- 对首屏 LCP 图片单独治理，不和普通列表图片混为一类。
- 为图片预留宽高，减少布局抖动。

## 常见误区

- 原图直接上 CDN，完全依赖浏览器缩放。
- 所有图片统一懒加载，反而拖慢首屏关键图。
- 只压缩体积，不处理尺寸、裁剪和展示比例。
