# 页面白屏排查方案

## 阅读建议

- 先按“资源 -> 路由 -> 运行时错误 -> 首屏依赖”顺序排，不要一开始就猜框架有问题。

## 排查主线

1. HTML 是否正常返回
2. JS/CSS 资源是否 404 或路径错误
3. 首屏脚本是否报错直接中断
4. 路由是否命中错误页面
5. 接口依赖是否把首屏阻塞死

## 常见原因

| 类别       | 典型问题                           |
| ---------- | ---------------------------------- |
| 部署路径   | `base` 配错、静态资源引用错        |
| 资源加载   | JS chunk 404、CDN 失效             |
| 运行时报错 | 初始化代码异常、环境变量缺失       |
| 路由       | history 回退未配置、路由守卫死循环 |
| 数据依赖   | 首屏接口超时、无兜底渲染           |

## 最小示例

```js
window.addEventListener('error', (event) => {
  console.error('runtime error:', event.error)
})
```

## 实施建议

- 先看 Network 和 Console
- 再看部署配置与构建产物路径
- 给首屏加错误兜底和骨架屏
