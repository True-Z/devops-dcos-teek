# 工程化下的页面性能优化

## 阅读建议

- 先区分首屏性能、交互性能、构建产物体积，再决定优化方向。

## 优化主线

| 方向     | 常见手段                             |
| -------- | ------------------------------------ |
| 首屏加载 | 路由懒加载、关键资源预加载、图片压缩 |
| JS 体积  | 拆包、按需引入、移除无用依赖         |
| 渲染执行 | 降低同步任务、减少重复渲染           |
| 缓存策略 | 文件指纹、长缓存、CDN                |

## 工程化层面的重点

- 按页面和路由拆包，而不是一股脑打成大包。
- 谨慎引入重依赖，能局部引入就不要全量引入。
- 对图片、字体、第三方脚本做优先级管理。
- 建立性能预算，避免产物持续膨胀。

## 最小示例

```ts
const UserPage = () => import('./pages/UserPage.vue')
```

- 这是最基本的按路由懒加载思路。

## 常见误区

- 只看包体积，不看执行和渲染成本。
- 只做压缩，不做拆包。
- 只优化首屏，不看交互卡顿和长任务。
