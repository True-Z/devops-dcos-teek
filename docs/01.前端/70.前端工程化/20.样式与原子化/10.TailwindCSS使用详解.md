# Tailwind CSS 使用详解

## 阅读建议

- 这页重点看“为什么某些类名能生效，某些动态拼接写法不生效”。

## 为什么动态拼接字符不可以

- Tailwind 主要依赖对源码的静态扫描来提取类名。
- 如果类名是在运行时字符串拼出来的，构建阶段通常无法可靠识别。

```ts
const cls = `m-${size}`
```

- 这种写法在构建时通常拿不到完整枚举，所以对应样式可能不会被生成。

## `m-2` 为什么可以生效

- `m-2` 这类类名来自 Tailwind 预定义的 spacing scale。
- `2` 不是随意数字，而是去 `theme.spacing` 里取值映射。

## 如何设置动态值

### 方案一：枚举映射

```ts
const marginClassMap = {
  sm: 'm-2',
  md: 'm-4',
  lg: 'm-6',
}
```

- 这是最稳的方式，因为类名在源码里是显式存在的。

### 方案二：配置 safelist

- 当你明确知道可能出现哪些类名，可以通过 safelist 保留它们。

### 方案三：使用 CSS 变量或行内样式承接真正动态值

- 如果值是运行时任意输入，通常更适合用 CSS 变量或行内样式，而不是强行拼 Tailwind 类名。

## 配置文件怎么配

```ts
import type { Config } from 'tailwindcss'

export default {
  content: ['./src/**/*.{vue,ts,tsx,html}'],
  theme: {
    extend: {
      spacing: {
        18: '4.5rem',
      },
    },
  },
  safelist: ['m-2', 'm-4', 'm-6'],
} satisfies Config
```

## 常见误区

- 把 Tailwind 当成“运行时解释器”，忽略它本质是构建期生成样式。
- 用大量任意拼接类名，最后样式丢失还不知原因。
- 不区分“枚举动态值”和“完全自由动态值”。
