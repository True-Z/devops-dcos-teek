# Vite 基础与运行机制

## 阅读建议

- 重点回答“为什么开发快、构建时又为什么走 Rollup”。

## 核心目标

- 理解 Vite 在开发态和构建态分别做什么。

## 主线

| 阶段       | Vite 在做什么                              |
| ---------- | ------------------------------------------ |
| 开发态     | 利用浏览器原生 ESM，按需转换模块           |
| 依赖预构建 | 提前把第三方依赖转成更适合浏览器消费的形式 |
| 构建态     | 交给 Rollup 统一打包输出产物               |

## 为什么开发快

- 不再一启动就全量打包。
- 页面访问到哪个模块，再按需处理哪个模块。

## 为什么还需要构建

- 因为线上仍然需要产物优化、压缩、拆包、指纹、兼容性处理。

## 常见追问

- 为什么 Vite 和 webpack 在开发体验上差异明显。
- 为什么插件生态通常要区分开发态和构建态能力。
