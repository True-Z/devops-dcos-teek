# pnpm workspace 与 monorepo

## 阅读建议

- 回答这类问题时，先讲“为什么要多包协作”，再讲工具选型。

## monorepo 是什么

- monorepo 指把多个相关包、应用、组件库放在同一个仓库管理。
- 它适合需要共享依赖、共享配置、共享发布节奏的团队。

## pnpm workspace 解决什么问题

- 统一安装与依赖链接
- 多包之间本地联动开发
- 减少重复依赖安装成本

## 最小结构示例

```text
apps/
packages/
pnpm-workspace.yaml
```

## 为什么常和依赖治理一起问

- 因为 monorepo 一旦包多起来，最容易失控的就是版本、边界和发布关系。

## 常见误区

- 还没到多包复杂度，就为了“先进”硬上 monorepo。
- 多包都共用一套依赖，却没有边界规范。
- 只建 workspace，不做统一 lint/test/build 约束。
