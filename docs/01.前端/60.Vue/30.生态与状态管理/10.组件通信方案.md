# Vue 组件通信方案

## 阅读建议

- 回答组件通信问题时，优先按“父子 / 跨层 / 跨页面共享状态”分层。

## 常见通信方式

| 方式             | 适合场景       |
| ---------------- | -------------- |
| `props` + `emit` | 父子组件       |
| `v-model`        | 父子双向约定   |
| `provide/inject` | 跨层级传递     |
| Pinia            | 跨页面共享状态 |

## 推荐顺序

1. 父子通信优先 `props` / `emit`
2. 跨层但上下文明确可用 `provide/inject`
3. 全局共享状态再考虑 Pinia

## 最小示例

```vue
<template>
  <Child :count="count" @change="count = $event" />
</template>

<script setup>
import { ref } from 'vue'

const count = ref(1)
</script>
```

- 这是最典型的父传子、子通知父的通信模式。

## 常见误区

- 一上来就上全局状态。
- 把 `provide/inject` 当成大型状态管理替代品。
- 让组件通信链路变得不可追踪。
