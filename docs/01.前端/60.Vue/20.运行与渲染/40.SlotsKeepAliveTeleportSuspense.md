# Vue Slots KeepAlive Teleport Suspense

## 阅读建议

- 这页适合把几个常见内建能力串起来看：内容分发、组件缓存、跨层挂载、异步占位。

## Slots 是什么

- Slots 本质上是组件内容分发机制。
- 它解决的是“组件壳子固定，但内部内容由外部决定”的问题。

```vue
<BaseCard>
  <template #header>标题</template>
  <template #default>内容</template>
</BaseCard>
```

- 面试里常追问：默认插槽、具名插槽、作用域插槽分别解决什么问题。

## KeepAlive 是什么

- `KeepAlive` 用来缓存动态组件实例，避免组件切走后立即销毁。
- 它更适合页面切换、Tab 切换、低频重建成本高的组件。

```vue
<KeepAlive>
  <component :is="currentView" />
</KeepAlive>
```

- 常见追问：为什么缓存后会有 `activated` / `deactivated` 这类生命周期。

## Teleport 是什么

- `Teleport` 解决的是“逻辑上属于当前组件，但渲染位置要挂到别处”的问题。
- 最常见场景是弹窗、抽屉、全局浮层。

```vue
<Teleport to="body">
  <Modal v-if="visible" />
</Teleport>
```

- 常见追问：它改变的是 DOM 挂载位置，不是组件归属关系。

## Suspense 是什么

- `Suspense` 用来处理异步组件或异步 `setup` 的加载占位。
- 它让你在异步内容未就绪时先显示 fallback。

```vue
<Suspense>
  <AsyncPanel />
  <template #fallback>loading...</template>
</Suspense>
```

- 常见追问：它更偏渲染层协作，不是通用异步管理方案。

## 一张表看区别

| 能力      | 核心问题 | 常见场景             |
| --------- | -------- | -------------------- |
| Slots     | 内容分发 | 通用组件封装         |
| KeepAlive | 组件缓存 | Tab、动态组件切换    |
| Teleport  | 跨层挂载 | Modal、Drawer、Toast |
| Suspense  | 异步占位 | 异步组件、异步 setup |

## 常见误区

- 以为 `Teleport` 会让组件脱离当前响应式上下文。
- 对所有动态组件都套 `KeepAlive`，导致缓存失控。
- 把 `Suspense` 当成接口请求状态管理替代品。
