# Vue Router 面试高频问题

## 阅读建议

- 重点回答“路由系统如何组织页面状态与导航行为”。

## 高频问题

### hash 和 history 模式有什么区别

- hash 模式基于 URL `#`，部署简单。
- history 模式 URL 更自然，但服务端要做好回退配置。

### 路由守卫怎么答

- 先说分类：全局守卫、路由独享守卫、组件内守卫。
- 再说用途：鉴权、埋点、条件跳转、离开确认。

### 动态路由和懒加载为什么常一起问

- 一个关注“路由结构如何扩展”，一个关注“资源如何按需加载”。
