# Pinia 面试高频问题

## 阅读建议

- 重点回答“为什么用 Pinia，以及它怎样组织状态”。

## 高频问题

### 为什么 Vue3 更推荐 Pinia

- API 更贴近 Composition API。
- 类型支持和模块组织更自然。

### `state`、`getters`、`actions` 怎么区分

- `state` 管数据
- `getters` 管派生结果
- `actions` 管业务操作和异步逻辑

### 为什么不要把所有东西都塞进全局状态

- 全局状态越大，维护边界越差。
- 应该优先区分页面局部状态和跨页面共享状态。
