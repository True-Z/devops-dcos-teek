# 解构赋值原理与4种形式

## 阅读建议

- 这页重点不是背语法，而是把数组解构和对象解构背后的取值逻辑区分清楚。

## 核心目标

- 看完后能知道 `[] = []`、`{} = {}`、`[] = {}`、`{} = []` 这几种形式为什么表现不同。

## 先记住两个核心逻辑

| 左边模式      | 右边需要什么 | 本质           |
| ------------- | ------------ | -------------- |
| 数组解构 `[]` | 可迭代值     | 按迭代顺序取值 |
| 对象解构 `{}` | 可转对象的值 | 按属性名取值   |

## 4 种形式怎么区分

| 写法                        | 是否可行 | 原因                             |
| --------------------------- | -------- | -------------------------------- |
| `const [a] = [1]`           | 可以     | 右边数组可迭代，按位置取值       |
| `const { a } = { a: 1 }`    | 可以     | 右边对象可按属性名取值           |
| `const [a] = { a: 1 }`      | 不行     | 普通对象不是可迭代值             |
| `const { length } = [1, 2]` | 可以     | 数组本质也是对象，可按属性名取值 |

## 外在表现形式

```js
const [a, b] = [1, 2]
const { x, y } = { x: 1, y: 2 }
const { length } = [1, 2, 3]
```

## 内部原理怎么理解

### 数组解构

- 看起来是按下标取值。
- 更准确地说，是按迭代顺序取值。
- 所以右边必须是可迭代对象，比如数组、字符串、Set。

### 对象解构

- 按属性名取值。
- 右边只要能当对象看待，就能解构属性。
- 所以数组也能被对象解构，因为数组也有属性，比如 `length`。

## 最小示例

```js
const [a] = 'hi'
const { length } = 'hi'
```

## 报错 / undefined / 默认值 对照表

| 写法                        | 结果            | 为什么                           |
| --------------------------- | --------------- | -------------------------------- |
| `const [a] = [1]`           | `a = 1`         | 数组可迭代，正常按顺序取值       |
| `const [a] = []`            | `a = undefined` | 没有第一个值，但解构本身成立     |
| `const [a = 10] = []`       | `a = 10`        | 取到的是 `undefined`，触发默认值 |
| `const [a] = { a: 1 }`      | 报错            | 普通对象不可迭代                 |
| `const { a } = {}`          | `a = undefined` | 对象解构成功，只是没这个属性     |
| `const { a = 10 } = {}`     | `a = 10`        | 属性值是 `undefined`，触发默认值 |
| `const { length } = [1, 2]` | `length = 2`    | 数组也是对象，可按属性取值       |
| `const { a } = null`        | 报错            | `null` 不能转成对象              |

## 什么时候是报错，什么时候是 `undefined`

| 情况                                           | 结果        |
| ---------------------------------------------- | ----------- |
| 解构模式本身不成立                             | 报错        |
| 解构模式成立，但值没取到                       | `undefined` |
| 解构模式成立，且值为 `undefined`，又写了默认值 | 走默认值    |

## 最小理解

```js
const [a = 1] = []
const { b = 2 } = {}
```

- 这两种都不会报错，因为左边的解构模式是成立的。
- 只是右边没拿到对应值，所以落到默认值。

## 常见误区

- 以为数组解构就是“按下标”这么简单，忽略了迭代器。
- 以为对象解构右边必须是普通对象，忽略了数组也能按属性取值。
- 把“解构形式相似”误当成“内部逻辑相同”。
