# JavaScript 手写题高频问题

## 阅读建议

- 手写题不要一上来追求完整版，先写最小可运行版本，再补边界条件。
- 面试官更关注你是否理解原理与取舍，而不是背出某个固定模板。

## 最常见的手写题有哪些

| 类型     | 高频题目                          | 重点考什么                   |
| -------- | --------------------------------- | ---------------------------- |
| 函数工具 | `debounce`、`throttle`、`compose` | 定时器控制、参数透传、`this` |
| 异步控制 | `Promise.all`、并发控制器         | 状态收敛、失败处理、边界条件 |
| 对象处理 | 深拷贝、`new`、`instanceof`       | 原型链、引用类型、递归       |
| 函数机制 | `call`、`apply`、`bind`           | `this` 绑定、参数处理        |
| 设计模式 | 柯里化、发布订阅                  | 函数组合、解耦               |

## 面试怎么答手写题

1. 先说输入输出和边界条件。
2. 再写最小可运行版本。
3. 最后补异常处理、`this`、参数、性能等增强点。

## `debounce`

```js
function debounce(fn, wait) {
  let timer = null

  return function (...args) {
    clearTimeout(timer)
    timer = setTimeout(() => {
      fn.apply(this, args)
    }, wait)
  }
}
```

- 追问点：立即执行版怎么写、组件卸载怎么清理、`this` 和参数怎么保持。

## `throttle`

```js
function throttle(fn, wait) {
  let lastTime = 0

  return function (...args) {
    const now = Date.now()
    if (now - lastTime >= wait) {
      lastTime = now
      fn.apply(this, args)
    }
  }
}
```

- 追问点：尾调用补发怎么做、时间戳版和定时器版差异是什么。

## 手写 `new`

```js
function mockNew(Constructor, ...args) {
  const instance = Object.create(Constructor.prototype)
  const result = Constructor.apply(instance, args)

  return result !== null && (typeof result === 'object' || typeof result === 'function') ? result : instance
}
```

- 追问点：为什么要连到 `Constructor.prototype`、构造函数显式返回对象时会发生什么。

## 手写 `instanceof`

```js
function mockInstanceof(obj, Constructor) {
  if (obj === null || (typeof obj !== 'object' && typeof obj !== 'function')) return false

  let current = Object.getPrototypeOf(obj)
  while (current) {
    if (current === Constructor.prototype) return true
    current = Object.getPrototypeOf(current)
  }

  return false
}
```

- 追问点：本质是在沿原型链查找 `Constructor.prototype`。

## 手写 `Promise.all`

```js
function mockPromiseAll(list) {
  return new Promise((resolve, reject) => {
    const result = []
    let count = 0

    if (list.length === 0) {
      resolve([])
      return
    }

    list.forEach((item, index) => {
      Promise.resolve(item).then(
        (value) => {
          result[index] = value
          count += 1
          if (count === list.length) resolve(result)
        },
        (error) => reject(error),
      )
    })
  })
}
```

- 追问点：为什么要保序、为什么要用 `Promise.resolve` 包一层、失败时为什么直接 reject。

## 手写 `call`

```js
Function.prototype.mockCall = function (context, ...args) {
  const ctx = context == null ? window : Object(context)
  const key = Symbol('fn')
  ctx[key] = this
  const result = ctx[key](...args)
  delete ctx[key]
  return result
}
```

- 追问点：为什么要临时挂载函数、为什么要处理 `null/undefined`、原始值为什么要装箱。

## 手写 `apply`

```js
Function.prototype.mockApply = function (context, args = []) {
  const ctx = context == null ? window : Object(context)
  const key = Symbol('fn')
  ctx[key] = this
  const result = ctx[key](...args)
  delete ctx[key]
  return result
}
```

- 追问点：和 `call` 的核心差异只在参数组织方式。

## 手写 `bind`

```js
Function.prototype.mockBind = function (context, ...presetArgs) {
  const fn = this

  return function (...laterArgs) {
    return fn.apply(context, [...presetArgs, ...laterArgs])
  }
}
```

- 追问点：完整版还要考虑构造调用场景，也就是 `new (fn.bind(...))()`。

## 手写柯里化

```js
function curry(fn, ...args) {
  return function (...restArgs) {
    const allArgs = [...args, ...restArgs]
    return allArgs.length >= fn.length ? fn(...allArgs) : curry(fn, ...allArgs)
  }
}
```

- 追问点：为什么用 `fn.length`、可变参数函数为什么会让这个判断变得不稳定。

## 手写发布订阅

```js
function createEventBus() {
  const events = new Map()

  return {
    on(event, handler) {
      const list = events.get(event) || []
      list.push(handler)
      events.set(event, list)
    },
    emit(event, ...args) {
      const list = events.get(event) || []
      list.forEach((handler) => handler(...args))
    },
    off(event, handler) {
      const list = events.get(event) || []
      events.set(
        event,
        list.filter((item) => item !== handler),
      )
    },
  }
}
```

- 追问点：如何支持 `once`、如何避免重复订阅、如何防止事件总线变成全局污染源。

## 练手优先级

- 第一梯队：`debounce`、`throttle`、深拷贝、`Promise.all`
- 第二梯队：`call/apply/bind`、`new`、`instanceof`
- 第三梯队：并发控制器、柯里化、发布订阅
