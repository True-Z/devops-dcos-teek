# Web 简介

Web 模块更偏“浏览器与网络协作机制”，适合把请求、缓存、安全、存储、性能串成一条链路去理解。

## 推荐阅读

- [Web 速查要点](/fe/web-core-point)
- [Web 原理与机制](/fe/web-point)
- [Web 渲染流程与关键渲染路径](/fe/web-rendering-critical-path)
- [Web 浏览器存储方案](/fe/web-storage-strategy)
- [Web 跨域与安全方案](/fe/web-cors-security)
- [Web 性能指标与优化路径](/fe/web-performance-path)

## 学习路径

1. 先看 `Web 速查要点`，建立请求链路、缓存、安全、性能的总视角。
2. 再看 `Web 原理与机制`，补 DNS、HTTP 缓存、渲染等细节。
3. 最后进入存储、安全、性能这些专题页。

## 最小理解示例

```text
输入 URL -> 建立连接 -> 请求资源 -> 浏览器解析 -> 页面渲染
```
