# HTML SEO 与结构化数据

## SEO 基础目标

- 让搜索引擎能“抓到、看懂、正确展示”页面。

## 页面基础要点

- `title` 与 `description` 唯一且有信息量。
- 合理层级标题结构（`h1-h6`），避免跳级混乱。
- 关键内容优先出现在首屏可见区域。
- 图片补充 `alt`，增强语义信息。

## 结构化数据（Schema）

| 场景     | 常用类型                   | 价值                 |
| -------- | -------------------------- | -------------------- |
| 文章页   | `Article`                  | 提升摘要展示质量     |
| 产品页   | `Product`                  | 价格、评分等增强展示 |
| 面包屑   | `BreadcrumbList`           | 提升结果页可读性     |
| 网站信息 | `Organization` / `WebSite` | 提升站点识别度       |

## 实施建议

- 先做基础 SEO（标题、描述、语义结构），再补 Schema。
- 每次改版检查是否破坏原有可抓取路径。
- 发布后关注抓取与索引状态，持续修正。
