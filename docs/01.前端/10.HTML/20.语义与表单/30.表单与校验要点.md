# HTML 表单与校验要点

## 表单设计目标

- 让用户“低成本输入、低成本纠错”。
- 让前后端“同口径校验、可追踪错误”。

## 字段设计建议

| 场景      | 建议                | 目的               |
| --------- | ------------------- | ------------------ |
| 邮箱/电话 | 使用语义类型        | 提升移动端输入体验 |
| 必填项    | 明确标识 + 即时反馈 | 降低提交后返工     |
| 长文本    | 显示剩余/已输入字数 | 减少超限失败       |
| 敏感输入  | 支持显隐切换        | 降低输错概率       |

## 常见 `input type` 速查

| `type`           | 适用场景   | 原生能力           | 常见注意点                         |
| ---------------- | ---------- | ------------------ | ---------------------------------- |
| `text`           | 通用文本   | 基础输入           | 默认类型，需自己控制语义           |
| `password`       | 密码       | 隐藏输入内容       | 仍需后端安全校验                   |
| `email`          | 邮箱       | 邮箱格式校验       | 只做基础格式判断，不保证真实可用   |
| `number`         | 数值       | 数值输入、步进     | 不适合手机号、身份证等“数字字符串” |
| `tel`            | 电话       | 移动端数字键盘友好 | 不做严格格式校验                   |
| `url`            | 链接       | URL 格式基础校验   | 需结合业务做协议限制               |
| `search`         | 搜索框     | 搜索语义           | 更多是语义与体验优化               |
| `date`           | 日期       | 原生日历控件       | 不同浏览器表现不完全一致           |
| `time`           | 时间       | 原生时间控件       | 需提前确认时区与格式口径           |
| `datetime-local` | 日期时间   | 日期时间控件       | 不包含时区信息                     |
| `checkbox`       | 多选       | 勾选态             | 需明确默认值与提交值               |
| `radio`          | 单选       | 互斥选择           | 同组必须共用 `name`                |
| `file`           | 文件上传   | 文件选择           | 需额外校验大小、类型、数量         |
| `hidden`         | 隐藏值传递 | 隐藏字段           | 仅用于辅助传值，不能信任其安全性   |

## 校验策略

- 前端校验：提升交互体验，尽早提示问题。
- 后端校验：最终兜底，防止绕过前端校验。
- 错误提示要可执行：告诉用户“哪里错、怎么改”。

## 提交行为建议

- 防重复提交：按钮 loading 与幂等处理配套。
- 失败可恢复：保留用户输入，不清空表单。
- 成功有反馈：成功提示 + 后续动作明确（跳转/留在当前页）。

## 最小示例

```html
<form>
  <label for="email">邮箱</label>
  <input id="email" type="email" required />

  <label for="phone">手机号</label>
  <input id="phone" type="tel" autocomplete="tel" />

  <label for="birthday">生日</label>
  <input id="birthday" type="date" />

  <button type="submit">提交</button>
</form>
```

- 这个示例体现了 3 个核心点：`label` 关联、语义化 `type`、原生 `required` 校验。
- 如果要看完整规则，可继续阅读 [MDN 表单](https://developer.mozilla.org/zh-CN/docs/Learn/Forms) 与 [Constraint validation](https://developer.mozilla.org/en-US/docs/Web/HTML/Constraint_validation)。
