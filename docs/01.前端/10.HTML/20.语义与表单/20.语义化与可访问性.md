# HTML 语义化与可访问性

## 为什么重要

- 语义化让页面结构更清晰，利于维护、SEO 和团队协作。
- 可访问性（a11y）让键盘用户、读屏用户也能完成核心操作。

## 最小语义化清单

| 区域     | 推荐标签  | 说明               |
| -------- | --------- | ------------------ |
| 页面头部 | `header`  | 页面级头部信息     |
| 导航区域 | `nav`     | 主导航/次导航      |
| 主体内容 | `main`    | 一个页面只建议一个 |
| 内容区块 | `section` | 有主题的分块       |
| 独立内容 | `article` | 可单独分发的内容   |
| 侧边信息 | `aside`   | 推荐、补充信息     |

## 最小可访问性清单

- 所有表单控件都要有可读标签（`label` 或等价语义）。
- 非装饰图片必须有 `alt`；纯装饰图使用空 `alt`。
- 交互优先原生控件（如 `button`），避免用 `div` 模拟按钮。
- 键盘可达：Tab 可聚焦、焦点可见、Enter/Space 可触发关键动作。

## 常见问题

- 视觉正确但语义错误：大量 `div` 造成结构不可读。
- 仅鼠标可用：键盘无法操作弹层、菜单、表单。
- 仅颜色传达状态：色盲用户无法辨别，需增加文案或图标。
