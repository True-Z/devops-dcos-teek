# TypeScript 基础泛型工具

## 阅读建议

- 这页重点不是死记工具名，而是理解这些工具类型到底在帮我们“改造什么类型”。

## 核心目标

- 看完后能知道常见泛型工具是怎么对对象、属性和联合类型做加工的。

## 一张表先看用途

| 工具            | 做什么              | 最小理解                 |
| --------------- | ------------------- | ------------------------ |
| `Partial<T>`    | 全部属性变可选      | 先有对象，再放宽必填要求 |
| `Required<T>`   | 全部属性变必填      | 把可选收紧成必填         |
| `Readonly<T>`   | 全部属性只读        | 防止后续再改             |
| `Pick<T, K>`    | 只挑一部分属性      | 从大对象里摘一块         |
| `Omit<T, K>`    | 去掉一部分属性      | 从大对象里删一块         |
| `Record<K, T>`  | 用一组 key 生成对象 | 批量生成同结构字段       |
| `Exclude<T, U>` | 从联合中排除一部分  | 做减法                   |
| `Extract<T, U>` | 从联合中提取一部分  | 做交集式筛选             |

## 最小示例

```ts
type User = {
  id: number
  name: string
  age?: number
}

type UserPatch = Partial<User>
type UserView = Readonly<User>
type UserNameOnly = Pick<User, 'name'>
```

## 这些工具的原理感怎么理解

- 对象类工具，很多本质上是在“重新映射属性”。
- 联合类工具，很多本质上是在“对联合类型做筛选”。
- 它们厉害的地方不是语法花哨，而是能把重复类型规则集中表达出来。

## 为什么这些工具重要

| 场景           | 为什么会用到         |
| -------------- | -------------------- |
| 更新接口参数   | 常常只传部分字段     |
| 只读展示数据   | 不希望被误改         |
| 大对象拆小对象 | 只关心局部字段       |
| 联合类型筛选   | 想精确拿到一部分类型 |

## 常见误区

- 会用 `Partial`，但不知道它是在放宽约束。
- 把工具类型当模板套，不理解它改了哪些边界。
- 一看到泛型工具就觉得很高级，其实很多只是“批量改类型”。
