# TypeScript 类型体操常见模式

## 阅读建议

- 这页重点不是刷题，而是把常见“类型体操”模式抽成几个固定套路，方便后面看复杂类型时快速识别。

## 核心目标

- 看完后能知道很多复杂类型，其实只是在重复几种模式：判断、提取、映射、递归、拼接。

## 常见模式一览

| 模式     | 在做什么               | 常见写法                    |
| -------- | ---------------------- | --------------------------- |
| 条件判断 | 判断类型是否满足某条件 | `T extends U ? X : Y`       |
| 类型提取 | 从已有类型中抽出一部分 | `infer`                     |
| 属性映射 | 批量改对象属性         | `[K in keyof T]`            |
| 联合分发 | 对联合类型逐个处理     | `T extends ... ? ... : ...` |
| 递归展开 | 一层层处理嵌套结构     | 条件类型递归                |
| 模板拼接 | 处理字符串字面量类型   | `` `${A}-${B}` ``           |

## 最小示例

```ts
type ElementType<T> = T extends Array<infer U> ? U : T

type ReadonlyPartial<T> = {
  readonly [K in keyof T]?: T[K]
}
```

## 怎么理解这些模式

### 条件判断

- 本质是类型层 if。

### 类型提取

- 本质是把目标类型中的一部分名字先起出来。

### 属性映射

- 本质是遍历对象每个 key，再重新组装一遍。

### 递归展开

- 本质是“当前层处理完，再继续处理下一层”。

## 为什么会觉得难

- 因为很多写法把几种模式叠在一起了。
- 一旦你能拆出“这里在判断”“这里在提取”“这里在递归”，理解就会快很多。

## 常见误区

- 一看到长类型就觉得是全新知识。
- 不先拆模式，直接硬读整段类型。
- 把类型体操当成语法记忆题，而不是结构识别题。
