# TypeScript 简介

TypeScript 模块主要围绕泛型、类型推断、约束关系、收紧与放宽等核心能力展开，重点不是只记语法，而是理解它为什么能在编译期帮助我们把问题提早暴露出来。

- [类型是如何确定约束收紧与放宽的](/fe/typescript-inference-constraint-narrow-widen)
- [条件类型与 infer](/fe/typescript-conditional-infer)
- [类型体操常见模式](/fe/typescript-type-patterns)

## 学习路径

1. 先理解泛型工具在做什么。
2. 再理解类型是怎么推断、约束和变化的。
3. 最后再看更偏技巧性的泛型实现，比如柯里化与递归推导。

## 最小理解示例

```text
先有值和结构 -> 再推断类型 -> 再做约束和收窄
```
