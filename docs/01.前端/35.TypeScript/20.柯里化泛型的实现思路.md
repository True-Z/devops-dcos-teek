# TypeScript 柯里化泛型的实现思路

## 阅读建议

- 这页重点不是做类型体操表演，而是理解值层柯里化和类型层柯里化怎么一一对应。

## 核心目标

- 看完后能知道多参数函数为什么能一步步拆成单参数函数，以及 TypeScript 怎么把这个过程表示出来。

## 先区分两层

| 层级   | 是什么                               |
| ------ | ------------------------------------ |
| 值层   | 函数一次收一个参数，逐步返回新函数   |
| 类型层 | 根据参数列表递归推导出下一层函数类型 |

## 最小值层示例

```ts
const add = (a: number) => (b: number) => a + b
```

## 最小类型层示例

```ts
type Curry<T> = T extends (arg: infer A, ...rest: infer R) => infer Ret ? (R['length'] extends 0 ? (arg: A) => Ret : (arg: A) => Curry<(...args: R) => Ret>) : never
```

## 这段类型在做什么

1. 先判断 `T` 是不是函数。
2. 用 `infer` 拿到第一个参数 `A`。
3. 再拿到剩余参数 `R`。
4. 如果没有剩余参数，就返回最后一层函数。
5. 如果还有参数，就继续递归。

## 为什么这里会用到泛型

- 因为参数个数和类型不是写死的。
- 泛型的作用就是把“未知但有规律”的类型结构抽出来。
- 柯里化泛型的本质，就是把函数参数列表递归拆开。

## 常见误区

- 只看 `infer` 语法，不看整体递归逻辑。
- 把值层柯里化和类型层柯里化混成一件事。
- 一开始就想写超复杂版本，反而看不清基本思路。
