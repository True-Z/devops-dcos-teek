# 音准与节奏基础

## 阅读建议

- 这页只讲业余入门最需要的部分：先唱准、跟稳，再谈更多技巧。

## 核心目标

- 建立最基础的唱歌稳定性：音不要飘太多，节奏不要总抢或总慢。

## 音准怎么理解

- 音准可以先理解成：该高的时候高，该低的时候低，不明显跑掉。
- 对业余入门来说，先“接近正确”比一开始追求很准更现实。

## 节奏怎么理解

- 节奏可以先理解成：跟着拍子走，不抢拍，也不拖拍。
- 很多时候不是不会唱，而是没跟稳节奏。

## 最小练习顺序

1. 先听原音。
2. 再跟着轻声唱。
3. 先练短句，不先练整首。
4. 先把拍子跟住，再管情绪表达。

## 最小示例

```text
先听一句 -> 跟一句 -> 停一下 -> 再重复
```

## 入门建议

| 方向 | 更稳的做法                   |
| ---- | ---------------------------- |
| 音准 | 先唱简单旋律，先别硬冲高音   |
| 节奏 | 跟伴奏、跟节拍器、跟原唱轻唱 |
| 练习 | 一次只练一小段               |

## 常见误区

- 一开始就整首反复硬唱。
- 音准不稳时还只顾着放大声音。
- 节奏没跟住就急着加感情。
