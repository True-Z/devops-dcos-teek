# 气息与发声练习

## 阅读建议

- 这页面向业余入门，重点不是专业技巧，而是让你唱得更稳、更自然、少用嗓子硬顶。

## 核心目标

- 建立最基础的唱歌习惯：先稳气息，再稳发声，再唱完整短句。

## 为什么先练气息和发声

- 因为业余唱歌最常见的问题，不是技巧太少，而是声音不稳、气不够、嗓子太用力。
- 气息和发声稳定后，唱歌会更轻松，也更不容易费嗓子。

## 最小练习顺序

1. 先放松身体和喉咙。
2. 先练平稳呼气。
3. 再练简单发声。
4. 最后再唱短句。

## 基础练习示例

| 练习        | 怎么做             | 目标               |
| ----------- | ------------------ | ------------------ |
| 呼气练习    | 吸气后慢慢均匀呼出 | 先把气息放稳       |
| `si` / `s`  | 轻声持续吐气       | 感受气息持续性     |
| `ma` / `na` | 轻声发音，不用力顶 | 感受自然发声       |
| 短句练习    | 先唱很短的句子     | 练稳定而不是练高音 |

## 最小示例

```text
吸气 -> 慢慢呼气 -> 轻声发 ma -> 再唱一句短句
```

## 练的时候注意什么

- 不要一开始就唱很大声。
- 不要用喉咙硬挤声音。
- 如果嗓子紧，就先停下来。

## 常见误区

- 把“唱大声”当成“唱得好”。
- 气息不稳时硬上高音。
- 一练就练很久，嗓子先累坏。
