# 开嗓与练声基础

## 阅读建议

- 这页面向业余入门，重点不是练高难技巧，而是让嗓子进入状态，减少一开口就发紧。

## 核心目标

- 建立最小开嗓习惯：先放松，再轻声发音，再进入简单练声，不硬顶嗓子。

## 最小顺序

1. 先放松肩颈和嘴巴。
2. 先做轻声发音。
3. 再做简单音阶或短音练习。
4. 最后再进入歌曲。

## 最小示例

```text
放松 -> 呼气 -> 轻声哼鸣 -> 简单发声 -> 再唱歌
```

## 开嗓怎么做

| 步骤 | 做法                             |
| ---- | -------------------------------- |
| 放松 | 活动肩颈，放松下巴和嘴角         |
| 哼鸣 | 用轻声哼，不要一开始就大声       |
| 发声 | 用 `ma`、`na`、`mi` 这类简单音节 |
| 练声 | 先做短音，再做简单上行下行       |

## 注意点

- 开嗓不是比音量。
- 嗓子紧时先停，不继续硬唱。
- 先求自然，再求更多技巧。

## 常见误区

- 一上来就直接唱高音。
- 开嗓时太大声，反而把嗓子唱紧。
- 练声时间过长，嗓子先疲劳。
