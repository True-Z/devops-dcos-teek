# 初次接触与破冰模板

## 阅读建议

- 这页重点不是显得很会聊天，而是让第一次开口没那么僵，先把气氛打开一点。

## 核心目标

- 让你在第一次接触、陌生场合、轻社交场景里，有几个自然开口的方式。

## 常见场景

| 场景       | 模板                             |
| ---------- | -------------------------------- |
| 第一次见面 | 你好，刚认识一下，我是……         |
| 找共同点   | 你刚才提到这个，我也有点兴趣。   |
| 轻松开场   | 这里氛围还挺轻松的。             |
| 不知道说啥 | 我先随便开个头，不然有点安静了。 |

## 发言模板

```text
你好，我是……
你刚才提到这个，我也有点兴趣。
我先随便开个头。
```

## 常见误区

- 一上来就问太私人。
- 为了不冷场，话说太满。
- 破冰变成尬聊硬撑。
