# 工作沟通发言模板

## 阅读建议

- 这页重点不是让表达变官话，而是让工作场景里的表达更清楚、更有边界、更容易协作。

## 核心目标

- 让你在汇报、提需求、反馈问题、提建议时，先有一套稳定表达框架。

## 常见场景

| 场景     | 模板                                         |
| -------- | -------------------------------------------- |
| 汇报进度 | 现在进度到这一步，剩下两个点还在处理。       |
| 反馈问题 | 目前这里有一个具体问题，我先说现象和影响。   |
| 提建议   | 我有一个建议，你看是否值得试一下。           |
| 说明风险 | 这个方案能做，但这里有一个风险点需要先说明。 |

## 发言模板

```text
我先同步一下当前情况。
我先说结论，再说原因。
这里我有一个建议，你看是否合适。
这个方案可以推进，但有一个风险点需要先确认。
```

## 常见误区

- 汇报时全说过程，不先说结论。
- 提问题只发情绪，不说现象和影响。
- 提建议像直接下指令。
