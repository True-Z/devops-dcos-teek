# 安慰与缓和气氛模板

## 阅读建议

- 这页重点不是说漂亮话，而是让对方先感到被接住，气氛先缓下来。

## 核心目标

- 让你在对方情绪重、气氛紧、需要安慰时，有更稳的表达模板可用。

## 常见场景

| 场景     | 模板                                         |
| -------- | -------------------------------------------- |
| 对方难受 | 我理解你现在不好受，先别急，我们慢一点说。   |
| 对方自责 | 先别急着全怪自己，我们先看具体哪里出了问题。 |
| 气氛紧张 | 我们先把情绪放一下，先看问题本身。           |
| 对方失落 | 这件事确实不容易，你先缓一下。               |

## 发言模板

```text
我理解你现在不太舒服。
我们先慢一点，不急着下结论。
这件事先别全压在自己身上。
我们先把问题拆开来看。
```

## 常见误区

- 对方还没被接住，就急着讲道理。
- 安慰时直接说“这有什么”。
- 气氛刚紧张，就马上开始分对错。
