# 被否定时怎么稳住表达模板

## 阅读建议

- 这页重点不是教你硬顶回去，而是让你在被否定时先稳住，不让表达直接失控。

## 核心目标

- 让你先分清对方否定的是观点、做法，还是人在情绪上给的判断。

## 常见场景

| 场景         | 模板                                               |
| ------------ | -------------------------------------------------- |
| 对方直接否定 | 我先听到了你的否定点，我想把我的理由补完整。       |
| 方案被否掉   | 如果这个方案不合适，我们可以一起看替代方案。       |
| 自己有情绪   | 我先缓一下，再把这个点说清楚。                     |
| 对方否定很重 | 我们先拆开看，是这个方案不合适，还是执行上有问题。 |

## 发言模板

```text
我先听到了你的否定点。
我把我的理由补完整一下。
如果这个方案不合适，我们可以换个方向看。
```

## 常见误区

- 把被否定直接等同于自己被全盘否定。
- 一急就开始自我辩护。
- 对方还在说，你已经先炸了。
