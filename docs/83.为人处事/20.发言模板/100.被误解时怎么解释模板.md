# 被误解时怎么解释模板

## 阅读建议

- 这页重点不是证明自己没错，而是尽快把误解点说清楚，减少继续发散。

## 核心目标

- 让你在被误解时，能快速切回“原话、原意、边界”这三件事。

## 常见场景

| 场景           | 模板                                     |
| -------------- | ---------------------------------------- |
| 话被理解偏     | 我解释一下，我刚才想表达的重点不是那个。 |
| 对方带情绪理解 | 我先把原意说清，再看哪里让你不舒服。     |
| 群里误会       | 我补一句背景，避免大家理解偏。           |
| 自己表达不清   | 可能是我刚才没说清，我重新讲一遍。       |

## 发言模板

```text
我解释一下，我刚才的重点不是那个。
可能是我刚才没表达清楚，我重新说一遍。
我先把原意补完整。
```

## 常见误区

- 一上来先怪对方听不懂。
- 解释时越说越散。
- 明明是误解，却说成对方故意针对。
