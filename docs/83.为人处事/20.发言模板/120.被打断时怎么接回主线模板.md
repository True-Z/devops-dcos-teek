# 被打断时怎么接回主线模板

## 阅读建议

- 这页重点不是争谁说得久，而是让你在被打断后还能把主线接回来。

## 核心目标

- 让你在对话被打断时，能礼貌但明确地把自己的主线说完。

## 常见场景

| 场景           | 模板                                     |
| -------------- | ---------------------------------------- |
| 会议里被打断   | 我先把这一句说完，再接你的点。           |
| 日常聊天被打断 | 你这个点我听到了，我先把前面那半句补完。 |
| 对方频繁插话   | 我先把主线说清，然后我们逐个看。         |
| 自己节奏乱了   | 我重新收一下，刚才我想说的是这三点。     |

## 发言模板

```text
我先把这句说完。
你这个点我记住了，我先把前面补完。
我重新收一下主线。
```

## 常见误区

- 一被打断就彻底丢主线。
- 为了抢回话语权，语气一下变冲。
- 被带着走，最后自己原本要说什么都忘了。
