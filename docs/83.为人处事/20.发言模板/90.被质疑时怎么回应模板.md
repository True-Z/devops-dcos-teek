# 被质疑时怎么回应模板

## 阅读建议

- 这页重点不是反击，而是让你在被质疑时先稳住节奏，把问题拉回事实和逻辑。

## 核心目标

- 让你在面对质疑时，不先被情绪带走，而是先确认问题点，再回应。

## 常见场景

| 场景         | 模板                                         |
| ------------ | -------------------------------------------- |
| 对方质疑做法 | 我先确认一下，你质疑的重点是这个环节，对吗？ |
| 对方质疑能力 | 这个点我先不按人来聊，我们先看具体问题。     |
| 对方语气冲   | 我先回应核心问题，情绪部分我们可以后面再说。 |
| 自己被误判   | 我补充一下背景，不然这里容易理解偏。         |

## 发言模板

```text
我先确认一下你质疑的重点。
我们先回到具体问题本身。
这个地方我补充一个事实。
```

## 常见误区

- 一被质疑就急着自证。
- 直接把讨论升级成人身对抗。
- 对方还没说清，你已经开始反击。
