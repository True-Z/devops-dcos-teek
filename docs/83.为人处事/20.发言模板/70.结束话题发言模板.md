# 结束话题发言模板

## 阅读建议

- 这页重点不是冷场，而是把不想继续展开的话题稳稳收住。

## 核心目标

- 让你在不方便继续聊、觉得已经说够、或者不想再展开时，能自然收口。

## 常见场景

| 场景       | 模板                                   |
| ---------- | -------------------------------------- |
| 不想继续聊 | 这个话题我先不展开了，我们先到这里。   |
| 时间不够   | 我这会儿先不细聊，后面有空再说。       |
| 气氛变重   | 我们先停一下，别越说越偏。             |
| 需要换话题 | 这个点我知道了，我们先回到前面的问题。 |

## 发言模板

```text
这个话题我先收到这里。
我们先别继续往下展开。
先回到眼前更重要的部分。
```

## 常见误区

- 想结束话题却一直解释。
- 收口时带讽刺或不耐烦。
- 明明不想聊，还硬撑着接话。
