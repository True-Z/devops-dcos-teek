# 日常沟通发言模板

## 阅读建议

- 这页重点不是教你背话术，而是给你几个高频场景下更稳的起手方式。

## 核心目标

- 让你在日常沟通里能更自然地开口、接话、提不同看法，而不容易一开始就把气氛弄僵。

## 常见场景

| 场景         | 模板                                           |
| ------------ | ---------------------------------------------- |
| 表达不同意见 | 我理解你的意思，不过这个地方我有一点不同看法。 |
| 提醒别人     | 我提醒你一下，这里可能要注意。                 |
| 接别人话     | 我大概明白你的意思了，我补充一个点。           |
| 回应误解     | 我解释一下，我刚才的意思不是那个方向。         |

## 发言模板

```text
我理解你的意思。
这个地方我有一点不同看法。
我先补充一个事实。
你看这样理解对不对。
```

## 常见误区

- 一开口就先否定对方。
- 提醒别人时像在指责。
- 一句没接住就急着讲自己的结论。
