# 拒绝与边界表达模板

## 阅读建议

- 这页重点不是让你变冷，而是帮你在不把关系弄僵的前提下，把边界说清楚。

## 核心目标

- 让你在拒绝、推开不合适请求、说明自己边界时，有一套更稳的表达方式。

## 常见场景

| 场景       | 模板                                         |
| ---------- | -------------------------------------------- |
| 不方便帮忙 | 这件事我这次可能帮不上，你最好提前另做安排。 |
| 不想继续聊 | 这个话题我先不展开了，我们先到这里。         |
| 时间不够   | 我现在时间不够，可能没法按你希望的节奏处理。 |
| 越界请求   | 这个部分超出我能接受的范围，我这边先说清楚。 |

## 发言模板

```text
这件事我这次可能做不了。
我先把边界说清楚。
这个部分我不太方便继续。
我理解你的难处，但这次我先不接。
```

## 常见误区

- 拒绝时解释过多，越说越乱。
- 怕尴尬就不说清楚，最后更难收。
- 先答应再反悔。
