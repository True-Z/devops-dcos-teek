# 道歉发言模板

## 阅读建议

- 这页重点不是把道歉说得漂亮，而是把责任、影响和补救说清楚。

## 核心目标

- 让道歉听起来真实、具体、可收尾，而不是空泛地说一句“对不起”。

## 常见场景

| 场景     | 模板                                       |
| -------- | ------------------------------------------ |
| 迟到     | 不好意思，我这次迟到了，是我没安排好时间。 |
| 说重了   | 我刚才话说重了，这点我认。                 |
| 做错事   | 这件事是我处理得不对，我先把问题承担下来。 |
| 影响别人 | 这次确实给你带来影响了，我先跟你道歉。     |

## 发言模板

```text
这件事是我处理得不对。
给你带来影响了，我先道歉。
我接下来会这样补一下。
```

## 常见误区

- 先解释半天，最后才道歉。
- 一边道歉一边推责任。
- 只说情绪，不说补救。
