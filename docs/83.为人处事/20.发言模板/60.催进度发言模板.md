# 催进度发言模板

## 阅读建议

- 这页重点不是催得更硬，而是催得清楚、礼貌、不让协作关系立刻变差。

## 核心目标

- 让你在需要推进事情时，能把时间点、状态和期望说清楚。

## 常见场景

| 场景     | 模板                                                 |
| -------- | ---------------------------------------------------- |
| 跟进工作 | 我跟进一下这个事情，现在进度大概到哪一步了？         |
| 临近截止 | 这个时间点快到了，我确认一下现在是否还能按计划推进。 |
| 提醒回复 | 我补问一下，上条消息你那边方便看一下吗？             |
| 确认阻塞 | 如果现在有卡点，你也可以直接告诉我。                 |

## 发言模板

```text
我跟进一下这个事情。
想确认下现在的进度。
如果有卡点你直接说，我好一起看。
```

## 常见误区

- 上来就质问“怎么还没好”。
- 只催，不给对方说卡点的空间。
- 情绪先于信息。
