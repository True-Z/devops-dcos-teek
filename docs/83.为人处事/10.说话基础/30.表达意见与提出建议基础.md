# 表达意见与提出建议基础

## 阅读建议

- 这页重点不是讲得多厉害，而是让意见更容易被听进去，不一开口就让人起防御心。

## 核心目标

- 建立最小表达顺序：先说事实，再说看法，最后给建议，并且保留余地。

## 最小顺序

1. 先确认对方是否愿意听。
2. 先说观察到的事实。
3. 再说自己的判断和建议。
4. 最后给对方保留选择空间。

## 常见场景

| 场景       | 更稳的做法             |
| ---------- | ---------------------- |
| 提意见     | 先讲事实，再讲看法     |
| 给建议     | 先询问是否愿意听       |
| 不同意见   | 先承认差异，再说明理由 |
| 对方不接受 | 先收住，不反复硬推     |

## 最小示例

```text
我有一个想法，你看要不要参考。
这个地方如果换一种做法，可能会更顺一点。
我只是提个建议，你自己决定就好。
```

## 常见误区

- 一提建议就像在下结论。
- 对方还没准备好听，就直接开始说教。
- 建议里带太多情绪和优越感。
