# 说话分寸基础

## 阅读建议

- 这页不讲圆滑技巧，重点是让说话更稳一点，少一点冒犯，少一点情绪化。

## 核心目标

- 建立最基础的分寸感：什么该直接说，什么该缓着说，什么不适合当场说。

## 最小原则

1. 说问题时尽量对事，不先对人下判断。
2. 先承认差异，再讲自己的看法。
3. 情绪重的时候先稳节奏，不急着硬碰。

## 常见场景

| 场景       | 更稳的做法               |
| ---------- | ------------------------ |
| 指出问题   | 先说事实，再说建议       |
| 提不同意见 | 先承认差异，再讲原因     |
| 自己不高兴 | 先停一下，再决定怎么表达 |
| 对方情绪重 | 先让对方说完，再处理问题 |

## 最小示例

```text
我理解你的意思。
这个地方我有点不同看法。
我们先看具体问题。
```

## 常见误区

- 一着急就上判断。
- 说问题时夹杂太多情绪词。
- 以为“说得重”才算表达清楚。
