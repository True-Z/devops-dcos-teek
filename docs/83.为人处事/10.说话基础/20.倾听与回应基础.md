# 倾听与回应基础

## 阅读建议

- 这页重点不是“会接话”，而是先学会听清别人到底在说什么，再决定怎么回应。

## 核心目标

- 建立最小倾听顺序：先听内容，再听情绪，最后再组织回应。

## 最小顺序

1. 先听完，不急着抢结论。
2. 先确认自己理解对没对。
3. 再表达看法或给回应。

## 常见场景

| 场景       | 更稳的做法               |
| ---------- | ------------------------ |
| 对方在抱怨 | 先听清重点，不急着讲道理 |
| 对方在解释 | 先确认事实，不急着反驳   |
| 对方情绪重 | 先接住情绪，再看问题     |
| 自己想回应 | 先复述一句，再开始表达   |

## 最小示例

```text
我理解你的意思是……
我先确认一下，我有没有听错。
如果是这样的话，我的想法是……
```

## 常见误区

- 对方还没说完，自己已经开始准备反驳。
- 把“回应”理解成“马上给答案”。
- 只听字面意思，不看对方情绪。
