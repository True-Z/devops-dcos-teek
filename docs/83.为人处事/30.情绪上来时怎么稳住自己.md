# 情绪上来时怎么稳住自己

## 阅读建议

- 这页不讲复杂心理学，重点是遇到情绪明显上来时，先怎么让自己别失控。

## 核心目标

- 建立最小处理顺序：先停、再看、后说，不让情绪直接接管表达和决定。

## 最小处理顺序

1. 先停一下，不急着立刻回。
2. 先分清是“事实问题”还是“情绪反应”。
3. 先把最激烈的话压住，再决定要不要表达。

## 常见场景

| 场景   | 更稳的做法                 |
| ------ | -------------------------- |
| 被误解 | 先解释事实，不先带情绪     |
| 被否定 | 先分清对方否定的是事还是人 |
| 被冒犯 | 先拉开一点节奏             |
| 很委屈 | 先把感受说清，不扩大判断   |

## 最小示例

```text
我现在有点情绪，先缓一下。
我们先把事实讲清楚。
这件事让我不太舒服。
```

## 怎么练

- 平时就练“慢半拍回应”。
- 情绪明显时，先少说一句。
- 先写下来也比马上冲出去更稳。

## 常见误区

- 把“情绪真实”当成“表达方式可以随便”。
- 一上来就给人和事情下结论。
- 事后后悔，但当下完全不做停顿。
