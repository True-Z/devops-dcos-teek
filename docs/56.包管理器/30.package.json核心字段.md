## 核心目标

- 先理解 `package.json` 为什么是 Node 项目的核心配置入口。

## 核心字段速查

| 字段              | 作用        | 常见用途               |
| ----------------- | ----------- | ---------------------- |
| `name`            | 包名/项目名 | 发布与标识项目         |
| `version`         | 版本号      | 依赖管理与发布         |
| `scripts`         | 脚本命令    | 开发、构建、测试       |
| `dependencies`    | 运行时依赖  | 项目运行必须依赖       |
| `devDependencies` | 开发时依赖  | 构建、测试、格式化工具 |
| `exports`         | 导出入口    | 控制包暴露内容         |

## 最小示例

```json
{
  "name": "demo-app",
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  }
}
```

- 对大多数前端项目来说，先理解 `scripts` 和依赖字段就已经足够开始维护项目。
