## 核心目标

- 理解为什么现在很多项目更倾向用 `pnpm` 而不是传统包管理器。

## 核心特点速查

| 特点         | 价值             | 说明                       |
| ------------ | ---------------- | -------------------------- |
| 磁盘占用更省 | 节省依赖空间     | 通过内容寻址和链接复用依赖 |
| 安装更快     | 提升开发效率     | 重复依赖复用更充分         |
| 依赖更严格   | 降低幽灵依赖问题 | 未声明依赖不应被直接使用   |

## 最小示例

```sh
pnpm install
pnpm add axios
pnpm run dev
```

- 这是使用 `pnpm` 的最小闭环：安装、加包、跑脚本。
