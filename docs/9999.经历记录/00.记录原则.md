# 经历记录

经历记录用于单独留存真实发生过的事情、当时的状态、自己的理解，以及后续值得留存的要点。这里不再按知识分类拆分，而是按记录本身持续追加。

## 记录原则

1. 先记事实：发生了什么。
2. 再记状态：当时怎么想、怎么感受。
3. 再记提炼：这件事之后最值得留下什么。
4. 最后记后续：之后准备怎么做。

## 编写提醒

- 记录页优先保证右侧目录展示顺畅，不要堆太多同级标题。
- 个人感悟、补充说明等内容默认降低一层使用，避免打断主线记录。
