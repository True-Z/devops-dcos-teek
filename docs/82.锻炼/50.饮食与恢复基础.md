# 饮食与恢复基础

## 阅读建议

- 这页不讲复杂营养学，重点是先建立“训练、饮食、恢复”三者要配合的最小认知。

## 核心目标

- 明白锻炼效果不只看训练本身，还取决于饮食、补水、睡眠和恢复节奏。

## 最小原则

| 方向   | 最小原则                       |
| ------ | ------------------------------ |
| 吃饭   | 先规律，不暴饮暴食             |
| 蛋白质 | 日常要有基本摄入               |
| 碳水   | 运动前后提供能量               |
| 补水   | 运动前中后都要注意             |
| 睡眠   | 恢复质量直接影响下一次训练状态 |

## 训练前后怎么做

| 时间点 | 建议                         |
| ------ | ---------------------------- |
| 训练前 | 不要太饿也不要太饱，适当补水 |
| 训练中 | 时间长或出汗多时及时补水     |
| 训练后 | 正常吃饭、补水、适当休息     |

## 恢复怎么理解

1. 恢复不是偷懒，是训练的一部分。
2. 长期疲劳、睡眠差、连续酸痛，往往说明恢复不够。
3. 恢复做得好，后续训练更稳定，也更不容易受伤。

## 最小示例

```text
训练 -> 补水 -> 正常吃饭 -> 睡够 -> 第二天再看状态
```

## 常见误区

- 只关注训练，不关注吃饭和睡觉。
- 练完很累就乱吃或不吃。
- 身体明显疲劳还继续硬练。
