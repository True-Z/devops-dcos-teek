# 每周锻炼计划模板

## 阅读建议

- 这页重点不是把一周排得很满，而是让锻炼有节奏、有恢复、有记录。

## 核心目标

- 帮你把跑步、羽毛球和基础身体训练安排进一周，同时避免过量和受伤。

## 一周最小模板

| 时间段 | 建议安排                           |
| ------ | ---------------------------------- |
| 周一   | 轻量活动或休息，做拉伸和活动度练习 |
| 周二   | 跑步或基础有氧                     |
| 周三   | 上肢/核心/下肢基础训练             |
| 周四   | 休息或轻量恢复                     |
| 周五   | 羽毛球或另一项运动                 |
| 周末   | 1 次较完整训练 + 1 次恢复/散步     |

## 适合日常入门的安排

| 方向     | 一周建议次数 | 说明                     |
| -------- | ------------ | ------------------------ |
| 跑步     | 1 到 3 次    | 先建立节奏，不先追求距离 |
| 羽毛球   | 1 到 2 次    | 先控制时长和强度         |
| 基础训练 | 2 到 3 次    | 胸肩背、腿臀、核心轮换   |
| 拉伸恢复 | 每次训练后   | 避免长期紧张和积累疲劳   |

## 最小示例

```text
周二：慢跑 20 分钟
周三：深蹲 + 俯卧撑 + 平板支撑
周五：羽毛球 40 分钟
周日：拉伸 + 轻松散步
```

## 执行要点

1. 先保证规律，再追求强度。
2. 一周里要有恢复日。
3. 同一周不要把跑步和羽毛球都堆到高强度。
4. 每次训练后简单记录感受和不舒服的地方。

## 常见误区

- 一周前两天练太猛，后面完全恢复不过来。
- 只安排训练，不安排恢复。
- 计划很满，但执行不了。
