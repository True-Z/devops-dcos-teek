# 跑步个人记录模板

## 阅读建议

- 这页不是展示成绩，而是帮助你记录跑步过程、身体状态和恢复情况，方便长期调整节奏。

## 核心目标

- 通过最小记录，知道自己跑了什么、跑完感觉如何、哪里需要调整。

## 最小记录模板

| 项目     | 示例                     |
| -------- | ------------------------ |
| 日期     | 2026-03-24               |
| 时长     | 25 分钟                  |
| 距离     | 3 公里                   |
| 体感     | 略喘，但能坚持           |
| 身体反馈 | 小腿微紧，膝盖无明显不适 |
| 恢复情况 | 补水，拉伸 5 分钟        |
| 下次调整 | 先保持时长，不急着加速   |

## 可直接复制模板

```text
日期：
时长：
距离：
体感：
身体反馈：
恢复情况：
下次调整：
```

## 记录建议

1. 先记录感受，再记录成绩。
2. 身体反馈要比配速更值得看。
3. 连续几次都不舒服时，要及时降低强度。

## 常见误区

- 只记速度，不记身体状态。
- 练完不记录，后面很难判断自己为什么状态波动。
- 明显疲劳还一味加量。
