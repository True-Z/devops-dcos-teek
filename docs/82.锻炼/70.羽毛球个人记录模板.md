# 羽毛球个人记录模板

## 阅读建议

- 这页重点是帮助你记录打球强度、身体反馈和动作问题，不是只记打了多久。

## 核心目标

- 通过最小记录，知道自己这次打球主要练了什么、哪里累、哪里不舒服、下次要注意什么。

## 最小记录模板

| 项目     | 示例                   |
| -------- | ---------------------- |
| 日期     | 2026-03-24             |
| 时长     | 45 分钟                |
| 训练内容 | 热身 + 对打 + 步伐练习 |
| 体感     | 中等偏累               |
| 身体反馈 | 手腕略紧，膝盖正常     |
| 恢复情况 | 补水，肩膀和腿部拉伸   |
| 下次调整 | 控制发力，先稳动作     |

## 可直接复制模板

```text
日期：
时长：
训练内容：
体感：
身体反馈：
恢复情况：
下次调整：
```

## 记录建议

1. 先记身体反馈，再记打球内容。
2. 哪个关节不舒服一定写下来。
3. 连续几次同一部位不适，就要调整节奏。

## 常见误区

- 只记打球时长，不记动作和身体情况。
- 发现不舒服还继续照常打。
- 打完不做恢复，也不记录原因。
