本目录聚焦“可实施、可落地、可复用”的工程解决方案，优先记录项目实践中的完整处理路径。

为避免与技术知识树冲突：

- `09.解决方案` 用于跨知识域的实施方案沉淀。
- 各技术专题目录（如 `JavaScript`、`IDE`）中的同类内容统一归为“应用方案”。

## 学习目标

- 先明确“问题属于哪类实施场景”。
- 再找到最小可执行路径。
- 最后按具体模块继续下钻配置、命令和注意点。

## 推荐学习路径

1. 先看 [前端解决方案简介](/solution/fe)，理解前端实施问题如何落地。
2. 再看 [插件详解简介](/solution/pluginUnderstand/pluginDetail-intro)，理解工程工具与配置体系。
3. 最后看 [项目理解简介](/solution/projectUnderstand-intro)，把工具和项目结构串起来。

## 模块入口总览

| 模块     | 适合解决的问题                | 入口                                                          |
| -------- | ----------------------------- | ------------------------------------------------------------- |
| 前端     | 部署、兼容、渲染、框架适配    | [前端解决方案简介](/solution/fe)                              |
| 插件理解 | 规范、提交、构建、类型体系    | [插件详解简介](/solution/pluginUnderstand/pluginDetail-intro) |
| 项目理解 | `@nsdk` 包分层、vben 项目配置 | [项目理解简介](/solution/projectUnderstand-intro)             |

## 最小使用方式

```text
遇到问题 -> 判断属于前端/插件/项目哪一类 -> 进入对应入口页 -> 再看具体专题页
```

- 这页不是直接给答案，而是帮助你先选对“从哪里开始看”。
