## 目标

统一代码风格与质量基线，降低代码评审成本，尽早发现潜在问题。

## 工具作用

| 工具        | 核心作用                     | 典型场景           | 在 @nsdk 中的价值                  |
| ----------- | ---------------------------- | ------------------ | ---------------------------------- |
| `eslint`    | 静态分析代码问题与不规范写法 | JS/TS/Vue 代码检查 | 统一语法与最佳实践，减少运行时错误 |
| `prettier`  | 自动格式化代码               | 提交前格式统一     | 降低风格争论，保证代码风格一致     |
| `stylelint` | 校验 CSS/SCSS 样式规范       | 样式文件检查       | 保持样式约束一致，降低样式冲突     |

## 配置与生态清单

### eslint

- 作用：静态分析 JS/TS/Vue 代码质量问题和潜在错误。
- 当前项目配置入口：`@vben/eslint-config`（应用侧）与 `internal/lint-configs/eslint-config`（仓库内配置源）。
- 常见生态插件：`@typescript-eslint/*`、`eslint-plugin-vue`、`eslint-plugin-import-x`、`eslint-plugin-unicorn`、`eslint-plugin-regexp`、`eslint-plugin-jsdoc`、`eslint-plugin-perfectionist`。
- 建议最小命令：`pnpm eslint . --ext .ts,.tsx,.js,.vue`。

```js
export default {
  extends: ['@vben/eslint-config'],
}
```

- 这是最小可用接法，先继承统一规则，再按项目需求少量覆盖。

### prettier

- 作用：统一格式化输出，减少风格分歧。
- 当前项目配置入口：`@nsdk/prettier-config`（应用侧）与 `internal/lint-configs/prettier-config/index.mjs`（仓库内配置源）。
- 常见生态插件：`prettier-plugin-tailwindcss`、`@trivago/prettier-plugin-sort-imports`（按需）。
- 建议最小命令：`pnpm prettier --write .`。

```js
export { default } from '@nsdk/prettier-config'
```

- 适合把格式规则集中维护，业务项目只做继承。

### stylelint

- 作用：统一 CSS/SCSS 书写规范，提前发现样式问题。
- 当前项目配置入口：`internal/lint-configs/stylelint-config/index.mjs`。
- 常见生态插件：`stylelint-config-standard`、`stylelint-config-standard-scss`、`stylelint-order`、`stylelint-config-recess-order`、`postcss-html`。
- 建议最小命令：`pnpm stylelint "**/*.{css,scss,vue}"`。

```js
export default {
  extends: ['stylelint-config-standard'],
}
```

- 最小配置先能跑通，再逐步叠加顺序规则和框架规则。
