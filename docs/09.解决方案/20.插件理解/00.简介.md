本文用于汇总 `@nsdk` 中常见工程插件与工具，按分类拆分到独立文档，便于后续系统学习。

## 学习目标

- 先知道每类工具“解决什么问题”。
- 再知道“最小接法”是什么。
- 最后再理解插件生态与项目内落点。

| 分类           | 目标                       | 代表工具                          | 文档入口                                                                                                 | 推荐学习顺序 |

## 推荐学习路径

1. 先看 [代码规范工具](/solution/pluginUnderstand/pluginDetail-codeSpec)，理解“代码为什么会被统一约束”。
2. 再看 [提交规范工具](/solution/pluginUnderstand/pluginDetail-commitSpec)，理解“团队如何约束变更历史”。
3. 最后看 [构建与类型工具](/solution/pluginUnderstand/pluginDetail-buildType)，理解“项目如何被真正跑起来”。

## 最小接入示例

```json
{
  "scripts": {
    "lint": "eslint .",
    "format": "prettier --write .",
    "typecheck": "vue-tsc --noEmit"
  }
}
```

- 这个最小示例体现了插件理解的核心：先把“检查命令”接进项目，再逐步细化配置。
