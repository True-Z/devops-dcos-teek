## 包清单（基于 `apps/web-ele`）

| 包名                    | 类型   | 主要职责                               | 备注                             |
| ----------------------- | ------ | -------------------------------------- | -------------------------------- |
| `@nsdk/constants`       | 运行时 | 常量、枚举、约束值统一出口             | 被 `utils/hooks/on/plugins` 依赖 |
| `@nsdk/filters`         | 运行时 | 常见格式化与转换函数                   | 依赖 `@nsdk/utils`               |
| `@nsdk/hooks`           | 运行时 | Vue 组合式逻辑封装                     | 依赖 `constants/types/utils`     |
| `@nsdk/on`              | 运行时 | 事件与行为编排入口                     | 依赖 `constants/plugins`         |
| `@nsdk/plugins`         | 运行时 | 插件能力聚合（如请求、时间、序列化等） | 依赖 `axios/dayjs/qs` 等         |
| `@nsdk/styles`          | 运行时 | 样式入口与样式分组导出                 | 提供 `./ele`、`./global` 子导出  |
| `@nsdk/utils`           | 运行时 | 通用工具函数集合                       | 依赖 `lodash-es`                 |
| `@nsdk/types`           | 开发时 | 全局类型与业务类型出口                 | 多包公共类型基础                 |
| `@nsdk/vite-config`     | 构建时 | Vite 配置复用能力                      | 输出 `dist/index.mjs`            |
| `@nsdk/tsconfig`        | 构建时 | TS 配置基线（base/web/node 等）        | 供工程统一继承                   |
| `@nsdk/prettier-config` | 开发时 | Prettier 统一规范配置                  | 代码风格统一入口                 |

## 依赖关系速记

- 基础层：`@nsdk/types`、`@nsdk/constants`
- 工具层：`@nsdk/utils`、`@nsdk/filters`
- 能力层：`@nsdk/plugins`、`@nsdk/hooks`、`@nsdk/on`
- 工程层：`@nsdk/vite-config`、`@nsdk/tsconfig`、`@nsdk/prettier-config`
