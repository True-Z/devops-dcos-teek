本文聚焦 `D:\1024.DevOps\@nsdk\apps\web-ele` 中 vben 相关配置，便于后续你独立搭建同类环境。

## 配置入口总览

| 配置项   | 文件位置                           | 作用                                           |
| -------- | ---------------------------------- | ---------------------------------------------- |
| 构建入口 | `apps/web-ele/vite.config.mts`     | 基于 `@vben/vite-config` 组织 Vite 配置与插件  |
| 启动入口 | `apps/web-ele/src/main.ts`         | 初始化偏好设置、启动应用、移除全局 loading     |
| 偏好设置 | `apps/web-ele/src/preferences.ts`  | 覆盖 vben 默认偏好（主题、权限模式、组件开关） |
| 路由守卫 | `apps/web-ele/src/router/guard.ts` | 登录态校验、动态路由生成、菜单注入             |
| 请求适配 | `apps/web-ele/src/service.ts`      | `@nsdk/plugins` 请求封装与 vben token 同步     |

## 关键配置拆解

### 1) 构建与插件（vite）

- 使用 `@vben/vite-config` 的 `defineConfig` 作为配置入口。
- 通过 `@nsdk/vite-config` 提供路径与环境变量工具（`getRootPath`、`getSrcPath`、`getConvertViteEnv`）。
- 应用侧主要外挂插件：`unplugin-auto-import`、`unplugin-vue-components`、`unplugin-icons`、`unplugin-element-plus`、`vite-plugin-svg-icons`。

### 2) 偏好设置（preferences）

- 通过 `defineOverridesPreferences` 覆盖 vben 默认偏好。
- 重点项：`app.name`、`app.accessMode`、`theme.mode`、`widget.languageToggle/notification`。
- 初始化时由 `main.ts` 调用 `initPreferences`，并使用 `namespace` 做多环境隔离。

### 3) 权限与路由（router guard）

- `setupCommonGuard` 负责页面加载进度和已加载标记。
- `setupAccessGuard` 负责 token 校验、登录跳转、动态路由生成。
- 路由生成流程：`convertResponseRoutes` -> `generateAccess` -> `setAccessMenus/setAccessRoutes`。

### 4) 请求与鉴权（service）

- `@nsdk/plugins` 中 `nsdkRequest` 负责 axios 统一封装。
- token 刷新成功后同步 `@vben/stores` 的 accessToken。
- 业务请求与文件请求分离为 `nsdkService`、`nsdkFileService`，职责更清晰。

## 复用这套配置时的最小清单

| 维度     | 必需项                                                                                | 说明                           |
| -------- | ------------------------------------------------------------------------------------- | ------------------------------ |
| 依赖     | `@vben/*`、`@nsdk/vite-config`、`@nsdk/plugins`                                       | 提供 UI/权限/构建/请求核心能力 |
| 配置文件 | `vite.config.mts`、`preferences.ts`、`router/guard.ts`、`service.ts`                  | 最小可运行配置骨架             |
| 环境变量 | `VITE_GLOB_API_URL`、`VITE_REQUEST_TIMEOUT`、`VITE_APP_NAMESPACE`、`VITE_APP_VERSION` | 支撑请求与命名空间隔离         |
