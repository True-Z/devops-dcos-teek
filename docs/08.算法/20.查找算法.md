## 二分查找

对已排序的整数数据进行查找。

## 选型速查

| 场景               | 适合方案   | 原因          |
| ------------------ | ---------- | ------------- |
| 数据无序、只查一次 | 线性查找   | 不需要预处理  |
| 数据有序、频繁查找 | 二分查找   | 查询效率高    |
| 哈希键值定位       | 哈希表查找 | 平均接近 O(1) |

## 最小使用路径

```text
先确认数据是否有序 -> 有序时优先二分查找 -> 无序时先排序或直接顺序查找
```

## 阅读建议

- 如果你只想快速判断“什么时候能用二分”，看完选型速查和最小路径就够了。
- 真正写代码时，再回头看示例实现。

```typescript
function binSearch(arr: number[], searchValue: number) {
  let leftPoint = 0
  let rightPoint = arr.length - 1
  while (leftPoint <= rightPoint) {
    let midPoint = ~~((leftPoint + rightPoint) / 2)
    if (arr[midPoint] < searchValue) {
      leftPoint = midPoint + 1
    } else if (arr[midPoint] > searchValue) {
      rightPoint = midPoint - 1
    } else {
      return midPoint
    }
  }
  return -1
}
```

- 二分查找的前提是“数据已排序”，这点比代码本身更重要。
