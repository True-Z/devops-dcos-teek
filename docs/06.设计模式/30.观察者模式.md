## 核心目标

- 让一个对象状态变化时，相关依赖方能够自动收到通知。

## 适用场景

| 场景     | 为什么适合               |
| -------- | ------------------------ |
| 事件系统 | 发布变化，多个订阅方响应 |
| 状态管理 | 数据变化驱动视图更新     |
| 消息通知 | 一次变更触发多个后续动作 |

## 最小示例

```js
const listeners = []

function subscribe(fn) {
  listeners.push(fn)
}

function notify(data) {
  listeners.forEach((fn) => fn(data))
}
```

- 这里最关键的不是写法，而是“发布者”和“订阅者”被解耦了。

## 常见误区

- 订阅过多却不清理，导致内存泄漏。
- 一个通知触发链过长，难以排查问题。
