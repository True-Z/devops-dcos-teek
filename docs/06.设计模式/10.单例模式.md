## 核心目标

- 保证某个类或对象在系统中只存在一个共享实例。

## 适用场景

| 场景         | 为什么适合               |
| ------------ | ------------------------ |
| 全局配置中心 | 避免多处创建不同配置实例 |
| 日志器       | 统一记录出口             |
| 缓存管理器   | 保持共享缓存状态         |

## 最小示例

```js
const config = {
  theme: 'dark',
}

export function getConfig() {
  return config
}
```

- 最小理解方式就是：系统里只有这一份共享配置对象。

## 常见误区

- 把所有全局变量都包装成单例。
- 用单例掩盖职责混乱问题。
