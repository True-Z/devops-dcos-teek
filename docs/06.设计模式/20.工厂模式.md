## 核心目标

- 把对象创建过程集中管理，而不是在业务代码里到处分散 `new`。

## 适用场景

| 场景                 | 为什么适合                   |
| -------------------- | ---------------------------- |
| 根据类型创建不同对象 | 统一创建入口                 |
| 组件/服务注册        | 降低业务代码对具体实现的耦合 |
| 多环境实例生成       | 可按配置生成不同实现         |

## 最小示例

```js
function createMessage(type) {
  if (type === 'success') return { color: 'green' }
  if (type === 'error') return { color: 'red' }
  return { color: 'gray' }
}
```

- 重点不是函数名叫“工厂”，而是创建逻辑被集中到了一个入口。

## 常见误区

- 简单对象也强行工厂化，导致层级过多。
- 工厂内部判断过于复杂，最后变成新的大杂烩。
