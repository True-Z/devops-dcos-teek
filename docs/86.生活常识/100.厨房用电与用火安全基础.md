# 厨房用电与用火安全基础

## 阅读建议

- 这页不讲复杂消防知识，重点是先把家里厨房最常见、最容易忽视的风险点记住。
- 很多事故不是大场面，而是油锅离人、插线板乱接、抹布靠火源太近这种小失误积累出来的。

## 核心目标

- 先建立最小判断：明火、热油、电器、插座、可燃物这几类风险该怎么避开。

## 厨房里最常见的风险点

| 风险类型 | 常见场景               | 更稳妥的做法             |
| -------- | ---------------------- | ------------------------ |
| 明火     | 开火后人离灶台         | 开火尽量不离人           |
| 热油     | 油温太高、锅边滴水     | 锅内保持干燥，别猛然加水 |
| 电器     | 电饭煲、电磁炉线路老化 | 线材破损及时更换         |
| 插座     | 多个高功率一起接排插   | 大功率尽量分开使用       |
| 可燃物   | 纸巾、塑料袋靠近火源   | 灶台周边保持空出来       |

## 日常最该养成的习惯

| 习惯               | 为什么重要           |
| ------------------ | -------------------- |
| 做饭前先备菜       | 减少开火后手忙脚乱   |
| 锅边和灶台保持干净 | 油污多更容易起烟起火 |
| 擦手后再碰插头     | 湿手碰电器风险更高   |
| 用完及时关火断电   | 降低忘关带来的隐患   |
| 把抹布锅柄摆顺     | 避免误碰、误拉翻锅   |

## 突发情况怎么做更稳

| 情况         | 优先动作             | 不建议做什么       |
| ------------ | -------------------- | ------------------ |
| 油锅起烟     | 先转小火或关火       | 继续硬烧到冒大烟   |
| 油锅起火     | 盖锅盖或湿布隔绝空气 | 直接泼水           |
| 电器冒味冒烟 | 先断电，停用并检查   | 继续通电硬用       |
| 插座发热     | 停止使用该插座/排插  | 觉得还能用就先凑合 |

## 最小示例

```text
厨房安全最小顺序：
先备菜 -> 再开火 -> 人别离锅 -> 用完关火断电 -> 台面复位
```
