# 搬家打包与物品分类基础

## 阅读建议

- 这页重点不是省到极致，而是先避免搬家时最常见的混乱、漏装、易碎和找不到东西。
- 打包最怕的不是东西多，而是没有分类、没有标记、最后一箱全塞杂物。

## 核心目标

- 先建立最小顺序：先分类、再分房间、再装箱、再标记、最后单独留出即用物品。

## 打包前先怎么分

| 分类方式 | 怎么分                   | 作用                     |
| -------- | ------------------------ | ------------------------ |
| 按房间   | 卧室、厨房、卫生间、书桌 | 到新住处更容易归位       |
| 按用途   | 衣物、工具、证件、清洁品 | 防止全混在一起           |
| 按脆弱度 | 易碎、重物、普通物品     | 方便决定箱子和填充方式   |
| 按时效   | 立即要用、近期用、不常用 | 搬后不会第一天就翻箱倒柜 |

## 最常用的打包原则

| 原则       | 怎么做                   | 注意点                   |
| ---------- | ------------------------ | ------------------------ |
| 重物小箱装 | 书、工具别塞大箱         | 太重不方便搬，也容易破箱 |
| 易碎单独护 | 玻璃、碗盘多包一层缓冲   | 贴上易碎标记             |
| 同类一起装 | 线材、药品、清洁用品分开 | 方便找，也减少污染       |
| 箱外做标记 | 写房间 + 类别 + 是否急用 | 搬到新家后效率高很多     |
| 证件单独带 | 身份证、合同、银行卡随身 | 不要跟普通杂物一起托运   |

## 搬家当天最该单独留一包

| 物品               | 为什么单独留           |
| ------------------ | ---------------------- |
| 证件和钥匙         | 第一优先，不能丢       |
| 手机充电器和插线板 | 到新住处马上能用       |
| 一套换洗衣物       | 当天很可能没空翻箱     |
| 洗漱用品           | 到点能直接洗漱休息     |
| 常用药和纸巾       | 临时不舒服时能马上拿到 |

## 常见失误

- 不写标记，导致每个箱子都要重新翻。
- 所有东西都往大箱里塞，最后重得搬不动。
- 证件、钥匙、合同没单独放，最容易临场找不到。
- 厨房和卫生间的液体用品没做好密封，运输时漏得到处都是。

## 最小示例

```text
搬家最小打包法：
按房间分 -> 同类装一起 -> 箱外写标签 -> 即用物品单独一包
```
