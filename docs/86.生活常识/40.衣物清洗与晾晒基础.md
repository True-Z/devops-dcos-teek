# 衣物清洗与晾晒基础

## 阅读建议

- 这页重点不是洗衣技巧大全，而是先把最常见的分类、清洗和晾晒思路理顺。
- 多数衣服洗坏，不是没洗干净，而是混洗、乱晒、乱烘。

## 核心目标

- 先建立最小判断：颜色分开、材质分开、重污渍先处理、晾晒看面料。

## 洗之前先怎么分

| 分类方式 | 怎么分                 | 主要原因                 |
| -------- | ---------------------- | ------------------------ |
| 颜色     | 浅色、深色、易掉色分开 | 防串色                   |
| 材质     | 棉、羊毛、运动面料分开 | 洗涤强度和晾晒方式不同   |
| 脏污程度 | 日常穿着、重污渍分开   | 重污渍最好先局部预处理   |
| 贴身程度 | 内衣袜子单独洗         | 更卫生，也更方便控制水温 |

## 常见衣物怎么处理

| 衣物类型   | 更稳妥的洗法     | 晾晒建议     | 注意点                 |
| ---------- | ---------------- | ------------ | ---------------------- |
| 棉T恤      | 常规机洗         | 反面晾晒     | 深色新衣前几次单独洗   |
| 牛仔裤     | 减少频繁机洗     | 反面通风晾   | 洗太勤更容易掉色变形   |
| 运动速干衣 | 轻柔机洗或手洗   | 通风处晾干   | 少用高温烘干           |
| 毛衣       | 轻柔手洗或洗衣袋 | 平铺晾干     | 挂晒容易拉长变形       |
| 羽绒服     | 看洗标处理       | 完全干透再收 | 没把握时优先送专业清洗 |

## 常见污渍的最小处理

| 污渍     | 先做什么         | 注意点                 |
| -------- | ---------------- | ---------------------- |
| 油渍     | 先局部用洗剂揉开 | 越早处理越容易洗掉     |
| 汗渍     | 先浸泡再洗       | 别长时间闷着不洗       |
| 泥点灰尘 | 先抖落或刷掉干污 | 直接湿洗有时会更难清   |
| 血渍     | 优先冷水处理     | 热水更容易让蛋白质凝固 |

## 最小示例

```text
洗衣前先做四件事：
看洗标 -> 掏空口袋 -> 按颜色和材质分开 -> 重污渍先局部处理
```
