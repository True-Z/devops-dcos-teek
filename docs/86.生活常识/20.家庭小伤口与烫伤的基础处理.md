# 家庭小伤口与烫伤的基础处理

## 阅读建议

- 这页只覆盖家庭常见的小伤口、小面积烫伤和何时该及时就医，不代替专业医疗判断。
- 先记住顺序，再记住哪些做法不要做，比背很多细节更有用。

## 核心目标

- 先建立最小判断：哪些能先自己处理，哪些不能拖，哪些常见土办法要避免。

## 小伤口怎么处理

| 场景     | 优先做什么       | 主要步骤                         | 注意点                     |
| -------- | ---------------- | -------------------------------- | -------------------------- |
| 轻微割伤 | 止血、冲洗、覆盖 | 压迫止血 -> 流水冲洗 -> 碘伏消毒 | 伤口深、持续出血要尽快就医 |
| 擦伤     | 清洁、去脏、覆盖 | 流水冲洗 -> 去掉明显脏物 -> 覆盖 | 不要反复摩擦伤面           |
| 小划伤   | 清洁、观察       | 冲洗 -> 消毒 -> 保持干净         | 红肿加重、化脓要看医生     |

## 小面积烫伤怎么处理

| 步骤 | 主要动作       | 关键点                                 |
| ---- | -------------- | -------------------------------------- |
| 1    | 先离开热源     | 先关火、放下热锅、远离热油热水         |
| 2    | 用流动凉水冲   | 一般持续冲 15 到 20 分钟，帮助降温     |
| 3    | 取下紧的饰品   | 手指、手腕烫伤时尽早取下戒指手表       |
| 4    | 轻盖干净敷料   | 用干净纱布或不粘敷料覆盖               |
| 5    | 观察是否要就医 | 面积大、起泡严重、脸手会阴部要尽快就医 |

## 这些做法别乱用

| 常见误区         | 为什么不建议               |
| ---------------- | -------------------------- |
| 直接抹牙膏       | 不利于清洁，还可能刺激伤口 |
| 直接抹酱油/香油  | 容易污染伤面，影响后续处理 |
| 冰块直接贴烫伤处 | 可能进一步刺激皮肤组织     |
| 深伤口自己贴死   | 容易把脏东西封在里面       |

## 什么时候别拖

- 出血压了几分钟还止不住。
- 伤口很深、边缘张开、怀疑要缝合。
- 烫伤面积较大，或在面部、手部、关节、会阴等敏感位置。
- 出现明显红肿加重、流脓、发热等感染迹象。

## 最小示例

```text
小割伤：压一压止血 -> 流水冲洗 -> 碘伏消毒 -> 干净覆盖
小烫伤：离开热源 -> 凉水持续冲 -> 干净覆盖 -> 观察是否就医
```
