# 租房入住检查清单

## 阅读建议

- 这页重点不是教你谈判技巧，而是帮你在入住前把最容易忽略、后面最容易扯皮的点先看掉。
- 看房和入住时最好边看边拍照、边记，不要只靠口头确认。

## 核心目标

- 先建立最小检查顺序：房屋状态、用水用电、家电家具、网络门锁、费用与交接。

## 入住前最该看的几类

| 类别     | 重点看什么                 | 为什么要看                   |
| -------- | -------------------------- | ---------------------------- |
| 房屋状态 | 墙面、地板、门窗、渗水痕迹 | 免得入住后分不清旧问题新问题 |
| 水电燃气 | 灯、插座、水龙头、热水器   | 直接影响日常使用和安全       |
| 家电家具 | 空调、冰箱、洗衣机、床柜   | 坏了要提前确认谁负责处理     |
| 门锁网络 | 门锁是否正常、网线/宽带    | 关系到安全和入住便利         |
| 费用交接 | 水电表、燃气表、物业费     | 避免替前租客埋单             |

## 看房时怎么快速过一遍

| 场景       | 最小检查动作                 | 注意点                   |
| ---------- | ---------------------------- | ------------------------ |
| 门窗       | 开关一遍，看看是否卡顿、漏风 | 纱窗、锁扣也要一起确认   |
| 灯和插座   | 逐个开灯，带充电器试几个插座 | 厨卫插座尤其要看         |
| 水路       | 开冷热水、冲马桶、看下水速度 | 看有没有返味、堵塞、渗漏 |
| 空调热水器 | 通电运行几分钟               | 不要只听“能用”两个字     |
| 墙面地面   | 看霉斑、起皮、鼓包、破损     | 卫生间和窗边最容易出问题 |

## 入住当天最好做的交接

| 项目     | 该怎么做                   | 目的                 |
| -------- | -------------------------- | -------------------- |
| 拍照留存 | 对每个房间、损坏点拍照     | 留证据，减少后续争议 |
| 记录表数 | 水表、电表、燃气表拍照     | 作为起始读数         |
| 钥匙门禁 | 确认数量、是否都能使用     | 避免门禁不全影响出入 |
| 费用说明 | 明确押金、物业、网费谁承担 | 免得后面口径不一致   |
| 联系方式 | 留房东/中介/物业联系方式   | 出问题时能及时找到人 |

## 常见容易扯皮的点

- 口头说“之后会修”，但没有写进聊天记录或合同。
- 入住前没拍照，退租时说不清原本是否破损。
- 没核对水电表，后面把上一任住户欠费一起算进来。
- 只看房间表面，没实际试空调、热水器、洗衣机。

## 最小示例

```text
看房/入住最小顺序：
拍照 -> 试水电 -> 试家电 -> 记表数 -> 留聊天记录/交接记录
```
