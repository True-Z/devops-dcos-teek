# 雨天出行与衣物防潮基础

## 阅读建议

- 这页重点不是讲装备发烧，而是先解决雨天最常见的几个问题：出门狼狈、鞋袜潮、包里进水、回家后发霉。
- 雨天的关键不是完全不湿，而是尽量少进水、回来后尽快处理。

## 核心目标

- 先建立最小顺序：出门前做准备，路上少进水，回家后及时晾干除潮。

## 出门前最实用的准备

| 物品/动作     | 主要作用         | 注意点               |
| ------------- | ---------------- | -------------------- |
| 折叠伞/雨衣   | 基础挡雨         | 大风天雨衣往往更稳   |
| 防水袋/塑料袋 | 保护手机和证件   | 包里留一个很实用     |
| 备用袜子      | 脚湿后及时更换   | 长时间穿湿袜很难受   |
| 深色速干衣物  | 回来后更容易处理 | 棉质厚衣物更难干     |
| 提前看天气    | 判断是否改路线   | 暴雨天别硬走低洼路段 |

## 回家后怎么处理更稳

| 对象 | 先做什么             | 注意点                 |
| ---- | -------------------- | ---------------------- |
| 雨伞 | 打开晾干再收         | 湿着收起来更容易有味道 |
| 鞋袜 | 先换下并通风         | 别闷在鞋柜里           |
| 外套 | 挂开晾，必要时开风扇 | 厚外套湿后更容易有潮味 |
| 背包 | 擦干表面，倒出积水   | 电子产品先拿出来检查   |
| 房间 | 适当通风除湿         | 潮湿天可配合除湿设备   |

## 最常见的问题

| 问题         | 更稳的做法             |
| ------------ | ---------------------- |
| 鞋里进水     | 先吸干，再通风晾       |
| 衣服有潮味   | 尽快洗或彻底晾干       |
| 包内文件受潮 | 先分开放平晾干         |
| 房间闷湿     | 通风和除湿一起做更有效 |

## 最小示例

```text
雨天最小处理法：
出门带伞和防水袋 -> 回家先换湿衣湿袜 -> 把鞋包伞都摊开晾干
```
