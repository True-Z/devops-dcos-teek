# 家用五金工具入门

## 阅读建议

- 这页不是讲装修，而是先认清家里最常会碰到的基础工具和典型场景。
- 先知道什么时候该拿什么工具，往往比蛮力更重要。

## 核心目标

- 先建立最小匹配：拧、夹、敲、量、切这几类动作分别优先想到什么工具。

## 家里最常用的几样

| 工具       | 主要用途           | 常见场景             | 注意点                   |
| ---------- | ------------------ | -------------------- | ------------------------ |
| 十字螺丝刀 | 拧十字螺丝         | 插座面板、小家电     | 刀头尺寸要匹配           |
| 一字螺丝刀 | 拧一字螺丝、轻撬   | 老式螺丝、卡扣       | 不要拿来硬撬危险结构     |
| 活动扳手   | 调节尺寸拧螺母     | 水龙头、小五金       | 先卡紧再发力             |
| 尖嘴钳     | 夹、弯、拉细小部件 | 电线、小零件         | 不等于绝缘操作工具       |
| 羊角锤     | 敲钉、起钉         | 挂画、简单固定       | 敲击前先确认墙面和位置   |
| 卷尺       | 量长度、留安装余量 | 家具、窗帘、收纳尺寸 | 常量两次，别凭感觉买东西 |
| 美工刀     | 切纸箱、裁薄材料   | 快递拆箱、简单裁切   | 刀片不用时及时收回       |

## 怎么快速选

| 你的目的       | 优先想到 |
| -------------- | -------- |
| 拧螺丝         | 螺丝刀   |
| 拧螺母         | 活动扳手 |
| 夹细小东西     | 尖嘴钳   |
| 量尺寸         | 卷尺     |
| 拆箱或裁切薄料 | 美工刀   |
| 轻敲或拔钉     | 羊角锤   |

## 使用时最容易忽略的点

- 先断电，再碰插座、灯具、裸露导线附近的零件。
- 螺丝刀和螺丝槽型、大小不匹配时，最容易打滑伤手。
- 拧不动时先确认是不是反方向，不要直接暴力上手。
- 需要打孔、上墙承重、改水改电的场景，不属于这页的入门范围。

## 最小示例

```text
租房/家用最小工具包：
十字螺丝刀 + 一字螺丝刀 + 活动扳手 + 尖嘴钳 + 卷尺 + 美工刀
```
