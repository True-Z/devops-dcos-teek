# 日常清洁工具与清洁剂基础

## 阅读建议

- 这页重点不是深度保洁，而是先分清家里最常用的清洁工具、清洁剂和基础使用边界。
- 很多清洁问题不是不会擦，而是工具不对、顺序不对，或者把不该混用的东西混在一起。

## 核心目标

- 先建立最小判断：擦灰、去油、刷污垢、拖地、消味分别该优先想到什么工具和清洁剂。

## 家里最常用的工具

| 工具         | 主要用途           | 常见场景         | 注意点                   |
| ------------ | ------------------ | ---------------- | ------------------------ |
| 超细纤维抹布 | 擦灰、擦台面、水渍 | 桌面、柜面、玻璃 | 生熟区和厨卫区尽量分开用 |
| 海绵/百洁布  | 去污、刷洗         | 水槽、灶台、锅具 | 粗糙面别乱刷易刮花表面   |
| 马桶刷       | 清洁马桶内壁       | 卫生间           | 用后冲净并保持通风晾干   |
| 扫把/簸箕    | 清理地面灰尘杂物   | 客厅、卧室       | 先扫再拖更省力           |
| 拖把         | 地面清洁           | 全屋地面         | 木地板和瓷砖用水量不同   |
| 橡胶手套     | 隔离污渍和刺激物   | 厨卫清洁         | 接触清洁剂时更稳妥       |

## 常见清洁剂怎么分

| 类型         | 主要用途         | 常见场景         | 注意点                       |
| ------------ | ---------------- | ---------------- | ---------------------------- |
| 中性清洁剂   | 日常基础去污     | 台面、地面、家具 | 入门最稳，适合大多数轻污渍   |
| 厨房去油剂   | 去油污           | 灶台、油烟机附近 | 重油污更有效，先小范围试用   |
| 卫生间清洁剂 | 水垢、皂垢、异味 | 马桶、洗手池     | 看说明使用，别长时间闷着不冲 |
| 玻璃清洁剂   | 去手印和水痕     | 玻璃、镜面       | 喷太多反而更容易留印         |
| 消毒类产品   | 特定场景消毒     | 垃圾桶、马桶圈等 | 不等于日常处处都要大量使用   |

## 最容易踩坑的点

| 问题             | 为什么要注意                 |
| ---------------- | ---------------------------- |
| 清洁剂混用       | 可能产生刺激性气味或风险     |
| 一块抹布全屋通用 | 容易把油污、细菌带来带去     |
| 先拖地后扫地     | 地上毛发灰尘会越拖越脏       |
| 不看材质乱刷     | 玻璃、不锈钢、木面可能被刮伤 |

## 最小顺序

```text
先收杂物 -> 再擦高处和台面 -> 再扫地 -> 最后拖地和清理厨卫
```
