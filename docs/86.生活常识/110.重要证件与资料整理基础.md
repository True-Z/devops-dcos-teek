# 重要证件与资料整理基础

## 阅读建议

- 这页不是教你做档案管理，而是先解决“证件平时乱放、急用时找不到”的现实问题。
- 重要资料最怕的不是多，而是分散、混放、没有备份。

## 核心目标

- 先建立最小原则：原件集中、复印件备用、电子扫描留底、敏感资料单独保管。

## 常见资料怎么分

| 类别       | 常见内容               | 更稳的放法               |
| ---------- | ---------------------- | ------------------------ |
| 身份类     | 身份证、户口本、护照   | 原件集中在固定文件袋     |
| 学历资格类 | 毕业证、学位证、资格证 | 单独夹层，避免折损       |
| 合同票据类 | 租房合同、发票、保修单 | 按时间或用途分类放       |
| 医疗类     | 病历、检查单、医保相关 | 常用和历史资料分开放     |
| 电子备份   | 扫描件、照片、重要截图 | 统一命名并备份到固定位置 |

## 最小整理法

| 步骤 | 主要动作             | 关键点                 |
| ---- | -------------------- | ---------------------- |
| 1    | 先归拢全部资料       | 别边找边收，容易漏     |
| 2    | 按类别分组           | 身份、合同、票据先分开 |
| 3    | 原件和复印件分开放   | 需要提交时不容易拿错   |
| 4    | 做电子扫描或拍照备份 | 重要证件优先留底       |
| 5    | 固定收纳位置         | 放回去比“记得住”更可靠 |

## 最容易忽略的点

- 只留原件，不留复印件和电子备份。
- 各种合同、发票随手塞抽屉，后面维权和报销都难找。
- 把高频要用和长期存档资料混在一个袋里。
- 敏感资料随便拍照发群或长期裸存聊天记录里。

## 最小示例

```text
资料整理最小结构：
原件一袋 + 复印件一袋 + 电子备份一处
```
