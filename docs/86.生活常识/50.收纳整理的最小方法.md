# 收纳整理的最小方法

## 阅读建议

- 这页不追求把家里整理成样板间，而是先解决“东西总找不到、越收越乱”的常见问题。
- 收纳的重点不是买很多盒子，而是先减少混放和临时堆放。

## 核心目标

- 先建立最小原则：同类放一起、常用放顺手、重物放下层、给物品固定位置。

## 最常用的四个原则

| 原则         | 怎么理解                 | 典型效果           |
| ------------ | ------------------------ | ------------------ |
| 同类归类     | 线材归线材，药品归药品   | 找东西更快         |
| 固定位置     | 每类物品有固定落点       | 用完后更容易放回去 |
| 使用频率优先 | 常用放顺手，不常用放高处 | 日常拿取更省事     |
| 先分区再细分 | 先按房间/用途分，再分盒  | 不会越整理越乱     |

## 家里最常见的收纳对象

| 对象       | 更稳的收法             | 注意点                   |
| ---------- | ---------------------- | ------------------------ |
| 证件票据   | 文件袋或固定抽屉集中放 | 重要证件别分散到多个角落 |
| 线材充电器 | 按设备分类捆扎收纳     | 不要全部塞一个杂物盒     |
| 常备药     | 单独小盒，分类放置     | 注意过期时间和儿童接触   |
| 工具       | 放一个固定工具区       | 常用工具别分散各房间     |
| 衣物       | 当季和非当季分开       | 非当季收纳前先洗净晾干   |

## 怎么开始最不容易失败

1. 先挑一个很小的区域，比如一个抽屉或一个桌面。
2. 先把里面东西全部拿出来，同类放一起。
3. 再决定哪些高频、哪些低频、哪些可以丢。
4. 最后才决定要不要用盒子，不要一开始先买收纳用品。

## 最小示例

```text
找不到东西的常见原因：
没有分类 + 没有固定位置 + 用完随手放
```
