# 常见药品与家庭药箱基础

## 阅读建议

- 这页重点是建立家庭药箱的最小配置思路，不是替代医生开药，也不是教长期自行用药。
- 比起囤很多药，更重要的是知道分类、有效期和什么情况该就医。

## 核心目标

- 先建立最小框架：外伤处理、发热疼痛、肠胃不适、鼻塞咽痛、体温与基础工具。

## 家庭药箱最小配置

| 类别     | 常见内容                   | 主要用途             | 注意点                 |
| -------- | -------------------------- | -------------------- | ---------------------- |
| 外伤处理 | 碘伏、棉签、创可贴、纱布   | 小伤口清洁和覆盖     | 污染后及时更换         |
| 发热疼痛 | 常见退热止痛药             | 发热、头痛、肌肉酸痛 | 看说明书和禁忌人群     |
| 肠胃不适 | 口服补液盐、常见止泻或胃药 | 轻度腹泻、胃部不适   | 严重腹痛、脱水要就医   |
| 鼻塞咽痛 | 常见含片、鼻部护理用品     | 轻微咽痛、鼻塞不适   | 症状久拖不缓解要看医生 |
| 基础工具 | 体温计、口罩、剪刀、小镊子 | 测温、简单处理、取物 | 工具也要保持清洁       |

## 药箱怎么放更稳妥

| 原则     | 怎么做                   | 作用               |
| -------- | ------------------------ | ------------------ |
| 分类摆放 | 外用、内服、工具分开放   | 取用时更不容易拿错 |
| 留说明书 | 盒子和说明书尽量一起留着 | 临时用药时方便核对 |
| 定期检查 | 隔几个月看一次有效期     | 避免过期药一直留着 |
| 儿童隔离 | 放高处或锁起来           | 降低误食风险       |
| 防潮避光 | 别放在潮湿高温位置       | 减少变质失效的可能 |

## 什么时候不要自己扛

- 高烧持续不退，或者反复明显加重。
- 腹痛剧烈、持续呕吐、明显脱水。
- 伤口深、感染迹象重，或者烫伤范围较大。
- 老人、儿童、孕妇、慢病人群用药拿不准时。

## 最小示例

```text
家庭药箱最小思路：
能处理小问题 + 能先观察 + 知道什么时候该去医院
```
