## 理解路径

1. 先进入运维认知，理解运维是什么、学什么、怎么分。
2. 再进入运维基础，建立计算机 4 大件的最小认知。
3. 接着进入操作系统，补 Windows 与 Linux 的实际环境认知。
4. 再进入知识实操，理解跨平台都通用的知识对象。
5. 然后进入实操方案，沉淀真正会反复使用的操作流。
6. 最后进入自动化运维，把重复动作逐步自动化。

运维模块用于承接开发者后续的运维认知、运维基础、操作系统、知识实操、实操方案和自动化运维六类内容，先建立最小认知，再进入平台环境与实际操作。
