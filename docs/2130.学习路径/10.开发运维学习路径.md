# 开发运维学习路径

## 主模型定位

- 主模型：认知层
- 这页主要回答“怎么理解这个主题，以及它在运维知识里的位置。”

## 阅读建议

- 这页面向开发者，不按传统运维认证路线展开，而是按“能上手排查与部署”来组织。

## 核心目标

- 帮你从 Linux 基础走到最小可用的开发运维能力。

## 推荐顺序

1. Linux 基础命令与目录结构。
2. 文件、权限、用户和组。
3. 日志查看与简单排障。
4. 服务管理与部署基础。
5. 网络与常见线上问题定位。

## 最小学习链路

```text
命令基础 -> 文件权限 -> 日志排查 -> 服务管理 -> 部署与网络
```

## 常见误区

- 一开始就学复杂平台，不先把 Linux 基础打稳。
- 只背命令，不理解命令所对应的系统对象。
- 学了部署，不学日志和回滚。
